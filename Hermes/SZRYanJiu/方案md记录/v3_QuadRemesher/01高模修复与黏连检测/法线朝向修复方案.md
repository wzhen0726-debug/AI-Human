# 高模修复 — 法线朝向修复方案

**日期**: 2026-07-24  
**项目**: v3_QuadRemesher 高模修复管线  
**问题**: AI 生成高模（Tripo/混元）材质模式下出现黑色/透明区域，预览模式正常

---

## 六、关键 Bug：BVH 缓存法线导致的重复翻转

### 问题

在射线循环中直接 `normal_flip()`，但 BVH 树缓存的法线未更新：

```
第 N 条射线命中面 fi → 翻转 fi
第 N+K 条射线再次命中 fi → BVH 返回的还是【翻转前的旧法线】
→ 再次满足翻转条件 → 又翻转回去（偶数次 = 没变，奇数次 = 错误）
```

### 修复：检测与修改解耦 + 投票制

```python
# 1. 收集投票（不修改）
face_votes = {f.index: [0, 0] for f in bm.faces}
for i in range(n_rays):
    hit, normal, fi, _ = bvh.ray_cast(origin, ray_dir, dim * 4)
    if hit and fi is not None:
        if normal.dot(ray_dir) > 0:
            face_votes[fi][0] += 1  # 朝内
        else:
            face_votes[fi][1] += 1  # 朝外

# 2. 统一翻转（只执行一次）
for fi, (wrong, correct) in face_votes.items():
    if (wrong + correct > 0) and (wrong > correct):
        bm.faces[fi].normal_flip()
```

### 结果

| 指标 | 值 |
|------|-----|
| 翻转面数 | **0**（原模型外表面法线本来就正确）|
| 收敛轮数 | **1** |
| 处理时间 | ~60 秒 |

**之前的 319 面翻转是 BVH 缓存 bug 导致的误伤。**

## 一、问题根因

AI 生成的高模是**多层网格结构**（衣物外层 + 衣物内层 + 身体层），其中**外表面部分面片法线朝内**。

在材质模式（Material Preview / EEVEE / Cycles）下，渲染器默认开启**背面剔除（backface culling）**，法线朝内的面片不被渲染，显示为黑色或透明（背景色透出）。

在实体模式（Solid）下，背面剔除默认关闭，所有面正常显示，所以问题不可见。

---

## 二、Blender 内置方案：Shift+N（normals_make_consistent）

### 原理

`normals_make_consistent(inside=False)` 从某个种子面开始，沿面邻接关系传播"统一方向"。

### 为什么在 AI 高模上失效

| 问题 | 说明 |
|------|------|
| 多层网格邻接断裂 | 衣物和身体是两个独立的壳，邻接关系不连续 |
| 假设不成立 | 算法假设"大多数面方向正确"，但 AI 高模可能有 50%+ 面朝内 |
| 每次结果不同 | 传播路径依赖种子面选择，在复杂拓扑上非确定性 |

**实测数据**（tripoTpose, 193 万面）:

| 操作 | 法线朝内面片数 |
|------|---------------|
| 修复前 | ~113,000 |
| Shift+N 第 1 次 | ~127,000（更差）|
| Shift+N 第 2 次 | ~124,000 |
| Shift+N 第 3 次 | ~9,000（部分恢复）|

**结论**: Shift+N 不可靠，不收敛，每次运行结果不同。

## 三、BVH 射线法（当前方案）

### 核心思想

不依赖面邻接关系，而是从外部向模型发射射线，检测哪些面是外表面，然后检查其法线方向。

### 正确逻辑

```
射线方向 = 从外部指向内部 (ray_dir = 外→内)
命中面的法线应该指向外部 = 与射线方向相反

判定:
  normal · ray_dir > 0  →  法线与射线同向  →  法线朝内  →  翻转
  normal · ray_dir < 0  →  法线与射线反向  →  法线朝外  →  正确
```

### 实现步骤

1. 计算模型包围盒中心 `center` 和最大维度 `dim`
2. 用 Fibonacci 球面采样生成 50,000 个均匀分布的射线方向
3. 每个射线从 `center + direction * dim`（外部）射向 `center - direction * dim`（内部）
4. BVH ray_cast 获取命中面片 `fi` 和命中法线 `normal`
5. 若 `normal · ray_dir > 0`，翻转 `bm.faces[fi].normal_flip()`
6. 重复直到收敛（通常 2 轮）

### Python 核心代码

```python
import bmesh, math
from mathutils import Vector
from mathutils.bvhtree import BVHTree

# 模型包围盒
xs = [v.co.x for v in mesh.vertices]
ys = [v.co.y for v in mesh.vertices]
zs = [v.co.z for v in mesh.vertices]
center = Vector(((min(xs)+max(xs))/2, (min(ys)+max(ys))/2, (min(zs)+max(zs))/2))
dim = max(max(xs)-min(xs), max(ys)-min(ys), max(zs)-min(zs))

bm = bmesh.new()
bm.from_mesh(mesh)
bm.faces.ensure_lookup_table()
bvh = BVHTree.FromBMesh(bm)

n_rays = 50000
golden = (1 + math.sqrt(5)) / 2  # 黄金比例

for rnd in range(3):  # 最多3轮
    flipped = 0
    for i in range(n_rays):
        # Fibonacci 球面均匀分布
        theta = 2 * math.pi * i / golden
        phi = math.acos(1 - 2 * (i + 0.5) / n_rays)
        dx = math.sin(phi) * math.cos(theta)
        dy = math.sin(phi) * math.sin(theta)
        dz = math.cos(phi)

        ray_dir = Vector((-dx, -dy, -dz))  # 外→内
        origin = center + Vector((dx, dy, dz)) * dim  # 外部起点

        hit, normal, fi, _ = bvh.ray_cast(origin, ray_dir, dim * 3)
        if hit and fi is not None and normal.dot(ray_dir) > 0:
            bm.faces.ensure_lookup_table()
            bm.faces[fi].normal_flip()
            flipped += 1

    bm.to_mesh(mesh)
    bm.free()
    mesh.update()

    if flipped == 0:
        break  # 收敛

    bm = bmesh.new()
    bm.from_mesh(mesh)
    bm.faces.ensure_lookup_table()
    bvh = BVHTree.FromBMesh(bm)
```

## 五、关键设计决策

### 5.1 为什么用 Fibonacci 球面采样而不是随机

| 方法 | 覆盖率 | 收敛性 |
|------|--------|--------|
| 随机采样 | 不均匀，有空洞 | 不收敛（每轮 ~2400 面） |
| Fibonacci 球面 | 均匀分布 | **2 轮收敛** |

### 5.2 为什么只翻转外表面

内表面（衣物内侧、口腔内部）的法线朝内是**正确的**——它们应该朝向身体。如果强行翻转内表面，会导致材质模式下出现白色斑块（光照异常）。

BVH 射线法天然只命中外表面，不会误伤内层。

### 5.3 为什么 50,000 条射线

193 万面模型的外表面约 50,000 面（2.6%），50,000 条射线覆盖率约 99.8%。

### 5.4 为什么需要多轮

第 1 轮翻转后，BVH 树需要重建（面法线变了），第 2 轮确认无残留。如果模型极复杂，可能需 3 轮。

## 六、已知限制

| 限制 | 说明 |
|------|------|
| 射线数固定 | 50000 条对 100 万面模型足够，对 500 万面可能需增加 |
| 非凸区域 | 裆部、腋下等凹陷区域，射线可能从内部命中，但概率极低（<0.01%） |
| 内层法线 | 内层法线朝内是正常的，本方案不处理也不影响 |
| 仅处理外表面 | 如果用户需要内层也朝外（如 3D 打印），需额外处理 |

## 七、尝试过的失败方案

| 方案 | 问题 |
|------|------|
| `normals_make_consistent` | 不收敛，每次结果不同 |
| 中心外向法 `(face_center - model_center)` | 人体非凸，裆部/腋下判断错误 |
| 按 Y 轴方向翻转 | 只处理前侧，忽略后侧/侧面 |
| 翻转所有朝内面（含内层）| 内层法线翻转后产生白色斑块 |
