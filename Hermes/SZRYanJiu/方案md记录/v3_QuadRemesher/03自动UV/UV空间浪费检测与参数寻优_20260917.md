# 03 自动UV — 大面积浪费检测 + 自适应参数搜索（2026-09-17 v3 定案）

## 问题
原 UV 展开（Smart UV Project 66° + 自带打包）存在**大面积浪费**：左中/左下整块连续空白
（最大空方块 0.238，占地图 5.68%），利用率仅 30.9%。

## 检测指标（每次展开后测量，全部由数据算出）

| 指标 | 算法 |
|---|---|
| 利用率 U | Σ\|UV面面积\| / 1.0（逐面 Shoelace 求和） |
| 最大空方块 | 布局栅格化(256²)+2格膨胀封孔 → 最大空方块 DP（归一化边长/面积） |
| 岛统计 | UV连通分量（共享边且两端UV相等）→ 岛数/最大岛面积与边长/中位岛边长 |
| 纹素密度CV | 逐面 (UV面积 / 3D面积) 的变异系数 |

## 判据（自参照三项比值，≤1 通过；**不含任何模型相关常量，换原始模型依然成立**）

| 比值 | 含义 |
|---|---|
| 废料比 = 最大空方块面积 / 最大岛面积 | <1：空块大到**装不下**最大的岛 = 无大面积浪费（越大越浪费） |
| 密度比 = 候选CV / 基准CV | ≤1：不破坏展开算法自身的纹素密度均匀度（保烘焙） |
| 岛数比 = 候选岛数 / 基准岛数 | ≤1：不新增接缝/碎岛（保"少接缝"） |

## 搜索与循环（5 轮预算，跑完择优，任何失败都不阻断）

- **第1轮**：66°（既有"少接缝"定案）+ 自带打包 = 基准（同时给出三项比值的分母）
- **第2轮**：66°+光顺+重打包（验证"重打包"增益）
- **第3轮**：89°+…（探上界）   **第4轮**：(66+89)/2=77.5°+…
- **第5轮**：朝**合法候选的峰值一侧**再二分一探（无合法者才退用原始U峰）
- **异常防护**：单轮展开失败自动跳过；全部方案都不满足约束时，按
  (废料比最小 → 利用率最高) 取"**最好一版**"继续（告警但不失败）；
- **定状态**：用选定参数重跑一次并复测三项比值，若不过则**依次退用次优**（处理运行波动），
  全部不过保留最优一版并告警 —— 每种情况都保证管线拿到可用的 UV。

## 实测（本模型 161,083 面；程序 ~58s = 5轮×~10s + 定状态复跑）

| 轮 | 方案 | U | 最大空方块 | 岛数 | CV | 废料比/密度比/岛数比 | 判定 |
|---|---|---|---|---|---|---|---|
| 1 | 66° 自带打包（基准） | 30.9% | 0.238(5.68%) | 429 | 0.114 | 1.02/1.00/1.00 | ✗ 大面积浪费 |
| **2** | **66°+光顺+重打包（选定）** | **41.6%** | **0.020(0.04%)** | **429** | **0.108** | **0.01/0.94/1.00** | ✓ |
| 3 | 89°+光顺+重打包 | 42.9% | 0.066(0.44%) | 333 | 0.221 | 0.07/**1.94**/0.78 | ✗ 密度变差 |
| 4 | 77.5°+光顺+重打包 | 40.3% | 0.020(0.04%) | 445 | 0.109 | 0.01/0.95/**1.04** | ✗ 新增碎岛 |
| 5 | 71.8°+光顺+重打包 | 40.6% | 0.023(0.05%) | 420 | 0.108 | 0.01/0.95/0.98 | ✓（U 较低未选） |

**结果：利用率 30.9% → 41.6%（+10.7pp）**，大面积空块 0.238→0.020 消失；
同轮实测也说明"岛越少越好/角度越高越好"均不成立（89°密度崩、77.5°碎岛增），
**必须以实测三项比值择优**。视觉复核：岛形态不变、仅重排/旋转、无重叠、无越界。
