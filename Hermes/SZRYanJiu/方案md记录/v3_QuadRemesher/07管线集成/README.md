# 07 管线集成 — 演示版终端控制台（2026-09-17 已实现）

**状态**: ✅ 已实现 — `演示版_终端控制端/控制台.py`（录屏汇报版）
**定位**: 把 01~06 六个环节串成一条命令驱动的流水线，在终端里逐环节真实调用 Blender 5.1 处理。

## 一、命令

| 命令 | 环节 | 说明 |
|---|---|---|
| `01` | 高模修复与黏连检测 | raw_model.glb → 修复后高模（96.5万顶点） |
| `01a` | 眼窝重建（半自动打点） | 放点→GUI手调→镜像→读取→开孔→赋材质 |
| `02` | 拓扑重建+眼窝碗+眼球摆入 | QR(15万quad) → 碗(纯rim程序化) → 眼球摆入并并入 |
| `03` | 自动UV | Smart Project（66°角度限制） |
| `04` | 纹理烘焙(4K) | Diffuse+Normal + 贴图溢出/异常斑自动处理 |
| `05` | 骨骼绑定与动作重定向 | AI打点→55骨→03B标准化→走/跑/跳；交付3个bl |
| `06` | GLB导出 | 三动画单文件GLB + 重导入复核 |
| `all` | 全流程 | 01→01a→02→03→04→05→06，环节间回车继续 |
| `clean [环节/all]` | 清理输出(递归)+中间件 | 保留脚本/手调文件/原始文件/_备份 |
| `status` | 产物状态看板 | 各环节产物大小与时间 |

## 二、工程约定

- **产物目录**：各 stage 的 `输出/`；中间件 `_中间/`；脚本 `scripts/`；**不设"交付/"目录**（测试期产物直接写输出/）
- **手调文件保护**：`01A_markers_eyelid.blend`、`eyelid_contour_manual.json`、`iris_3ddfa.json`（3ddfa/三json）、ARP手调点位备份 —— clean 绝不删除；权威备份在 `_备份/手调文件_权威/`
- **两个 GUI 介入点**（展示半自动能力）：01a 眼裂轮廓微调、05 的17关节微调；各自自动弹点位指南
- **完成标记把关**：每步脚本必须打印完成标记（DONE标志），控制台以"退出码0 + 标记在日志中"双重判定
- **单行动态进度**：旋转符+进度条+阶段名原地刷新；详细日志写 `logs/<环节>.txt`
- **噪声过滤**：插件后台注册的 Traceback 自动隐藏（真实报错照常显示）
- `DEMO_SKIP_GUI=1` 环境变量可跳过GUI等待（自动化测试用；正式录屏不设）
