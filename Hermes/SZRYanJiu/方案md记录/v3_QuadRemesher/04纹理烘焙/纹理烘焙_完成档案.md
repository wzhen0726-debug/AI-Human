## 2026-09-17 · 贴图溢出处理(烘焙后自动步骤, 用户要求)
- 现象: 烘焙 Diffuse 在深色衣物(背心/袜口/裤腿)与皮肤交界处可见"深褐色/暗红渗出斑块与条状污迹"(亮度 48~95 的过渡污染), 用户截图报修。
- 修复(脚本 `04纹理烘焙/scripts/texture_fix.py`, 已由 04_bake.py 在 Diffuse 保存后自动调用并 reload 携带进 blend/FBX):
  判据 = (亮度<95) 且 (非UV空白) 且 (不在衣物本体连通块内) 且 (距衣物本体 ≤18px) → 替换为就近皮肤色 + 2px 高斯过渡。
  关键坑: ①渗出紧贴衣物边缘, 窗口里皮肤占比≈50% → "皮肤占比高"类判据会全漏(实测只检出74px); ②必须整块排除衣物本体(连通块), 否则衣物最外圈被吃掉→边缘毛糙缺口(实测吃掉后渲染可见"锯齿/缺口"); ③统计"处理后残留"时别忘同口径排除衣物本体, 否则把整件衣服算进残留(数值爆表)。
- 实测(本模型): 检出 13045 px → 替换后残留 7901 px(残留=衣物边缘正常过渡带); 渲染前后差分仅 0.20%, 改动只沿"皮肤↔衣物交界"呈细线状, 脸部/衣物主体/大面积区域零改动; 处理前原图自动备份至 `_备份/`。
- 说明: 该处理是"稍微处理"口径 —— 只清紧贴衣物的渗出, 不碰面部五官(眉毛/头发)、不修大面积色块。


## 2026-09-17 · v2 网格引导异常斑清理(用户要求"用算法优化, 不能写死")
- 用户指出: 双脚趾端暗红/黑褐斑点(贴图实锤 ✓ 网格扫描), 短裤下摆附近暗色短线/白色细线(贴图上无强信号 → 疑几何).
- v2 算法(脚本 `texture_fix.py::fix_diffuse_mesh_guided`, 04_bake.py 中在 v1 之后自动跑, 迭代两遍):
  · 面级颜色(UV重心采样) → 3D 邻域(半径=最近邻中位距×4, 自动)中位差 dev;
  · 阈值 = max(4×(1.4826×MAD), |dev|的P99.5) —— 全部由模型数据推导, 无固定数值;
  · 只抓"偏暗"离群; 簇切分(贪心, 3D直径 ≤ 模型高度2.5%) → 面数上限 0.15%×N;
  · 保护: bbox 高度 80% 以上(头部/五官)不处理; 簇自身颜色须偏离"皮肤色域"(Mahalanobis, 由亮暖色面推导);
  · 邻域需含足量皮肤样面(≥3 且 ≥8%), 替换色 = 这些皮肤样面的颜色中位; UV 三角形光栅填充 + 2px 过渡.
- 实测(本模型): 44 簇/344 面/2986 像素(第1遍) + 301 面(第2遍); 双脚趾/双手/肩带边均有覆盖; 脚部残留离群 141→13; 头部五官零改动.
- 已知边界: ①右脚趾"畸形"= 网格几何问题(非贴图, 需几何工序另议); ②贴图上无信号的线条(如疑似下摆折缝)不在本步范围.
- 关键坑: ①固定"皮肤占比"判据在衣物边缘全部漏检(渗出紧贴边界, 窗口半暗); ②邻域判据必须容许"斑点在趾缝/衣边旁"的混合邻域, 用皮肤样面子集中位色替换; ③大簇不能整簇丢弃, 要切分; ④迭代两遍显著提升残余清除率.
