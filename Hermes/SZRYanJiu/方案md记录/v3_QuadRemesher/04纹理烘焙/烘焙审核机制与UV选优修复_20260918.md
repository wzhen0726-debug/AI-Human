## 一、04 烘焙审核机制（`scripts/bake_qa.py` + `04_bake.py` 集成）

**三项指标（全部无量纲 / 数据自参照）：**

| 指标 | 定义 | 含义 |
|---|---|---|
| 未填充 unfilled | 网格UV采样点(每面中心+首角)处贴图像素 alpha<0.5（无alpha则判纯黑）的占比 | 烘"空洞/没盖到"的直接度量 |
| 脏块 dirty | 8px块中位色 vs 3×3邻域中位 的离群块占比，阈值=全局 MAD×6（由数据推导） | "脏块"代理量（衣物纹理细节会抬底噪，仅用于轮次间相对比较）|
| 密度CV cv | 每面 纹素密度(UV面积/3D面积) 的 std/中位 | 与 03UV 同口径（越小越均匀）|

**轮次与择优：**
- 边距阶梯 = 既有基准(16px) × [1, 1.5, 0.6]（相对量，非写死）；
- 每轮：烘焙→存临时件→**同一套贴图处理**(溢出+离群清理)→测量；
- 择优 = 字典序 (unfilled, dirty, cv) 最小者（**不用权重常数**）；
- 双零（无空洞无脏块）早停；选定轮复制为正式文件；临时件清理；贴图处理失败不阻断。

**本轮实测**：m16: 0.07%,13.67%,0.112 / **m24: 0.03%,13.56%,0.112 ✓选中** / m10: 0.12%,13.53%,0.112。

## 二、03 自动UV 择优缺陷（脏块真正的源头）

**事故链还原（铁证在日志里）**：
1. 第2轮 66°+光顺 三项比值 = 0.010 / 0.912 / **1.002** → 对比 `岛数比≤1.000` 严格判据 → **判"不过"**（471/470，差0.2%被刀锋卡掉）；
2. 5轮内无候选全过 → 触发 fallback：`min(key=(废料比, -利用率))` → 选中第3轮 89°（废料0.004最小）——**其密度比 1.81、CV 0.215**；
3. 全链重跑 → 04 在密度两倍不均的UV上烘焙 → 用户看到的脏块/拉伸条纹。

**修复**（03_auto_uv.py）：
- `passes()` 加 `_TOL = 0.01`（1% 数值容差，相对量）：数值抖动不再制造伪违约；
- 新增 `viol()` = 三项比值超出1的部分之和；fallback 与复测排序改为 **(违约度 → 废料比 → 利用率)**；
- 比值打印 2→3 位小数（刀锋问题可视化）。

**修复后实测**：第2轮 0.010/0.912/1.002 **✓通过** → 选中 66°+光顺+CONCAVE，U=39.3%，CV=0.109（+8.1pp，全部指标与 09-17 验证轮一致）。

## 六、复检发现的二次问题：边距与清理半径脱钩（已修）

渲染复检：**皮肤本体（面/颈/胸/肩）脏块全部消失 ✓**；但背心领口/肩带边缘出现锯齿状深色脏边 ✗。
**根因**：烘焙 margin 从 16 提到 24 后，贴图处理 `fix_diffuse_png(reach_px=18)` 的清理半径**没跟着变**（18px 是按旧 margin 16 调过的），渗出带 24px 超出半径 → 外圈残留。
**修复**：04 调用改为 `reach_px = 本轮margin + 4`（4px=过渡保护；基数=实际烘焙设置，活参数）。
**修复后实测**：各轮溢出清除 43.7% / 51.4% / 35.7%（此前被半径截断）；深色污染环消失，皮肤侧全部干净 ✓；渲染残余的衣物边缘"锯齿"= **低模几何边在 4K 近距下的正常多边形棱角**（非贴图缺陷，正常视距无感）。
**教训**：任何"按边距膨胀"的产物清理，其作用半径必须与边距同源，改一个必须同步另一个。
