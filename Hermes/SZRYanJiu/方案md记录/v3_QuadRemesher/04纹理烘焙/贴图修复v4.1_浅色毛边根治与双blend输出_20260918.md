## 一、归因方法

利用每轮贴图处理自动保留的快照（`_备份/<时间>_04diffuse_处理前|v2前/`），对本轮(r2)取五段：
raw → v1_pass1后 → v1_pass2后 → v2a后 → final，逐段统计"衣物像素(lum<48)→变亮(>90)"的数量：

```
raw: 0 → v1_pass1: +412 → v1_pass2: +13 → v2a: +2883 → v2b: +2784 = 6,092px
```

**结论：浅色毛边 93% 由 v2 造成** ✓（v2 把衣物边缘面替换成肤色）。

## 二、修复（texture_fix.py）

```
v2 禁吃衣物守卫（在计算替换色之前）:
  _cl = lum(簇自身色中位);  if _cl < 55: skip          # 衣物级深色=织物本身
  邻域深色面占比 = #{lum<48}/#邻域;  if ≥0.25: skip    # 衣物边缘的簇
v1 边缘守卫: 候选像素 7px 窗内深色占比 ≥50% → 不替换（那是衣物边缘自身）
```
