## 关键证据链

1. **排除高模/贴图替换**：`04_bake.py` 中 `01_original_tex_fixed.png` 不存在 → 使用高模自带贴图（日志："使用高模自带贴图: 3d模型写实人像_basecolor (8192x8192)"）✗；且源高模渲染该处=干净 ✗。
2. **射线配置 A/B 试验（当时不敏感✗）**：8mm(笼20mm) → 全黑（射线够不到表面 ✗，反证 S2A 语义=从 cagе 起点向内）；27mm=(20+7) 与 101mm 差异仅 0.09% 纹理像素 ✗ —— 彼时被折叠掩盖 ✗。
3. **折叠铁证**：`uv.select_overlap` 原检测=**437 面**；打包器换 CONVEX/AABB/各 margin_method 均无效（非岛间重叠 ✗）；全网格 unwrap 整体崩塌（U=0% ✗）；正确做法=**局部切出折叠区重展**（等价"折痕处切缝"）✓。
4. **射线铁证（折叠修复后）**：残余点全部指向后肩 (0.139,0.059,1.501) 处 face 38882 等，UV (0.350,0.684) 与高模源的映射正常、无重叠（同texel面数=0✓），但 texel=75 暗而源干净 → 射线在衣物覆盖处从笼点打到衣物 ✗；改为 6mm/14mm 配对后 texel 稳定为皮肤色 ✓。
5. **最终视觉**：同相机三联（旧缺陷|新未调整|新已调整）→ 新两版皮肤干净，仅剩背心边缘自然边界线 ✓。

## 教训（供 skill）

- **仅查"面积均匀度/岛数/浪费"的 UV 判据对"岛内自折叠"完全盲** —— 必须加 `uv.select_overlap` 维度的硬门槛 ✗。
- **投影式 smart_project 对环状/长条区域必生折叠**，与角度阈值弱相关（实测 25°~89° 各角度 37~1709 面 ✗ 无角度能天然清零 ✗）→ 修复只能"局部重展" ✗。
- **S2A 烘焙 cage 与 ray 必须按语义配对**：ray ≥ cage + 低↔高实测偏差余量；cage 必须小于"皮肤到覆盖物间距"，否则射线从覆盖物上方出发必先打到覆盖物 ✗。
- **修复后必须做密度归一（average_islands_scale）**，否则局部重展区的纹素密度与全布局不一致 → CV 指标爆表（实测 5815 ✗）。
- 视觉复核三联法（旧问题态|新未调整|新已调整，同相机同区域）+ "射线→UV→texel 归属"定位链 ✗ 是定案利器 ✓。
