**最终验证**: L/R 双侧 0 开放边 / 0 非流形边，眼窝凹 23.5mm 方向正确，法线全朝 -Y（朝眼球）

## 一、问题现象

用户 GUI 验收发现眼窝是"破面"。渲染表现为：
- 碗面放射状三角扇（星爆纹）
- 手风琴式明暗条纹（面片交叉翻折）
- 碗口锯齿状尖刺
- 左右两眼同病

## 二、诊断过程（含所有失败的假设）

### 定量诊断先行
输入文件 `01_highpoly_repair.blend` 眼区检查：**0 开放边 / 0 非流形 / 0 重复顶点** → 输入干净，破面是我自己的流程产生的。

### 逐个排除的假设（都试过错的）
| # | 假设 | 验证结果 | 结论 |
|---|---|---|---|
| 1 | 碗面环序错位（拓扑行走序 vs 角度序方向相反 → quad 交叉） | 改了环序，条纹仍在 | ❌ 不是唯一根因 |
| 2 | 内圈"均匀角度重采样"与 ring0 真实角度不一致 → quad 扭转 | 改同顶点同角度收缩，条纹仍在 | ❌ 不是唯一根因 |

### 关键定量证据
- 删面后单独检查：**干净单环 70 顶点，0 杂环**（洪泛删面正确时）
- 但旧版封碗（角度排序）后：出现 45 条开放边 / 5 个断环 → 证明封碗环节引入破面
- 碗区顶点法线：孤立碗分离后 3943/12962 面朝内、1792 朝侧 → 法线混乱

## 三、最终修复方案（v12，全部生效）

### 1. 洪泛填充删面（替代面心判断）
从眼中心最近面（**3D 距离**，xz 最近会选到后脑勺）BFS 生长，只收录面心在轮廓内且 y<y_cut 的邻面 → 删区必连通成**单环**，无孤岛。

### 2. 拓扑行走序找边界环（不排序！）
沿开放边邻接走环（`adj` 图 DFS），保持网格原有拓扑顺序。**禁止 atan2 角度排序**——那会破坏拓扑序导致 quad 跨越。

### 3. ring0 松弛去锯齿（3 次 Laplace）
`v.co = v.co*0.5 + (prev+next)*0.25`，3 次。顶点与皮肤共享，移动它同时平滑洞口边缘。这是消除碗底 sliver 非流形边的关键。

### 4. 球面 8 圈收缩 + 共享极点三角扇封底
- 8 圈 cos 球面剖面收缩（口沿缓、碗底快收）
- 末环连到**单个共享 pole 顶点**（经典 UV 球极点拓扑，每条边恰好 2 面，构造上流形）
- **不用 ngon 封口**（三角化出碎片）、**不用 pointmerge**（碗底重复面）——两者都实测留非流形边
- smooth shading 与皮肤一致

### 5. 法线校正
碗面法线统一朝 -Y（朝眼球），fix_socket_normals 局部翻转，不全局重算（历史教训：全局 Shift+N 翻过洞边缘）。

### 6. sliver 溶解（2026-08-07 v13-v16，ad-hoc 验证抓到的缺陷）
口沿有 <0.5mm² 的皮肤碎片面（法线乱，锯齿尖刺根因）：
- `make_eye_socket` 末尾溶解**严格内部** sliver（L 698 / R 592 个）
- `make_eye_cup` 封碗后溶解**封碗后才变内部**的反向 rim sliver（L 128 / R 116 个）
- 两个坑：
  - **法线陈旧**：`update_edit_mesh` 后 `f.normal` 是旧值，必须先 `bm.normal_update()` 再按法线过滤，否则反向面逃过检查（3 个 sliver 靠旧法线漏掉）
  - **zone 判据**：3 个 sliver 在眼窝 zone 内但在眼睑 polygon **外**，`point_in_polygon` 判据漏掉，fix_socket_normals 补 zone 判据（眼中心 22mm xz 半径 + y∈[-0.116,-0.080] 深度带）

## 四、失败尝试的教训（避免重蹈）
1. **remove_doubles 焊接 ring0 顶点**：实测让非流形 0→10（把 ring0 误并入皮肤）。ring0 本就与皮肤共享，绝不能焊。
2. **ngon 封口**：大 ngon 三角化出放射扇 + 碎片。
3. **pointmerge 末环**：碗底留重复面 → 1 非流形边。
4. **xz 最近面选种子**：头是封闭壳，同 x/z 有前后两层，必须用 3D 距离。
