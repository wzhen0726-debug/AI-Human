## 一、根因链（为什么"每轮打点不同就会复发"）

旧路径（v86 及之前）：
```
每个外圈顶点 → 在手描轮廓点集上取"最近邻点"的弧长参数
  → 沿外圈顺序解绕(±total/2 折返)
  → 强制单调 uu[t] ≥ uu[t-1] + total/K*0.5   ← 角尖处跳变后这一步把序列推过头
  → 取模 mod total
  → 内环点 = 轮廓上该参数的插值点
```
杏仁形角尖是**高曲率+局部半径≪带宽**的区域：外圈点在此处"最近邻"会集体吸附到同一点，
解绕后的序列出现**小回退**；强制单调把小回退一律向前推，**累计超出**后在取模处**回头覆盖**
已用过的轮廓段 → 内环折线**自交** → 桥接出的条带面互相穿插（用户看到的"重叠乱面"）。
02QR 对自交区重网格 → 放大为退化细长面与硬折线。**每次打点形状略变，触发与否随机** ——
这正是"半自动打点每轮都不一样、问题时有时无"的机制解释。

## 二、修复（`socket_ops.py` `rebuild_rim_band` ③段）

新路径：
```
以轮廓质心为极点，把【外圈】按环序解绕极角
  → 对每个外圈顶点求"目标角 = 轮廓首点角 + mod(θ_v − θ0, 2π)"
  → 内环点 = 轮廓折线上【同一极角】的插值点（含深度 CY）
```
- **星形环性质**："同角度 = 同轮廓点" → 配对天然单调、**无交叉、无双覆盖**（结构性保证，不依赖参数调优）；
- 内外环绕向自动对齐（反向则反转外圈）；轮廓点序与角度序不一致时按角重排；
- **形状与深度严格取自手描轮廓**（CP/CY 不变），只改采样位置 —— 与 v86 同一哲学；
- 同时内建**交叉自检**：内外环折线在 XZ 平面线段交叉数（应=0，>0=乱面前兆），直接印进日志；
- v86 的"间距正则化 + 强制单调"随之移除（其存在的理由是旧的最近邻配对，已不需要）。

## 三、判据盲区修复（QA 扩展）

- `_rim_qa` 增加 **针状(<5°)占比**（原只有 小角<15% / 长条）→ 择优分 = 小角+长条+针状；早停条件同步加入；
  打印新增"针状"列（band vs 参考带）。
- 教训（第③次踩）：**修复判据和验证判据同盲区 = 自证陷阱**。本轮显式引入两个**独立于重建逻辑**的检查：
  ① 交叉自检（线段求交，直读几何事实）；② 针状(<5°)（更锐的独立阈值）。
