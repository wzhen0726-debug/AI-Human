# 眼窝碗形重做方案：圆锥封口 → 平滑半椭圆碗

**状态**: 📐 方案设计（2026-08-06）
**取代**: `seal_socket_bottom()` 的圆锥封口（已废弃，效果差）

---

## 一、当前圆锥版为什么差

`seal_socket_bottom()` 把所有三角面连到**同一个碗底顶点**：

1. **尖底圆锥**：N 个三角形共享一个尖顶，是个锥体不是碗，视觉尖锐；
2. **零曲率**：开口边界环到尖顶之间是直线连线，三角形是平面，整个内壁由一圈圈平直三角带组成 → **瓦楞状平直表面**；
3. **锯齿放大**：开口边界是删面留下的离散锯齿环，直接连顶点把锯齿一路带到尖顶。

本质：这是"封洞"的应急做法，不是"做眼窝"。解剖学眼窝是**平滑的半椭圆凹碗**。

## 二、目标形态

**半椭圆旋转面（lathe surface）**：以椭圆开口为口沿，向内（+Y）凹陷成一个半球/半椭球内壁。

- 口沿：贴合现有开口边界（椭圆 26×18mm）
- 剖面：从口沿到碗底是一条**平滑的圆弧/椭圆弧**，不是直线
- 碗底：是一个**收窄的圆形/椭圆形区域**（不是尖点），深度约 12-15mm
- 整体：连续光滑曲率，无棱线、无瓦楞

## 三、算法：参数化半椭圆网格

不连接现有锯齿环，而是**新生成一个干净的参数化碗面**，再把口沿焊接到开口边界。

### 网格结构（经线 M × 纬线 N）

- **经线** M=32（绕碗口一圈 32 段，足够平滑）
- **纬线** N=8（从口沿到碗底 8 圈，控制深度渐变）

### 顶点参数方程

口沿在 x-z 平面是椭圆（半轴 rx=HOLE_RX, rz=HOLE_RZ），碗向内凹陷方向是 +Y。

对第 j 圈（j=0 口沿 … j=N 碗底）、第 i 段（i=0..M-1，角度 θ=2πi/M）：

```
# 归一化深度参数 t = j/N ∈ [0,1], 0=口沿 1=碗底
t = j / N

# 该圈的椭圆半径缩放: 口沿1.0 → 碗底收缩
# 用余弦收缩保证口沿切线平滑(碗底不尖)
scale(t) = cos(t * π/2)          # t=0→1, t=1→0 (半球剖面)

# 该圈的 x/z (椭圆)
x = cx + rx * scale(t) * cos(θ)
z = cz + rz * scale(t) * sin(θ)

# 该圈的凹陷深度 y: 用正弦让剖面是圆弧而非直线
# y_depth(t) = max_depth * sin(t * π/2)  → 口沿0 碗底最深
y = rim_y + max_depth * sin(t * π/2)
```

- `scale(t)=cos(t·π/2)`：口沿 1.0，碗底 0 → 剖面是 1/4 椭圆弧，碗底自然收成一点但**切线连续不尖**（半球底）
- `y=sin(t·π/2)`：深度从 0 平滑增到 max_depth，剖面曲率连续
- 碗底 j=N 圈所有顶点 scale=0 重合于 (cx, rim_y+max_depth, cz) —— 这是**半球底部的极点**，曲率连续（像球面南极），不是尖锥

> 关键区别：圆锥是"环→点直线连"，本方案是"环→按椭圆弧逐圈收缩"，剖面是圆弧，所以是碗不是锥。

### 面片

- 相邻两圈（j, j+1）× 相邻两段（i, i+1）构成 quad（梯形），碗底极点圈用三角扇
- 全部朝向眼窝外侧（朝眼球，-Y）

### 与开口的缝合

1. 生成的碗口沿第 0 圈顶点（32个），投影/吸附到最近的开口边界环顶点（保证无缝）
2. 或直接 replace：删面后，用碗口沿作为新的边界环，与周围面 bridge 连接
3. 法线朝外（朝眼球），与原表面一致

## 四、参数

| 参数 | 值 | 说明 |
|---|---|---|
| M 经线段数 | 32 | 碗口平滑度 |
| N 纬线圈数 | 8 | 深度方向平滑度 |
| max_depth | 12mm | 碗最深（比压凹10mm略深，容纳眼球后极） |
| 口沿 rx/rz | HOLE_RX/HOLE_RZ | 与开孔一致 |

## 五、验证

1. 渲染碗内壁（从眼洞往内看）：应是平滑凹面，无棱线、无瓦楞
2. 剖面图（过眼球中心横切）：凹陷曲线是连续圆弧，不是折线
3. 放入眼球：眼球后极不穿出碗底，碗内壁在眼球后方形成封闭背景
4. 法线检查：碗内壁法线全部朝眼球方向（-Y），无红色背面
