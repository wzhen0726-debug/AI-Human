## 一、碗结构问题的诊断过程

用户口径(verbatim): "没补洞的时候没问题, 你补了洞, 结构就错了…不要按眼珠去做眼窝, 就按昨天我那个方案直接做眼窝, 复刻我的做法, 不去管眼珠, 然后眼窝的深度, 你自己去算好"。

**诊断方法**: 用户手调参考碗(151k版, 仅改屏幕右侧一只眼)是"方法"的唯一权威物证 →
- 用 **BFS 图距分层**(从 rim 出发按网格边数分层, 一圈=一层)破解其环结构:
  **8 环 × 47 顶点 + 1 极点**, 顶点顺序≠环顺序(是手工重建的), 只有拓扑法能可靠分环;
- 逐环实测发现规律**精确到惊人**:
  1. **深度步进 +3.13mm × 7 全等**(= Ctrl+R 均匀分段的特征);
  2. **波动线性衰减**: 各环 y 波动 = (8-k)/8 × rim波动, 实测 4.21→3.61→3.01→2.40→1.80→1.20→0.60→**0.00**;
  3. **最深环全平**: std=0.00, 跨度=0.00(Y轴打平);
  4. **缩放线性步进** ≈0.102/环;
  5. **极点比最深环再深 +2.17mm**(= "再挤出一点距离合并到中心")。
- 即:**纯线性插值 y_k_i = (1−t_k)·rim_y_i + t_k·y_deep, t_k = k/8** —— 与用户描述("先做Y轴打平的眼窝心环, 中间加分段")完全一致。

**旧版错在**: ① 深度来自眼球/旧参考件(不该看眼珠); ② 叠加非线性剖面+λ衰减(拍脑袋拟合); ③ 最深环不平(4.5mm斜跨)。

## 二、v19 实现(全程序化)

```
r_ref      = rim 顶点到眼心的 XZ 距离中位数        # 开口等效半径, 现场测量
D          = 2.04 × r_ref                          # 碗深(rim平面→眼窝心平面)
步进        = 0.255 × r_ref                         # 决定环密度
n          = clamp(round(D/步进), 5, 12)            # 实测=8
最深环比     = 0.152                                # 无量纲
y_k_i      = (1−t_k)·rim_y_i + t_k·y_deep          # t_k=k/n, 末环恰好全平
极点         = y_deep + 0.176×r_ref                 # 再挤一点
```
五组系数均由参考碗实测反推, 全部无量纲、随模型尺寸随动; 两只眼各自按自己的 rim 计算。
已删除: 眼球载入/半径拟合/旧参考件射线采样/非线性剖面/二次打平块。

## 六、方法论备注(下次遇到"复刻用户手工做法")

1. 用户手调文件是**唯一权威物证**, 先反推其结构(拓扑级); 
2. 环识别用 **BFS 图距**(顶点顺序不可信); 
3. 把规律写成**无量纲比值**, 再用**逐环数值**验收(≤0.1mm 量级); 
4. 拟合出来的常数只能作为**初值**, 最终实现必须"从几何算出来"。
