# 简化版方案技术缺陷分析报告

> 基于修正版WBS（Quad Remesher + Mixamo，不做对称/不去衣/不分离眼球，30万面，6-8周）的深度技术调研

## 一、方案概述

| 维度 | 内容 |
|------|------|
| 输入 | 2-4张照片→AI生成高模(.glb) |
| 处理 | 几何修复→黏连修复→Quad Remesher(30万面)→UV+烘焙→Mixamo绑定 |
| 输出 | 含骨骼+权重+材质的GLB，约30万面 |
| 特点 | 不做对称化、不去衣服头发、不分离眼球、不装控制器 |
| 工期 | 6-8周 |

## 二、核心风险点总览

| # | 风险 | 等级 | 可解决？ | 对工期影响 |
|---|------|------|------|-----------|
| 1 | Quad Remesher面数30万+Mixamo兼容 | 🟡 | ⚠️需调整 | +0.5周 |
| 2 | 黏连检测与修复 | 🟡 | ✅可实现 | 0 |
| 3 | Smart UV Project不可用于生产 | 🔴 | ❌需手动 | +1-2周 |
| 4 | 眼球保留导致烘焙错误 | 🔴 | ❌方案矛盾 | +0.5-1周 |
| 5 | 衣服烘焙干扰 | 🟡 | ✅可解决 | +0.5周 |
| 6 | 宽松衣服绑定权重差 | 🟡 | ⚠️需修正 | +0.5-1周 |

| 8 | Normal贴图轮廓问题 | 🟢 | ✅可接受 | 0 |

## 三、各风险点详细分析

### 3.1 Quad Remesher面数30万+Mixamo兼容 🟡

**调研结论**：30万面可行，但需调整。

- Quad Remesher Adaptive Size模式能自动在高曲率区域（褶皱、面部）分配更高面密度
- 但**30万面处于Mixamo边界值**（社区经验25-50万面可上传），建议**降到20-25万面**确保稳定性
- 关闭Symmetry X后轻微不对称可能影响Mixamo绑定精度，建议**恢复Symmetry X**（如果衣服差异不大）或重拓扑后做少量对称修正
- 混合模型（含衣服）Quad Remesher质量可接受，Material ID可引导布线

**建议**：目标面数降到20-25万面，恢复Symmetry X。如衣服差异大保留不对称。

### 3.2 黏连检测与修复 🟡

**调研结论**：技术可行，需要迭代策略。

- MediaPipe Holistic 33个关键点检测在AI 3D渲染图上PCK@0.2预计85-92%（写实风格），足够做粗定位
- 最小距离算法参考BVH加速+三角面片距离查询，标准方法
- 修复方案：沿法线小幅位移→Laplacian变形+权重衰减平滑→Taubin平滑避免收缩
- **风险**：修复后产生新自相交概率30-50%，必须用迭代小步长+每步验证的策略
- 修复必须在Quad Remesher之前（Remesher要求几何正确）

**建议**：拍照时双腿分开肩宽预防黏连，降低修复难度。算法用约束优化代替纯几何位移。

### 3.3 Smart UV Project不可用于生产 🔴

**调研结论**：这是最重要的风险点，需要大量手动工作。

Smart UV Project在所有30万面复杂模型上有以下问题：
- 接缝位置不可控（可能在面部前方、脖子正面）
- UV岛碎片化（产生大量细小岛，纹理绘制困难）
- 高曲率区域拉伸明显（耳朵、鼻子、手指）
- **无法用于生产级角色，必须手动标记接缝+Unwrap**

**影响**：30万面不对称模型的UV展开需要熟练的UV技能+1-2周时间。文档中只分配了0.5周，严重不足。

**建议**：增加UV展开工期到1.5-2周，或降低标准接受Smart UV Project结果（但质量差）。

### 3.4 眼球保留导致烘焙错误 🔴

**调研结论**：方案存在内部矛盾。

WBS说"眼球保留在头部网格内"不分离。但烘焙时：
- 高模眼球是**球状凸起几何体**，低模如果也保留眼球=低模也有球状凸起
- 如果低模**不保留眼球**（眼眶平滑过渡），烘焙投射光线会从平滑眼眶表面射向高模眼球球体，**命中错误位置**→眼部纹理错乱
- 烘焙必须分离高模的眼球，但WBS说"眼球保留在网格内"——**矛盾**

**唯一正确方案**：
1. 烘焙前：将高模眼球**单独分离为独立对象**
2. 烘焙身体：只选身体高模作为源（排除眼球）
3. 烘焙眼球：单独烘焙眼球贴图
4. 低模保留眼球几何体

**影响**：虽然WBS删除了"眼球分离"任务，但烘焙阶段**必须分离**，这会增加0.5-1周。

**建议**：恢复眼球分离步骤，或接受眼部纹理质量损失。
