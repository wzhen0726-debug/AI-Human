# 数字人模型AI自动化处理流程：技术方案（全自动化版v3）

> 全自动化管线，工期8-10周。修正：UV用自动边缘角度接缝+标准Unwrap。

## 一、项目目标

| 项目 | 内容 |
|-----|------|
| 输入 | 2-4张照片（T-pose，紧身衣，正面+侧面+背面） |
| 输出 | 含骨骼+权重+材质的GLB，20-25万面 |
| 方案 | AI高模→修复→黏连修复→Quad Remesher→自动UV→烘焙→Mixamo绑定 |
| 特点 | 全自动化，不做对称/不去衣/不分离眼球(烘焙时仅分离) |
| 工期 | 8-10周 |

## 二、流程总览

```
拍照(紧身衣+T-pose) → AI高模 → 几何修复 → 黏连修复
→ Quad Remesher(20-25万面,Symmetry X开启)
→ 自动UV(边缘角度接缝+对称轴接缝+Unwrap+Pack)
→ 眼球分离烘焙 → 合并 → Mixamo绑定 → 权重修复 → GLB
```

## 三、各阶段详述

### 阶段1：高模获取（1.5周）
拍照规范：**必须紧身衣/泳衣**，双腿肩宽，T-pose。AI生成全身高模GLB。

### 阶段2：几何修复（1.5周）
破洞填补+bmesh清理+Voxel Remesh+Laplacian Smooth。

### 阶段3：黏连修复（1.5周）
MediaPipe Holistic关键点→大腿内侧黏连检测→法线推开修复。

### 阶段4：Quad Remesher（1.5周）
- 面数：20-25万面
- Symmetry X：开启（紧身衣对称）
- Preserve Sharp Edges：开启
- Adaptive Size：开启

### 阶段5：自动UV展开（0.5-1周）⭐全自动化方案

| 步骤 | 方法 | 命令/API |
|------|------|------|
| 自动标记接缝 | 边缘角度>55°标记为接缝 | `bpy.ops.mesh.edges_select_sharp(sharpness=0.96)` + `mark_seam()` |
| 对称轴接缝 | X=0处补充接缝确保左右UV对称 | 选择X≈0的边→mark_seam |
| 展开 | Angle Based Unwrap | `bpy.ops.uv.unwrap(method='ANGLE_BASED')` |
| 自动打包 | pack_islands | `bpy.ops.uv.pack_islands(rotate=True)` |
| 均衡密度 | average_islands_scale | `bpy.ops.uv.average_islands_scale()` |

**优势**：纯Blender API，零外部依赖，100%自动化，质量远超Smart UV Project。

### 阶段6：纹理烘焙（1.5周）
眼球分离→身体烘焙(Selected to Active, Cage, Diffuse+Normal)→眼球合并。

### 阶段7：绑定与权重修复（1.5周）
Mixamo绑定(20-25万面)→权重修复(跨腿+独占平滑+全局平滑)。

### 阶段8：GLB导出（0.5周）

### 阶段9：Pipeline集成（2周）

## 四、关键修正

| 原WBS | 问题 | 本方案 |
|------|------|------|
| Smart UV Project | 接缝不可控+无对称性 | 自动边缘角度接缝+标准Unwrap |
| UV展开0.5周 | 手动UV时间不够 | 自动方案0.5-1周 |
| 30万面 | Mixamo边界 | 20-25万面 |
| 关闭Symmetry X | 绑定精度差 | 紧身衣恢复对称 |
| 删除眼球分离 | 烘焙矛盾 | 恢复分离(仅烘焙时) |
| 6-8周 | 未考虑修正 | 8-10周 |

## 五、风险

| 风险 | 等级 | 应对 |
|------|------|------|
| Mixamo绑定失败 | 中 | 切Auto-Rig Pro |
| 黏连修复不彻底 | 中 | 拍照预防+迭代修复 |
| 烘焙纹理质量差 | 中 | 分离高模+Cage |
| 自动UV接缝可见 | 低 | 非AAA可接受，接缝在隐藏位置(边缘角度>55°) |
| 宽松衣穿模 | 中 | 拍照穿紧身衣预防 |
