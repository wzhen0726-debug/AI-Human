# Mixamo标准骨骼绑定方案 v3

## 一、概述

从AI生成高模 → Quad Remesher低模 → 自动骨骼绑定全流程。

**核心设计原则**：算法不硬编码任何人体比例参数，通过mesh几何的宽度曲线+密度分析自动检测关节位置，适配任意体型（瘦子/胖子/男性/女性）。

## 二、Mixamo标准骨骼结构（20骨骼）

```
Hips (root)
├── Spine → Spine1 → Spine2
│   ├── Neck → Head
│   ├── LeftShoulder → LeftArm → LeftForeArm → LeftHand
│   └── RightShoulder → RightArm → RightForeArm → RightHand
├── LeftUpLeg → LeftLeg → LeftFoot → LeftToe
└── RightUpLeg → RightLeg → RightFoot → RightToe
```

骨骼命名完全遵循Mixamo标准，可直接用于Mixamo自动绑定。

## 三、关节位置检测算法

### 3.1 胯部位置（Hips）

**方法**：在Z轴[25%, 55%]范围内扫描X轴宽度曲线，找**最宽点**。

- 对每个Z高度取该高度的所有顶点，计算X跨距= max(X) - min(X)
- 选择X跨距最大的Z作为Hips高度
- 对胖子：胯部宽度更突出，算法自动找到更大跨距
- 对女人：腰窝/X跨距比例不同，但最宽点逻辑不变

### 3.2 手臂分离位置（Shoulder）

**方法**：在Z轴[65%, 88%]范围内扫描**max(X)**，找峰值。

- T-pose模型的手臂在肩高处X值最大
- 对A-pose模型：手臂下垂，max(X)峰值会下移，但仍在手臂高点
- 适用任意臂展角度

### 3.3 肩关节X位置（Shoulder Joint）

**方法**：在手臂分离Z高度做X方向**密度峰值分析**。

- 以0.005m步长扫描 X∈[0.02, max_X * 0.35]
- 统计每个X位置的顶点数量
- 选择顶点数量最多的X → 肩关节（躯干与手臂连接处密度最高）

### 3.4 手腕位置（Wrist）

**方法**：在手臂Z高度的X方向做**密度谷值分析**。

- 扫描 X∈[max_X * 0.7, max_X * 0.95]
- 统计每个X位置的顶点数量
- 选择顶点数量最少但>10的X → 手腕（手臂最细处）

### 3.5 膝盖位置（Knee）

**方法**：Z轴固定0.22*H（膝盖高度），X从mesh几何取该高度的重心。

### 3.6 脚踝位置（Ankle）

**方法**：Z轴固定0.05*H（脚踝高度），X从mesh几何取该高度的重心。

## 四、问题与解决方案记录

### Q0: ARP对T-pose模型生成错位骨架 → 方案1抢救成功 (2026-08-27)
**现象**：用户17打点正确、AI guess_markers准确，但go_detect产出的变形骨架手臂下垂(A-pose)、整体偏移。
**实测数据**：参考骨arm_ref.l head=(0.229,0.068,1.435)正确落在标记点，但最终变形骨shoulder.l z=1.308、hand.l z=1.148(比标记低29cm)。
**验证**：完整官方流程(guess_markers→go_detect一气呵成)与分步流程结果**完全相同** → 根因不在流程编排，在go_detect内部。
**根因**：ARP模板骨架是A-pose(手臂下垂)，对T-pose模型(手臂水平)无法自动修正姿势。预设仅DEFAULT/UE4/UE5(全A-pose)，无Mixamo/T-pose预设。
**抢救方案(成功)**：弃用go_detect生成的A-pose变形骨，改为提取ARP**参考骨架**(66根,位置全对=用户标记点,含30根手指参考骨)重建最终骨架。
**步骤**：
1. extract_refs.py: 从参考骨提取55根骨,映射为Mixamo命名(含手指15根/手,脚趾)
2. align_refs_roll.py: 复刻方案A已验证做法 — tail方向=align_roll(Mixamo Z轴)
3. arp_walk_test.py: Mixamo行走动画验证
**验收结果**：55骨全部落在用户标记点(超标0), 行走测试通过(2794/3000顶点变形, 左手z=0.921自然摆臂, 右脚贴地0.244)。
**结论**：ARP参考骨架可用,手指需求满足。方案1成功。

### Q1: 骨骼比模型大2倍 → ARP无解
**现象**：ARP模板按180cm人体建rig，0.976m模型缩放0.5后骨骼变"长颈鹿"。
**根因**：ARP模板骨骼比例硬编码，缩放只改变整体大小不改比例。
**解决**：放弃ARP，从mesh几何直接手动创建骨骼。

### Q2: 手臂骨骼"反了"（从手指→身体）
**现象**：shoulder X=0.484（手臂末端），tail X=0.104（身体侧）——方向颠倒。
**根因**：band_extreme_x找到的是手臂最远端，关节位置逻辑错误。
**解决**：肩关节用密度峰值(X≈0.10)，腕部用密度谷值，手骨骼tail延伸到max_X。

### Q3: 胯部在脚踝（Z=0.050）
**现象**：analyze_limb_separation从Z=5%扫描，脚部分叉被误判为胯部。
**根因**：脚部X-spread > 0.15*W，低于阈值触发。
**解决**：改为找[25%, 55%]最宽X跨距，且从15%开始扫描跳过脚。

### Q4: 手臂偏低（Z=0.742 vs 实际0.780）
**现象**：arm_sep_z找到Z=0.742（臂展0.5*W处），但实际手臂在Z=0.780。
**根因**：X-width > 0.5*W在Z=0.742触发，但这是手臂开始变宽处，不是最大臂展处。
**解决**：改为扫描max(X)峰值，直接找到手臂最远端的Z高度。

### Q5: UV 3110个岛（碎片化）
**现象**：6672条接缝造成1个巨大岛(175K面) + 3089个1面碎片。
**根因**：战略接缝容差太宽，大量边被标记。
**解决**：收紧容差至0.003*W，目标降至~7条接缝（背中/腋窝/裆部/脖子/腰）。

## 五、管线流程

1. **repair**: 高模导入 + 旋转90° + 法线重算 → 34K面
2. **adhesion**: 34对面片粘合
3. **remesh**: Quad Remesher → 200K面
4. **uv**: 7条战略接缝 + Smart UV Unwrap
5. **bake**: Cage模式(0.3m) + 128采样 + 2K → 高模纹理投射到低模
6. **rig**: Mixamo标准骨骼 + 自动权重绑定
7. **export**: GLB（1 mesh + 1 armature + 0 empty）
