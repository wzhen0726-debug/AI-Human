## 二、各阶段技术要点

### 01 高模修复
- 做对：foot_score v3 朝向修复、Taubin 平滑、焊接必须早于UV。
- 做错：法线修复前烘焙 = 黑面（08-24 三次返工）；命门是面还 flat 时调 add 固化平直法线。
- 局部几何异常先诊断根因再修；胸口凸起是原始几何特征需雕刻平滑，不是法线问题。

### 01A 眼窝与眼球
- 眼窝定案：v48 inward_fillet（M形凸脊根因=倒角环外扩段，只内收不下沉）。
- 眼球定案：v4 解剖规律（角膜凸0.1mm/虹膜底+1.4mm），半自动微调面板。
- 用户GUI手动调→脚本定量反推解剖规律固化 = 审美定案最快路径。

### 02 QR 拓扑
- 输入必须焊接（remove_doubles 0.0001）+ 填开放边，否则 xremesh 卡死。
- SymAxis 关闭决策：纹理不对称导致烘焙错位。

### 03 UV / 04 烘焙
- 高面数上"边缘角度>55°标接缝"碎岛，已弃用；Smart UV Project 66°。
- 去黑面顺序：焊接(必须UV前)→清自定义法线→shade_smooth→bmesh标锐边(>30°)→最后add烘焙。
- cage_extrusion 0.01 + max_ray_distance 0.05 防衣服穿透见皮肤。

### 05 骨骼绑定（08-25~28 主战场，详见 05骨骼绑定_完整记录）
- **方案A**：骨骼朝向照抄 Mixamo 参考骨架实测世界轴 + 位置用用户点 = 静止姿态0.00°偏差。
- **ARP 对 T-pose 模型**：go_detect 变形骨必错，但参考骨架正确 → 提取参考骨重建（55骨含手指）。
- **只 align_roll，绝不改 tail**（改tail=关节全断；Mixamo重定向允许比例差）。
- **手指映射**：掌骨区归Hand骨（尾到中指指根），Finger1只用x1_ref禁并x1_base。
- **标记点**：官方命名 `_loc/_sym`、EMPTY SPHERE 0.012、右侧主点+左侧驱动器镜像、前视图正交。
- **Blender 5.x Slotted Action**：slot必须绑装fcurves的channelbag，否则动画静默不生效。
- **变形验证**：必须用 depsgraph evaluated mesh（原始mesh恒显示0变形）。
- 眼球绑定：只换算位置不换算旋转 = 瞳孔朝下；用完整矩阵换算。

## 三、Blender 5.1 API 高频坑

| 坑 | 正确写法 |
|---|---|
| `bpy.ops.object.add` 建在3D光标处 | 先 `scene.cursor.location=(0,0,0)` |
| `ShrinkwrapConstraint.wrap_method` | `shrinkwrap_type`，枚举 `NEAREST_SURFACE` |
| `mesh.vertices[::50]` 切片 | 不支持，按索引遍历 |
| `action.fcurves` | 5.x 不存在，用 `layers[].strips[].channelbags`（属性带s不可调用） |
| `ActionSlot.name` | 无此属性，用 `identifier`/`handle` |
| `scene.cursor_location` | `scene.cursor.location` |
| 后台 `-b` 模式 select_all 失效 | 用数据API `o.select_set` + 先 mode_set('OBJECT') |
| 插件噪音淹没print | 结果写文件而非靠 stdout |
