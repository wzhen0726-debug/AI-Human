## 一、核心战略：彻底放弃Wrap，接受QR拓扑

### 为什么放弃Wrap

- 头部v3.4：数值0.402mm但视觉质量差（耳朵/嘴唇/眼角扭曲+178自相交），不可用
- 身体：9轮尝试全部失败（Shrinkwrap/RBF/Affine/PROJECT/Surface Deform），根因是衣服嵌套
- Wrap需要密集锚点+无遮挡表面，AI高模不满足

### 为什么接受QR

- 90K面均匀quad，无非流形边，拓扑干净
- 对Mixamo自动绑定成功率极高
- 生成速度快，无需人工干预
- 缺点：UV展开质量差（但这是下一个问题，不是拓扑问题）

## 二、三阶段演进路线

### 阶段一：MVP暴力直通（当前，1个月内）

**目标**: 跑通全流程，证明"照片→GLB数字人"一键生成可行

**技术方案**:

```
Tripo高模(193万面) → 几何修复 → Quad Remesher(9万面)
→ Smart UV Project(66°, margin=0.03) → Bake(margin=16px)
→ Mixamo绑定 → GLB输出
```

**Smart UV 暴力投影**:
```python
bpy.ops.uv.smart_project(
    angle_limit=math.radians(66.0),
    island_margin=0.03,  # 关键：留间隙防烘焙黑边
    area_weight=0.0,
    correct_aspect=True,
    scale_to_bounds=False
)
```

**Bake防黑边**:
```python
bpy.context.scene.render.bake.margin = 16  # 像素向外扩张
```

**预期结果**: UV碎成~2000岛，但无重叠、间隙分明、烘焙不漏色

**局限性（需向领导说明）**:
- UV利用率低（碎片化+margin间隙）
- 无环形线，动画时关节拉扯
- 后期美术无法编辑（碎玻璃式UV）

### 阶段二：3D语义分割+ARAP Wrap（1-3个月）

**目标**: 解决4K/8K贴图的UV利用率和可编辑性

**核心思路**: 用AI分割识别"皮肤区域"和"衣服区域"，分级处理

```
Tripo高模 → 3D语义分割（AI识别皮肤/衣服区域）
→ 皮肤区域: Shrinkwrap吸附到MetaHuman
→ 衣服区域: ARAP姿态对齐（不做表面吸附）
→ 继承MetaHuman标准UV（完美对称、接缝在内侧）
```

**关键技术**:
- 3D语义分割：轻量级点云/网格分割模型（如SAM 3D开源变体）
- ARAP变形：保持局部刚性，避免RBF的膨胀问题
- 分级约束：皮肤区域严格吸附，衣服区域只对齐姿态

**预期收益**:
- 继承MetaHuman 32K工业级UV（利用率>90%）
- 人类画师可在Substance Painter中直接编辑
- 面部环形线保留，动画质量大幅提升

**风险**:
- 3D分割精度（宽松衣物边界模糊）
- ARAP求解速度（32K顶点实时性）

### 阶段三：参数化模型逆向拟合（终极形态，3-6个月）

**目标**: 摆脱对外部AI高模拓扑的依赖，实现从骨骼到皮肤的绝对掌控

**核心思路**: 把Tripo高模当作"3D扫描参考物"，用SMPL-X标准模型逆向拟合

```
Tripo高模(仅作参考) → SMPL-X参数化模型逆向优化(Non-Rigid ICP)
→ 体型参数(胖瘦/长短)自动匹配高模外轮廓
→ 衣服通过Displacement提取，生成独立Mesh
→ 输出: 完美拓扑+完美UV+精准骨骼权重
```

**关键技术**:
- SMPL-X模型：学术黄金标准，涵盖身体+手势+面部
- Non-Rigid ICP：迭代最近点非刚性配准，GPU加速
- Displacement提取：从高模表面提取衣服厚度差值

**预期收益**:
- 影视级完美拓扑和UV
- 自带精准骨骼权重，不会"手插进躯干"
- 可换装、可驱动超精细微表情

**风险**:
- 求解器开发复杂度高
- SMPL-X模型的授权问题（学术免费，商用需确认）

## 三、各阶段对比

| 维度 | 阶段一(MVP) | 阶段二(分割+ARAP) | 阶段三(SMPL-X) |
|------|-------------|-------------------|----------------|
| 拓扑来源 | Quad Remesher | MetaHuman Wrap | SMPL-X参数化 |
| UV质量 | 碎片化(~2000岛) | 工业级(32K标准UV) | 影视级 |
| UV利用率 | ~60-70% | >90% | >95% |
| 可编辑性 | ❌ 无法编辑 | ✅ 可编辑 | ✅ 完全可控 |
| 动画质量 | 关节拉扯 | 良好 | 影视级 |
| 开发周期 | 1周 | 1-3月 | 3-6月 |
| 技术风险 | 低 | 中 | 高 |
| 适用场景 | Demo/验证 | 商业产品 | 影视/8K |
