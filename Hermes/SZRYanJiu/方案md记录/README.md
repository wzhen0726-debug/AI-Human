## 关键结论

1. **头部 wrap (v3.4)**: MediaPipe 478点 + Procrustes + Shrinkwrap 4轮 + 锚定迭代 25轮 → 数值0.402mm/96.2%，但耳朵偏小/上唇扭曲/内眼角拉伸/鼻翼错位/颈部锯齿，**视觉质量不可用**
2. **身体 wrap**: ❌ 全部失败（路线随 v1 暂停） — 根因是 Tripo AI 高模含衣服嵌套 + 53.1% 法线反转，所有自动方法失效
3. **UV 展开**: QR 均匀 quad 网格 UV 展开质量差(≤4.5/10)，所有自动方案（Blender/RizomUV/xatlas）碎片化严重
4. **骨骼绑定**: 使用 Mixamo 标准（不用 Auto-Rig Pro），通过几何分析自动检测关节位置
5. **眼窝 (01A, 2026-08-21)**: v48 inward_fillet 定案。M形凸脊根因=倒角环外扩段；解法=只内收不下沉；完整性全绿
6. **眼球摆入 (01A, 2026-08-21)**: v4 解剖规律定位定案。角膜贴开口平面+虹膜底贴下睑；左右天然同步；半自动微调面板+中文颜色面板已做进管线
7. **QR拓扑 (02, 2026-08-21)**: 已用含眼窝高模重跑，14.3万面/100%quad/52秒
8. **03B 骨骼标准化 (05, 2026-09-17)**: **只对齐四肢47骨（不含肩）；肩/躯干/颈/头8骨保持原样** —— 实测证明这部分对齐=负优化（Mixamo 的脖子前倾是靠 Head 骨起点前移 31.4mm，非颈骨倾斜；强行扳直=头脸整块后拖30mm 五官变形；肩骨对齐=肩胛旋转致背沟+挺胸）
9. **眼区权重统一 (05, 2026-09-17)**: 眼睑/眼窝皮肤原为 Head0.91+Neck0.09，头颈相对运动时滞后3.9mm 致眼球"爆出"观感 → 眼区权重统一为 Head 主导（核心纯Head），滞后→0.000000mm
10. **04 贴图处理 (2026-09-17)**: 烘焙后自动两步处理 —— ①边界渗出 ②网格引导统计离群；全部阈值由模型自身尺度推导（不写死参数），已固化进 04_bake.py
11. **06 GLB导出 (2026-09-17)**: 单文件GLB（4K贴图内嵌·米制比例）+三动画（走1.200s/跑0.667s/跳1.033s）+三段自查（源自查/GLB头部解析/重导入复核：比例0.00mm、变形签名0.07mm）
12. **管线集成 (07, 2026-09-17)**: `演示版_终端控制端/控制台.py` 一条命令跑 01→06；录屏前全链自检 22 项 0 缺失
13. **UV浪费检测与自适应搜索 (03, 2026-09-17 v3)**: 展开后自动测量 利用率/最大空方块/岛统计/密度CV；**判据自参照三项比值**(废料比<1 / 密度比≤1 / 岛数比≤1, 无模型相关常量, 换模型仍成立)；5轮预算自适应二分(朝合法峰)，跑不好取最好一版不阻断；定状态复测不过依次退用次优；本模型 利用率 30.9%→41.6%、空块消失，全链已刷新
14. **rim带坏面归因与自适应修复 (01A, 2026-09-18 v86)**: 半自动打点每轮点位不同 → 归因实测"输出band坏面(小角7.2%/长条6.3%) vs 同网格皮肤(0.9%/0.3%)"=新缝条带所致；根因=内环采样继承外环疏密(最近参数映射) → 内环环距**有界低通正则化**(限幅0.45~2.2×均距, 只改采样位置) + rim块外套**检测→带宽W阶梯(×0.7/1/1.45)→择优**包装(≤3轮, 早停, 不阻断)；L条带 7.2/6.3%→2.5/**0.9%**、02QR L带长条 11.2%→**1.6%**、外眼角细丝消失；判据全自参照, 换模型/换打点轮次仍成立
15. **烘焙审核机制 + UV择优缺陷修复 (04/03, 2026-09-18 焦点)**: 04脏块/拉伸**根因在03择优**——①判过是"刀锋"(岛数比471/470=1.002 被 ≤1.000 卡掉) ②fallback只看(废料比→利用率) → 选中密度比1.81/CV0.215的坏UV。修: passes()加**1%数值容差** + 新增**违约度 viol()** 择优 + 比值3位小数；04新增 `bake_qa.py` **审核机制**(未填充/脏块/密度CV 三指标全自参照 + margin相对阶梯[×1/1.5/0.6] + 字典序择优 + 双零早停, margin选定24px)；**边距与清理半径必须同源**(reach_px=margin+4, 16→24后曾因reach写死18出现背心边缘锯齿)。选定 66°+光顺 CV=0.109
16. **网格层级归位 (05, 2026-09-18)**: step2生成骨架后 身体+眼球 **父级到骨架**(保持世界位置, 位移0.000mm) —— 此前中间件里网格悬在Collection根下；配套: 眼珠蒙皮顶点组名随**骨架实际骨名**(不硬编码mixamorig:前缀)、normalize加顶点组↔骨名同步、眼珠摆入锚点改**3DDFA虹膜**(±34.21, 不再随手描轮廓漂移)、摆入幂等守卫改替换；实测 物体模式移骨架1m → 眼珠/身体1000.0mm全跟随
17. **rim带极角配对修复 (01A, 2026-09-18 v87 第二轮)**: 用户本轮新打点后眼角**再次**出现重叠乱面(02QR放大成退化细长面+眼裂硬折痕)。根因=内圈采样的**"最近邻参数"配对**在杏仁角尖处跳变 → 解绕小回退 → **强制单调+取模**后 **内环双覆盖=自交**(打点微变即随机触发)。修: 内圈改**极角单调配对**(星形环"同角度=同轮廓点", 结构性无交叉/无双覆盖, 形状深度仍取自手描轮廓) + 内建**交叉自检**(内外环线段求交数, 应=0, 直读印日志) + QA 增**针状(<5°)列**并纳入择优/早停(独立维度, 破"判据与修复同盲区"自证陷阱)。实测: 交叉自检 L/R 全0; QA选定 W=0.87 (L 1.2/2.0/0.2% · R 1.8/2.0/0.0%); 01_1黑缝/卷边消失、02眼睑边缘干净
