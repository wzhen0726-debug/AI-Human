# 半自动打点 — 全部位放置提示

**文件**: `A_半自动打点/06_rig_markers.blend`（Blender 5.1 打开）
**你只需放 8 个点**：3 个中线（黄）+ 5 个右侧（红）。左侧由脚本镜像生成，不用管。
**操作**：选中球 → 按 G → 拖动 → Ctrl+S 保存。

## 逐个点位提示（从头顶到脚）

| 点 | 放哪 | 怎么找 |
|---|---|---|
| 头顶（黄） | 头顶最高点 | 模型最顶部 |
| 颈根（黄） | 头颈交界处 | 下巴正下方、脖子开始的地方 |
| 会阴（黄） | 两腿分叉处 | 大腿内侧最顶部、两腿之间的中间 |
| 右肩（红） | 肩关节点 | **不是肩膀最外侧**。是肩膀最鼓那个三角肌的**正中间** |
| 右肘（红） | 肘关节 | 手臂弯折的中心 |
| 右腕（红） | 手腕 | 手掌和手臂的连接处 |
| 右膝（红） | 膝盖骨中心 | 膝盖骨（髌骨）正中心 |
| 右踝（红） | 踝骨最高点 | 脚踝外侧凸出来的骨头 |

## 关键提醒

1. **肩点放"肩膀最鼓处的正中间"**，不是肩膀最外侧、也不是锁骨末端。
2. **左右不用都放**——只放右侧 5 个点，左侧脚本自动生成。
3. **中线点只有一个**——头顶/颈根/会阴各 1 个，不需要放第二个。
4. 点在**肢体内部**（不是表面）——直接放，不需要贴皮肤。
5. 每个点的初始位置已经是测量算出来的，**只需要微调**，不用从零摆。
