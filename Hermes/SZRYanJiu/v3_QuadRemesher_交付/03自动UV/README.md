# 步骤03：自动UV展开

**日期**: 2026-07-31  |  **状态**: 已验证通过

---

## 功能

对 QR 拓扑后的低模（14.9 万面）自动展开 UV，用于后续纹理烘焙。

## 方案

在 14.9 万面高模上，边缘角度 >55° 会标记过多接缝导致每个面都是碎岛。改用 **Smart UV Project**（角度限制 66°），它能自动处理接缝和岛合并，在高面数模型上更稳定。

## 流程

1. **Smart UV Project**：`angle_limit=66°`, `island_margin=0.01`, `correct_aspect=True`
   - 自动检测最佳接缝位置
   - 自动合并相邻面为合理大小的 UV 岛
   - 岛间边距 0.01，避免烘焙时颜色溢出

## 脚本

`scripts/03_auto_uv.py`

## 输入/输出

| 项目 | 路径 |
|------|------|
| 输入 | `02QuadRemesher拓扑/02_qr_150k.blend` |
| 输出 | `03自动UV/03_auto_uv.blend` |
