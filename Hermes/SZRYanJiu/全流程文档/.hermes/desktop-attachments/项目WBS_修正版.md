## 六、决策点详细说明

### DP-1：Mixamo对衣服模型可行性（第2周末）

| 项目 | 内容 |
|-----|------|
| **决策内容** | 确认Mixamo能否对含衣服高模生成合理骨骼和权重 |
| **测试方法** | 1组修复后高模→FBX→Mixamo→下载检查 |
| **通过标准** | 骨骼>50根，权重分布合理，无严重穿模 |
| **未通过行动** | 切换到Auto-Rig Pro Smart |
| **时间影响** | +0.5周 |

### DP-2：黏连修复效果（第3周末）

| 项目 | 内容 |
|-----|------|
| **决策内容** | 确认黏连修复算法有效性 |
| **测试方法** | 3组模型修复后，测量大腿间隙 |
| **通过标准** | 间隙>1cm，无自相交 |
| **未通过行动** | 调整拍照规范（双腿分开更多）或调算法参数 |
| **时间影响** | +0.5周 |

### DP-3：Quad Remesher质量（第4周末）

| 项目 | 内容 |
|-----|------|
| **决策内容** | 确认30万面低模质量（关闭Symmetry X） |
| **测试方法** | 3组模型重拓扑后检查 |
| **通过标准** | 面数30万、无破面、锐边保留 |
| **未通过行动** | 调面数参数或调其他Remesher参数 |
| **时间影响** | +0.5周 |

### DP-4：绑定质量（第5周末）

| 项目 | 内容 |
|-----|------|
| **决策内容** | 确认绑定+权重修复后的动画效果 |
| **测试方法** | 走路/挥手动画 |
| **通过标准** | 无严重穿模，关节变形自然 |
| **未通过行动** | 调权重参数或换绑定方案 |
| **时间影响** | +0.5周 |

### DP-5：端到端测试（第7周末）

| 项目 | 内容 |
|-----|------|
| **决策内容** | 确认全流程通过率和运行时间 |
| **测试方法** | 5组不同输入 |
| **通过标准** | 通过率>80%，单组<45分钟 |
| **未通过行动** | 延长1周或降标准到70% |
| **时间影响** | +1周 |
