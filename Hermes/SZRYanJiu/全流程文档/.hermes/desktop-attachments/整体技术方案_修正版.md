## 二、关键修正说明

### 2.1 为什么关闭Symmetry X

**原方案设想：** Quad Remesher开启Symmetry X，一键生成对称低模。

**现实问题：** 衣服几何不对称（左边长袖、右边短袖；左边有手表、右边没有）。Symmetry X会把这些差异强制镜像，导致：
- 短袖变成长袖
- 右边无中生有手表凸起
- 口袋被镜像到对侧

**结论：Symmetry X全局对称不适用于衣服款式不对称的场景。**

### 2.2 对称化的替代方案

既然3D层面无法做几何对称，对称化转移到**2D拍照层面**：

| 层面 | 做什么 | 不做什么 |
|-----|-------|---------|
| **2D拍照** | 控制姿态对称（站直、双臂水平、腿开角一致） | 不控制衣服款式（长袖/短袖保留自然差异） |
| **3D模型** | 继承照片姿态，继承衣服款式 | **不做几何对称化** |
| **低模** | 保留衣服款式差异，姿态接近对称 | 不强制镜像 |
| **绑定** | 自动权重分配，接受不对称权重 | 不做权重镜像传递 |

**最终结果：低模整体不对称（衣服款式差异），但姿态接近对称（拍照控制）。**

### 2.3 删除眼球分离/装配

眼球保留在网格内，不参与单独处理。AI生成的高模中眼球是镶嵌在头部网格内的球状几何。

- **不做的原因：** 时间节省，简化流程
- **影响：** 眼球跟随头部运动（因为是头部网格的一部分），不能独立转动
- **可接受度：** 中等——基础动画场景下够用，精细表情场景不足

## 三、整体技术流程

```
【阶段0：输入准备】
  │
  ├── 用户拍摄照片（T-pose，正面+侧面+背面，4张最佳）
  │     ├── 必须：站直、双臂水平伸直、双腿分开肩宽、中性表情
  │     ├── 建议：穿紧身衣/泳衣（减少穿模）、头发后梳（不遮挡面部）
  │     └── 接受：衣服款式不对称（长袖/短袖、手表有无等保留自然差异）
  │
  └── 混元3D API生成高模（Normal + MultiView + FaceCount 100K-500K）
        └── 输出：全身高模GLB（50-200万面，含衣服、头发、眼球）

【阶段1：高模导入与几何修复】（2周）
  │
  ├── 1.1 GLB导入Blender
  ├── 1.2 破洞检测与填补（bmesh fill_holes）
  ├── 1.3 乱面清理（dissolve_degenerate + remove_doubles + delete_non_manifold）
  ├── 1.4 表面平整（Voxel Remesh + Laplacian Smooth，面部特征保护）
  └── 1.5 自相交检测与清理

【阶段2：黏连检测与修复】（1.5周）
  │
  ├── 2.1 MediaPipe Holistic 33点检测（肩/肘/腕/髋/膝/踝）
  ├── 2.2 大腿内侧黏连检测（最小距离算法，阈值5mm）
  ├── 2.3 黏连自动修复（沿法线方向推开顶点 + 过渡平滑）
  └── 2.4 修复验证

【阶段3：Quad Remesher重拓扑】（1周）⭐关键步骤
  │
  ├── 3.1 设置目标面数：30万面（三角形）
  ├── 3.2 启用 Preserve Sharp Edges（保留衣服边缘、面部轮廓）
  ├── 3.3 关闭 Symmetry X（衣服不对称，不能开对称）
  ├── 3.4 重拓扑执行（全自动，5-30分钟）
  └── 3.5 质量检查（面数、破面、锐边保留）

【阶段4：UV展开与纹理烘焙】（1.5周）
  │
  ├── 4.1 UV展开（Smart UV Project 或手动标记接缝 + Unwrap）
  │     └── 低模不对称，UV左右独立展开，不做镜像复用
  ├── 4.2 纹理烘焙设置（Selected to Active）
  │     ├── 烘焙距离：0.5-2cm
  │     ├── Diffuse Color烘焙（保留衣服颜色、皮肤纹理）
  │     └── Normal贴图烘焙（保留衣服褶皱）
  └── 4.3 烘焙质量检查

【阶段5：绑定与权重修复】（1.5周）
  │
  ├── 5.1 Mixamo绑定（云端全自动）
  │     └── 备选：Auto-Rig Pro Smart（本地，适应性更好）
  ├── 5.2 权重自动修复
  │     ├── 大腿内侧跨腿权重检测与修复
  │     ├── 单骨骼独占顶点平滑
  │     └── 全局权重Laplacian平滑
  └── 5.3 绑定质量验证（走路/挥手动画，检查穿模/折痕）

【阶段6：GLB导出】（0.5周）
  │
  ├── 6.1 骨骼层级整理（Mixamo/ARP命名规范）
  ├── 6.2 GLB导出（含骨骼+权重+材质）
  └── 6.3 .blend源文件归档

【阶段7：Pipeline集成与交付】（2周）
  │
  ├── 7.1 pipeline.py主控脚本
  ├── 7.2 config.json配置文件
  ├── 7.3 各阶段Checkpoint机制
  ├── 7.4 端到端测试（5组输入，通过率>80%）
  └── 7.5 工具包打包与文档
```

## 四、关键技术详解

### 4.1 Quad Remesher 关闭 Symmetry X

```python
import bpy

# 选中高模物体
bpy.context.view_layer.objects.active = high_poly_obj

# 调用 Quad Remesher（关闭Symmetry）
bpy.ops.quadremesher.remesh(
    target_count=300000,      # 30万面
    use_symmetry_x=False,     # 关闭X轴对称 ⭐关键修改
    detect_hard_edges=True    # 保留锐边
)

# 输出：不对称低模，保留衣服款式差异
```

**效果：**
- 左边长袖 → 低模左边还是长袖
- 右边短袖 → 低模右边还是短袖
- 左边手表凸起 → 低模左边保留凸起
- 褶皱走向 → 保留原始走向

**代价：**
- 低模整体不对称
- UV不能镜像复用，纹理文件稍大
- 绑定权重左右独立分配，不能镜像传递

### 4.2 黏连检测与修复

```python
def detect_thigh_clamping(mesh, landmarks):
    """检测大腿内侧黏连"""
    left_hip = landmarks['left_hip']
    left_knee = landmarks['left_knee']
    right_hip = landmarks['right_hip']
    right_knee = landmarks['right_knee']
    
    left_inner = get_verts_in_cylinder(mesh, left_hip, left_knee, radius=0.15)
    right_inner = get_verts_in_cylinder(mesh, right_hip, right_knee, radius=0.15)
    
    min_dist = min(distance(lv.co, rv.co) for lv in left_inner for rv in right_inner)
    return min_dist < 0.005  # 5mm阈值
```

### 4.3 权重自动修复

```python
def fix_cross_leg_weights(mesh):
    """修复大腿内侧跨腿权重"""
    for vert in mesh.verts:
        weights = get_weights(vert)
        left = weights.get('LeftLeg', 0)
        right = weights.get('RightLeg', 0)
        
        if left > 0.1 and right > 0.1:
            # 根据X坐标重新分配
            if vert.co.x > 0:
                weights['LeftLeg'] = 0
            else:
                weights['RightLeg'] = 0
            normalize(weights)
```

## 五、质量预期

| 维度 | 质量 | 说明 |
|-----|------|------|
| **面部像本人** | ⚠️ 中等 | 无BlendShape，面部静态；AI高模面部质量有限 |
| **身体动画** | ✅ 良好 | 走路、挥手、转身正常；30万面关节变形良好 |
| **衣服跟随** | ⚠️ 可接受 | 紧身衣跟随好，宽松衣大动作可能穿模 |

| **衣服褶皱** | ✅ 保留 | Normal贴图保留褶皱凹凸 |
| **头发** | ⚠️ 刚性 | 跟随头部运动，无物理；短发可接受 |
| **眼球** | ⚠️ 静态 | 镶嵌在头部网格内，不能独立转动 |
| **对称性** | ⚠️ 近似 | 姿态接近对称（拍照控制），但衣服款式不对称 |
| **文件大小** | ⚠️ 中等 | 30万面+纹理，GLB约40-80MB |

## 九、拍照规范（最终版）

### 必须满足

| 要求 | 说明 | 不满足后果 |
|-----|------|-----------|
| **T-pose** | 双臂水平伸直，双腿分开肩宽，躯干站直 | 绑定权重差 |
| **中性表情** | 嘴闭拢，眼自然睁开 | 面部变形异常 |
| **纯色背景** | 均匀光照，无阴影 | 生成质量下降 |
| **4视角** | 正面+左侧面+右侧面+背面 | 单张生成质量差 |

### 建议满足

| 要求 | 说明 | 不满足后果 |
|-----|------|-----------|
| **紧身衣** | 健身压缩衣、泳衣（纯色） | 宽松衣大动作穿模 |
| **短发/后梳** | 不遮挡面部和颈部 | 头发僵硬遮挡 |
| **无饰品** | 不佩戴眼镜、手表、项链 | 饰品粘连 |

### 可以接受（不做强制要求）

| 项目 | 说明 |
|-----|------|
| **衣服款式不对称** | 左边长袖右边短袖、有手表无手表——完全接受，3D模型会保留 |
| **身体轻微不对称** | 如左肩略低——拍照尽量控制，3D层面不修正 |
| **衣服褶皱** | 自然褶皱——完全保留，Normal贴图会烘焙 |
