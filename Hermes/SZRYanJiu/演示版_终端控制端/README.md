# 数字人资产生产管线 — 终端控制端（演示版）

录屏汇报用：在终端输入命令，真实调用 Blender 5.1 逐环节处理，实时输出处理数据，产物落到对应输出文件夹。

## 用法

```
python 控制台.py
```

| 命令 | 环节 | 输入 → 输出 | 实测耗时 |
|---|---|---|---|
| `01` | 高模修复与黏连检测 | 原始文件/raw_model.glb → 01高模修复/输出/01_highpoly_repair.blend | ~2.2 分钟 |
| `01a` | 眼窝重建与眼球摆入 | 01产物 → 01a眼窝眼球/输出/（眼窝+眼球+rim锐化 3个blend） | ~5.1 分钟 |
| `02` | QuadRemesher 拓扑重建 | 01a rim锐化版 → 02QR拓扑/输出/02_qr_150k.blend（117万面→14万quad） | ~1.5 分钟 |
| `03` | 自动UV展开 | 02产物 → 03自动UV/输出/03_auto_uv.blend | ~0.1 分钟 |
| `04` | 纹理烘焙 4K | 03产物 → 04纹理烘焙/输出/（blend + diffuse 4K + normal 4K） | ~0.5 分钟 |
| `05` | 骨骼绑定+动作重定向 | 04产物 → 05骨骼绑定/输出/（55骨骨架 + 走/跑/跳动作） | ~6 分钟（含AI打点） |
| `all` | 全流程顺序执行 | 01→01a→02→03→04→05 | ~16 分钟 |
| `status` | 查看各环节产物状态 | — | 即时 |

## 目录

- `原始文件/` — 输入资产（Tripo高模GLB、眼球GLB、Mixamo动画FBX×4、眼位检测JSON）
- `交付/` — 管线工作区（镜像正式交付结构，脚本在此运行）
- `01高模修复/输出` ~ `05骨骼绑定/输出` — 各环节最终交付产物
- `控制台.py` — 终端入口
- `logs/` — 每次运行的完整日志

## 说明

- 所有环节**真实运行**，非模拟；输出的数字均为真实处理数据
- 05 环节含 AI 自动打点（ARP 智能检测17个关节标记）与 Mixamo 动作重定向（测量驱动：骨架rest朝向自动对齐Mixamo标准，帧数按参考动画原样）
- 每个环节跑完自动落产物到输出文件夹，`status` 可随时查进度
