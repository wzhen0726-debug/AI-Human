# 数字人资产生产管线 — 终端控制端（演示版 v2.0）

录屏汇报用：在终端输入命令，真实调用 Blender 5.1 逐环节处理，单行动态进度实时刷新，产物落到对应输出文件夹。

## 用法

```
python 控制台.py
```

| 命令 | 环节 | 说明 | 实测耗时 |
|---|---|---|---|
| `01` | 高模修复与黏连检测 | raw_model.glb → 96.5万顶点修复后高模 | ~2.3 分钟 |
| `01a` | 眼窝重建与眼球摆入 | **半自动打点**→眼窝→眼球(Eye.fbx) | ~5.5 分钟（含手动） |
| `02` | QuadRemesher 拓扑重建 | 117万面 → 14万quad | ~1.5 分钟 |
| `03` | 自动UV展开 | Smart Project 少接缝无碎岛 | ~10 秒 |
| `04` | 纹理烘焙 | 4K Diffuse + Normal | ~30 秒 |
| `05` | 骨骼绑定与动作重定向 | **AI打点**→55骨→走/跑/跳 | ~1.5 分钟（含手动） |
| `all` | 全流程顺序执行 | 01→01a→02→03→04→05 | ~12 分钟 |
| `status` | 查看各环节产物状态 | — | 即时 |

## 演示特性

1. **单行动态进度**：旋转符 + 进度条 + 百分比 + 用时 + 实时阶段名，原地刷新不刷屏；详细数据写 `logs/`
2. **每环节清屏**：整屏只显示当前环节进度+结束摘要框，终端始终干净（历史靠日志回看）
3. **打点环节开 Blender GUI**：01a 眼裂轮廓、05 关节点位，自动打点后**打开 GUI 让你手动微调**，调整完关窗即自动继续——展示半自动人工介入能力
4. **05 自动弹出《点位指南.md》**：手动调点时同步参考
5. **噪声过滤**：Better FBX 等插件后台注册的红色 Traceback 自动隐藏（真实报错照常显示），录屏画面干净

## 手动打点环节（演示重点）

| 环节 | 打点内容 | 流程 |
|---|---|---|
| 01a | 眼裂轮廓（右眼12点） | 自动放点 → GUI手调 → 镜像到左眼 → 样条加密72点轮廓 |
| 05 | 17关节标记 | AI自动打点 → GUI手调（镜像约束同步左右）→ go_detect建骨架 |

> 跳过GUI（用现有点位）：设环境变量 `DEMO_SKIP_GUI=1`（仅自动化测试用，正式录屏别设）

## 目录

- `原始文件/` — 输入资产：Tripo高模GLB、**眼睛模型002(Eye.fbx + Textures)**、Mixamo动画FBX×4、眼位检测JSON、修复贴图
- `交付/` — 管线工作区（镜像正式交付结构，脚本在此运行）
- `01高模修复/输出` ~ `05骨骼绑定/输出` — 各环节最终交付产物
- `控制台.py` — 终端入口
- `logs/` — 每次运行的完整日志

## 关键说明

- 所有环节**真实运行**，输出数字均为真实处理数据
- 眼球用 **Eye.fbx**（眼睛模型002，单只眼663顶点已合并、瞳孔朝-Y、Hazel色），01a 摆入后 05 蒙皮到 Head 骨
- 05 动作重定向是测量驱动：骨架rest朝向自动对齐Mixamo标准（锚T-Pose.fbx），帧数完全按参考动画原样（走36/跑20/跳31）
- 每环节跑完自动落产物到输出文件夹，`status` 可随时查进度

## 录屏前自检

录屏前确认 `status` 全部"未生成"（干净状态），从 `01` 或 `all` 开始跑。若要重录，重跑会覆盖旧产物。
