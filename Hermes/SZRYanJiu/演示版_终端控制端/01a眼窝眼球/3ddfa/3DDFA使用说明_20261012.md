# 3DDFA 在本管线的使用说明（2026-10-12 集成）

> 一句话：**3DDFA 只在一个环节使用 = 01a 开头新增的「⓪ 眼区语义锚再生」前置步**；
> 它产出一个文件 `01a眼窝眼球/3ddfa/iris_3ddfa.json`（两眼中心的 3D 坐标），
> 下游 **④ 眼窝开孔** 和 **02 的眼球摆入** 读这个文件来定位眼睛。其余环节不用 3DDFA。

## 一、链路图

```
01高模修复/输出/01_highpoly_repair.blend        ← 输入(当前高模)
        │
        ▼  ⓪-1 渲染   01a眼窝眼球/scripts/_3ddfa_render_front.py   (Blender 无头)
        │             正交正脸 1024×1024 带贴图渲染 → face_front.png + cam_params.json
        ▼  ⓪-2 推理   3DDFA-V3/.venv/Scripts/python.exe demo.py    (开源仓库, 只读; CPU ~10s)
        │             → face_front.npy (ldm68: 68 个人脸关键点, 含两眼各 6 点)
        ▼  ⓪-3 反投影 01a眼窝眼球/scripts/_3ddfa_backproject.py    (Blender 无头)
        │             像素→正交射线→在高模上 ray_cast; 眼中心用 9 射线邻域投票取"最朝前的角膜命中"
        ▼
01a眼窝眼球/3ddfa/iris_3ddfa.json   ← 产物: L/R 的 center_3d(角膜表面交点)/corner/normal
        │                              + source_blend_md5(来源高模指纹) + generated_at
        ├──────────► ④ 眼窝开孔  run_eye_socket.py :: load_3ddfa_centers()
        │              眼区中心 → 眼窝切割位置/眼区半径/前后阈值 全部由它推导(活参数)
        └──────────► 02 眼球摆入 run_eyeball_v2.py :: EYE_EYEBALL_ANCHOR=e3
                       L 眼球 x = L.center_3d.x(本侧锚); R 眼球 x = 对称锚(两侧|x|均值)
```

编排脚本：`01a眼窝眼球/scripts/regen_iris_3ddfa.py`（串起 ⓪-1/2/3 + md5 门控 + 旧 json 备份）。
控制台接入点：`控制台.py` 的 `step_01a()` 第 0 步（在 ①放点 之前；`01r` 重建模式同样会跑）。

## 二、门控与开关

| 条件 | 行为 |
|---|---|
| json 内 `source_blend_md5` == 当前 01 高模 md5 | **跳过**（不重算，0 耗时） |
| 不匹配 / json 缺失 / `--force` | 重生成（实测 ~13s） |
| `EYE_3DDFA_REGEN=0` | 整步关闭，沿用现有 json（回退历史行为） |
| 重生成前 | 旧 json 自动备份到 `logs/_3ddfa_regen/iris_3ddfa.pre_regen_<时间>.json` |

## 三、为什么从"离线冻结"改成"动态再生"

- 历史：json 是 9 月初对**交付版高模**一次性生成的冻结件。
- 问题：高模后续修过（眼区几何变化），json 没跟着再生 → 对当前高模 **R 眼中心偏 4.6mm**（跟进实测）。
- 现在：每次高模变了，⓪ 步自动重生成，锚永远与当前高模一致；换头/换模型也自动适配（3DDFA 是语义检测，不写死坐标；缩放泛化实测 center 偏差 0.225mm）。

## 四、验证数据（跟进报告 scratch/dddfa_followup/REPORT.md）

- 方法忠实性：对交付版高模复现旧 json **逐值 0.000mm**（口径完全一致，非新算法）。
- 确定性：同输入渲染像素 0 差异；同图推理两次 bit 级相同。
- 集成后重跑（10-12）：环 170/170@0.545mm、贴面 L 0.044/0.406 / R 0.018/0.313mm、门控 L6/R6、ringflip 145、02 自交残留 0 —— 全门通过。
- 眼球位置变化：对称锚 +34.208→+35.039mm（R 外移 0.83mm）、L −35.802→−35.763mm；对照图 `logs/_3ddfa_regen/figs/AB19_眼球新旧对照.png`（肉眼不可见差异）。
