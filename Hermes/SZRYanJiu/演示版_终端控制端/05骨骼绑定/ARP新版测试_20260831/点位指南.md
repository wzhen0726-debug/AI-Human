# ARP 17点 打点位置指南

## 速览表（先看这里）

| 点 | 一句话位置 | 高度参考（本模型） |
|---|---|---|
| **chin** 下巴 | 下巴轮廓最下尖 | z≈1.59 |
| **neck** 颈根 | 颈后大椎高度·身体正中线 | z≈1.47 |
| **shoulder** 肩 | 肩缝（三角肌中点） | z≈1.43，距中线≈0.23 |
| **elbow** 肘 | 肘外侧骨点，**与肩同高** | z≈1.43 |
| **hand** 腕 | 腕横纹中点，与肩同高 | z≈1.43 |
| **hand_tip** 指尖 | 中指指尖，与肩同高 | z≈1.43 |
| **root** 骨盆中心(Hips) | **骨盆上缘**(髂嵴高度, 肚脐正后方)，**高于胯点(thigh)约6-7cm** | z≈0.93~0.94 |
| **thigh** 胯 | 大转子（大腿外侧最上硬骨） | z≈0.88 |
| **knee** 膝 | 髌骨外侧缘高度 | z≈0.52 |
| **foot** 脚踝 | 外踝骨突 | z≈0.14 |

**对称自检**：所有左右点 |x| 相等、z 相等；手臂四点（肩肘腕指尖）z 全部相同（T-pose 水平线）。

---

## 正面+侧面都要看（重要）

每个点是3D点。正面只能确定 左右(x) 和 高度(z)，**前后(y) 必须切侧面图（小键盘3）确认**：

| 点 | 侧面要检查什么 |
|---|---|
| chin | 贴在下巴最前凸点，不缩进脖子 |
| neck | 颈根前后中点，不前到喉结、不后贴颈椎皮 |
| root | 身体前后径**中点**（体腔内），不贴肚皮不贴后腰 |
| knee | 膝关节前后中点 |
| foot | 踝关节前后中点 |

**建议流程**：正面打完 → 切右侧正交视图检查 chin/neck/root/knee/foot 的前后位置 → 回正面复查。

## 详细点位说明

> 判定原则：每个点锚定一个**唯一的体表标志**。
> 模型为 T-pose，面朝 -Y，+X 侧 = 人物左手。`_sym` 为镜像点，标准相同。

### 头部（中线，x=0）

**chin_loc — 下巴尖**
- 下颌骨最下缘的**正中点**（颏隆凸）
- 正脸看：下巴轮廓最低点；侧脸看：下巴最前凸点的下缘
- 不是嘴唇，不是喉咙

**neck_loc — 颈根**
- 颈部与躯干交界的**正中点**（约第7颈椎棘突/大椎穴高度）
- 头前倾时颈后最突出的骨头的高度，取正中线；≈衣领后缘中点
- 不是喉结（喉结偏前偏上）

### 手臂

**shoulder_loc — 肩点**
- **三角肌中点**（肩峰外侧缘，手臂与躯干连接的最高点）
- 即T恤肩缝的位置
- 不是体内肩关节旋转中心，不是斜方肌上缘

**elbow_loc — 肘点**
- **肘关节外侧**（肱骨外上髁）
- 屈肘时肘部最突出骨点的外侧面；T-pose 手臂伸直取肘弯横纹外侧端
- 高度应与肩点同高

**hand_loc — 腕点**
- **腕横纹**（手掌与前臂交界横纹）正中，约尺骨茎突高度
- 不是掌根（掌根已过腕横纹2cm）

**hand_tip_loc — 指尖点**
- **中指指尖**末端（五指并拢伸直最长那根）

### 躯干（中线，x=0）

**root_loc — 骨盆中心（Hips 起点）**
- **骨盆上缘**（髂嵴最高点连线的高度），肚脐正后方、身体正中线、前后径中点（体腔内）
- **必须高于胯点(thigh)约 6-7cm**——Hips 骑在大腿根上方，两者不能同高
- 参考：系皮带的位置正中（不是裤腰下缘，是骨盆最上沿）；双手掐腰时拇指按到的骨头高度
- 不是大腿根/会阴（那是 thigh），不是肚脐表面（在体内5-8cm）

### 腿部

**thigh_loc — 胯点（大腿根）**
- **股骨大转子**（髋关节外侧最突出的骨点）
- 站立时手摸大腿外侧最上方突出的硬骨，约臀横纹高度
- 不是腹股沟中点（偏内偏前）

**knee_loc — 膝点**
- **膝关节外侧**（股骨外上髁高度），髌骨外侧缘
- 屈膝时关节缝隙处的高度

**foot_loc — 脚踝点**
- **外踝**（脚踝外侧最突出的骨点，腓骨外踝）中心
- 不是脚底，不是脚跟
