# 高模修复模块 — 测试指南与功能清单

**日期**: 2026-07-23  
**模块版本**: v10  
**管线阶段**: M1（高模获取与几何修复）+ M2（黏连修复）

---

## 一、推荐测试模型特征

| 特征 | 为什么重要 | 优先级 |
|------|-----------|--------|
| **AI 生成（Tripo/混元/Meshy）** | 模块针对 AI 模型缺陷设计 | 必须 |
| **高面数（100万+）** | 考验修复性能和细节保留 | 建议 |
| **非标准朝向**（手臂沿 Y、面朝 X） | 测试自动旋转功能 | 可选 |
| **开放壳体**（非流形边>10万） | 测试网格修复能力 | 建议 |
| **身体黏连**（大腿/腋下贴合） | 测试黏连修复 | 建议 |
| **衣物复杂**（多层、褶皱、手持物） | 测试碎片检测和排除区 | 挑战项 |
| **手部融合**（AI 典型并指） | 测试排除区有效性 | 建议 |
| **面部细节丰富** | 验证 Laplacian 是否保细节 | 建议 |

**最差情况测试**: 找一个"AI 生成质量差"的模型——朝向错、壳体开、黏连重、手部糊、有衣物。这能跑通，好模型更没问题。

## 二、当前模块功能清单（v10）

### 2.1 网格修复（repair.py）

| 功能 | 说明 | 参数 |
|------|------|------|
| 朝向检测 | arms 沿 Y→X，face 朝 +X→-Y | 自动 |
| 居中接地 | X=0, Y=0, Z=0 | 自动 |
| Remove Doubles | 合并重合顶点 | 0.05mm（收紧） |
| Dissolve Degenerate | 溶解零面积面 | 自动 |
| Fill Holes | 补闭边界孔洞 | sides=0 |
| Fix Non-Manifold | 修复 >2 面的边 | 溶解多余面 |
| Laplacian 平滑 | 渐进式 0.35→0.10 | 2 次迭代 |
| Final Fill+Doubles | 封闭残余孔洞 | 0.05mm |
| 重新接地 | 平滑后 Z 对齐 | 自动 |
| 质检验证 | 11 项指标 | 自动 |

### 2.2 黏连修复（adhesion.py）

| 功能 | 说明 | 参数 |
|------|------|------|
| KDTree 检测 | 近距面对检测 | 5.0mm 阈值 |
| 法线过滤 | 相对法线 >0.5 才判黏连 | 60° 锥 |
| **排除区** | 手腕以远（\|X\|>0.42）、脚踝以下（Z<0.10） | 自动 |
| 推开修复 | 检测时法线方向推开 | 0.5mm 步长 |
| **位移 clamp** | 单点最大 1.5mm | 防碎片 |
| **渐进平滑** | 0.35→0.10 局部平滑 | 5 次迭代 |
| 快速复检 | 前 100K 面确认残余 | 30s 上限 |

### 2.3 质检（repair_qa.py）

| 检查项 | 标准 | 新增 |
|--------|------|------|
| 非流形边 | ≤50 | |
| 边界边 | ≤50 | |
| 松散顶点 | =0 | |
| 退化面 | =0 | |
| **blade_faces** | =0 | ✅ 碎片检测 |
| 朝向 arms 沿 X | True | |
| X/Y 居中 | <0.01/<0.05 | |
| Z 接地 | <0.005 | |
| 面数下限 | ≥10万 | |
| 身高范围 | 0.8-2.5m | |

## 三、测试时观察重点

| 阶段 | 看什么 | 预期 |
|------|--------|------|
| 导入后 | 顶点/面数 | 与原始一致 |
| 修复后 | 非流形边 | 从几十万→<50 |
| 黏连后 | blade_faces | 0（关键指标） |
| 渲染图 | 双手/衣物 | 无新增碎片 |
| 面部特写 | 细节保留 | 皱纹、毛孔可见 |
| 衣物褶皱 | 是否平滑过度 | 褶皱应保留 |

## 五、测试流程

1. **准备模型**: 将测试模型放入 `test03_SimplifiedPipeline/input/raw_model.glb`
2. **运行修复**: `blender --background --factory-startup --python scripts/run_repair.py`
3. **运行质检**: `blender --background v6_run/01_repair.blend --factory-startup --python scripts/repair_qa.py`
4. **查看报告**: `v6_run/repair_qa_report.json`
5. **渲染验证**: 检查 `v6_run/repair_screenshot_*.png`
