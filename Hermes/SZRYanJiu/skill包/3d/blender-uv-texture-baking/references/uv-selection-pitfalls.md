# 自动UV"择优"的两个致命缺陷

## 1. 刀锋判据(严格 ≤1.000)会把好候选卡成不过
自参照比值判据(废料比<1 / 密度比≤1 / 岛数比≤1)在**恰好等于1附近**极其脆弱: 实测岛数比 471/470=**1.002**(差0.2%)把"三项全过"的66°光顺候选判成✗, 5轮没候选全过 → 掉进fallback。
**修**: `passes()` 给密度比/岛数比加 1% 数值容差(`<= 1.0+0.01`)——是数值容差不是质量放宽; 打印比值改3位小数否则刀锋不可见。

## 2. fallback 只看废料比 = 主动挑坏UV
原 fallback `min(key=(废料比, -利用率))` 实测选中了 密度比1.81 / CV 0.215 的最差候选(因为它空块0.004最小) → 下游烘焙全是脏块。
**修**: 新增 `viol()` = 三项比值超出1的部分之和, fallback 与复测排序改用 **(违约度 → 废料比 → 利用率)**。全不达标时选"最不违规"的, 而不是"废料最少"的。

## 判别口诀
- 比值 ≈1.000 附近 → 立刻怀疑刀锋, 先看3位小数;
- 选中(方案)与历史最优(CV)明显不一致 → 查 fallback 是否被触发、它的排序键是什么;
- 下游(烘焙/渲染)出现质量问题时, **先比对两次上游(UV)的指标差值**, 上游一改就重审下游判据。
