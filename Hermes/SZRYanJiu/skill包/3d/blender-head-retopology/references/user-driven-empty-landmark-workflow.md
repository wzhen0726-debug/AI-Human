# 用户驱动的空对象标记工作流

> 2026-07-27 test02 session: 当自动特征点检测失败时，用户提出用 Blender 空对象手动标记

## 背景

自动特征点检测（比例估算、拓扑分析）在 A-pose 模型上完全失效：
- 比例估算误差 30-50cm（肘在 62% 身高、腕在 42% 身高 —— A-pose 手臂下垂）
- 拓扑分析不对称 dX 0.24（MetaHuman 有轻微不对称）

用户提出：用 Blender 空对象手动标记特征点，比自动方法快且准。

## 工作流

### 1. 创建特征点场景

Agent 创建包含以下内容的 blend 文件：
- 目标模型（Tripo/MetaHuman）
- 16 个预命名空对象（`LM_NN_description_L/R`）

空对象初始位置按 bbox 比例估算：
- 头顶： Z = bbox_max.z * 0.97
- 下巴： Z = bbox_max.z * 0.86
- 胸中心： Z = bbox_max.z * 0.75
- 肩： Z = bbox_max.z * 0.82, X = ±bbox_size.x * 0.25
- 肘： Z = bbox_max.z * 0.62, X = ±bbox_size.x * 0.35
- 腕： Z = bbox_max.z * 0.42, X = ±bbox_size.x * 0.40
- 骨盆： Z = bbox_max.z * 0.55
- 膝： Z = bbox_max.z * 0.28, X = ±bbox_size.x * 0.15
- 踝： Z = bbox_max.z * 0.05, X = ±bbox_size.x * 0.18

### 2. 用户 GUI 调整

用户在 Blender GUI 中：
1. 打开 blend 文件
2. 选择空对象（`LM_01_head_top` 等）
3. 按 `G` 键移动到正确关节位置
4. 保存文件（`Ctrl+S`）

### 3. Agent 读取坐标

```python
for empty in bpy.data.objects:

        world_pos = empty.matrix_world.translation
        print(f"{empty.name}: ({world_pos.x:.3f}, {world_pos.y:.3f}, {world_pos.z:.3f})")
```

| 方法 | 时间 | 精度 | 可靠性 |
|------|------|------|--------|
| 自动检测 | 数小时调试 | 30-50cm 误差 | ❌ 不可靠 |
| 截图标记 | 10 分钟 | 依赖反投影 | ⚠️ 中等 |

## 用户要求（v6 更新，2026-07-28）

用户明确要求：
1. **中英文双语命名**：空对象名必须同时包含中文和英文，如 `LM_01_头顶_head_top`
2. **显示在最前方**：`empty.show_in_front = True`（否则空对象被模型遮挡，用户看不到）
3. **每个点必须有定位说明**：存入 `empty["description"]`，说明标在前面、后面还是中心
4. **前后位置必须明确**：人体有厚度，用户不知道标在头部中心、前额还是后脑勺

### 前后定位规则

坐标系：`-Y = 前（正面/面部/胸部/腹部），+Y = 后（背面/后脑勺/背部/臀部）`

| 部位 | 前后定位 | Y值 | 理由 |
|------|---------|-----|------|
| 头顶 | 正中偏前 | -0.02 | 头顶中心，略微偏前 |
| 下巴 | 前方 | -0.08 | 下巴尖在正前方 |
| 胸口 | 前方 | -0.08 | 胸口在正面 |
| 腹部 | 前方 | -0.06 | 肚脐在正面 |
| 后背 | 后方 | +0.08 | 背面与胸口对应 |
| 骨盆 | 前方 | -0.04 | 裆部上方正面 |
| 肩/肘/腕 | 中心 | -0.02 | 手臂中心，不分前后 |
| 膝 | 前方 | -0.04 | 膝盖骨正前方 |
| 踝 | 前方 | -0.02 | 踝关节正前方 |

## 场景创建 UX 要求（2026-07-28 用户明确要求）

1. **默认工具设为移动工具**（非框选）：`bpy.context.workspace.tools.update(active_tool="builtin.move")`。这样视口中会出现轴向手柄（红绿蓝箭头），不熟悉 Blender 的用户可以直接拖拽轴向移动空对象，不需要按 G 键。
2. **角色网格设为不可选中**：`mesh_obj.hide_select = True`。这样用户在视口中点击只会选中空对象，不会误选到角色本体。用户反馈："角色可以改成无法选中，方便只控制要打的点，不会误选到角色本体"。
3. **中英文双语命名**：`LM_01_头顶_head_top`（用户要求）
4. **show_in_front=True**：空对象显示在最前方，不被模型遮挡
5. **每个点有定位说明**：存入 `empty["description"]`
6. **参考模型默认隐藏**：Tripo 等参考模型设 `hide_set(True)` + `hide_render = True`，避免用户混淆。用户反馈："这个文件中还有个 tripo的模型是用来做啥的，还是默认显示的，我怕其他人会误会"。
7. **不要镜像对称**：用户明确否定镜像功能："算了 镜像不要了。我的模型也可能就是不堆成的"。模型本身可能不对称，镜像会导致错误。左右两边都手动标。

## 关键教训

- **当自动方法失败时，优先接受用户驱动的空对象标记**
- 空对象初始位置按 bbox 比例估算，用户只需微调
- **命名必须中英文双语**：`LM_01_头顶_head_top`（用户要求）
- **必须开启 `show_in_front=True`**：否则空对象被模型遮挡，用户无法在视口中看到
- **每个点必须有定位说明**：存入自定义属性 `empty["description"]`，包含前后位置信息
- **前后位置必须明确**：`-Y`是正面（面部/胸/腹），`+Y`是背面（后脑勺/背/臀），用户需要知道标在前面还是中心
- **打点指南必须给出唯一体表标志，不留歧义**：用户反馈"你的md里面也看不出来说的哪个位置"。不要用"手臂与躯干连接处"这种模糊描述，要明确到"三角肌中点，肩膀最圆最厚的肌肉隆起，不是腋窝凹陷"。每个点应该只有一个可能的标记位置。
- **肩膀标在三角肌中点，不是腋窝凹陷**：肩关节旋转中心在肱骨头与肩胛骨连接处，体表标志是三角肌中点（肩膀最圆最厚的位置）。腋窝内侧凹陷是手臂与躯干连接处，不是关节旋转中心，标在那里会导致绑定时手臂旋转轴心偏移。
- **需要镜像对称功能**：~~用户反馈"没有对称操作很多东西要操作两遍，而且左右对不齐"。下次生成场景时应加入镜像功能——用户标完左侧空对象后自动镜像到右侧，避免手动标两边导致不对称。可实现为：用户标完一侧后运行脚本读取左侧坐标，自动设置右侧坐标为(-left.x, left.y, left.z)。~~ **已废弃**：用户后续明确否定镜像："算了 镜像不要了。我的模型也可能就是不堆成的"。模型本身可能不对称，镜像会导致错误。左右两边都手动标。
- 比截图标记准（直接 3D 坐标，无反投影误差）
