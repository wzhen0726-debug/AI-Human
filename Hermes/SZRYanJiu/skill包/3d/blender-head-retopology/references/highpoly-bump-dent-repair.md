# 高模修复中的局部凸起/凹陷处理教训（2026-08-03）

**来源**：v3_QuadRemesher_交付 01高模修复 实战
**用户确认**：胸口凸起和腹部凹陷都是**原始模型自带的几何特征**，不是黏连/重叠/法线问题

---

## 一、方向判断：凹陷≠凸起

模型面朝-Y时：
- **凸起**：Y值比邻域更负（更往外）
- **凹陷**：Y值比邻域更负（更往内）

判断方向错会越修越坏（把凸起推成凹陷，或把凹陷推成凸起）。

---

## 二、两个实战案例

### 1. 胸口凸起（x=-0.043, z=1.209）

- **现象**：比周围表面凸出~10mm
- **修复**：环状参考面（内圈15mm/外圈40mm），100%推平
- **结果**：-0.1479 → -0.1411（↓6.8mm）

### 2. 腹部凹陷（x=0.032, z=1.218）

- **现象**：比周围表面凹陷~15mm
- **修复**：环状参考面（内圈15mm/外圈40mm），100%推平
- **结果**：-0.1472 → -0.1427（↓4.5mm）

## 三、通用修复代码

```python
import bmesh
from mathutils import Vector, kdtree

def fix_bump_or_dent(bm, cx, cz, inner_r=0.015, outer_r=0.040, is_bump=True):
    """修复局部凸起/凹陷。
    
    cx, cz: 问题中心 X/Z 坐标
    inner_r: 问题区域半径（米）
    outer_r: 参考面外圈半径（米）
    is_bump: True=凸起（推内）, False=凹陷（推外）
    """
    # 找问题区域顶点
    problem_verts = [v for v in bm.verts
        if ((v.co.x-cx)**2 + (v.co.z-cz)**2)**0.5 < inner_r]
    
    # 构建KDTree（全模型）
    kd = kdtree.KDTree(len(bm.verts))
    for vi, v in enumerate(bm.verts): kd.insert(v.co, vi)
    kd.balance()
    
    # 用环状区域（inner_r~outer_r）计算正常表面
    for v in problem_verts:
        ring = []
        for (co, vi, dist) in kd.find_range(v.co, outer_r):
            if dist < inner_r * 0.7: continue  # 排除内圈（问题本身）
            ring.append(bm.verts[vi].co)
        if len(ring) < 30: continue
        avg = Vector((0,0,0))
        for rv in ring: avg += rv
        avg /= len(ring)
        
        diff_y = v.co.y - avg.y
        if is_bump and diff_y < -0.002:  # 凸起（更负）
            v.co = avg  # 100%推到参考面
        elif not is_bump and diff_y > 0.002:  # 凹陷（更正）
            v.co = avg  # 100%推到参考面
```

## 四、教训

1. **先诊断再修复**：用顶点Y值排序找到最极端的顶点，确认是凸起还是凹陷
2. **环状参考面**：必须排除问题区域本身，否则自污染（平均被拉向问题区域）
3. **100%推平**：小步长（0.5/0.8）推不平，直接100%推到参考面
4. **不要全局法线翻转**：用中心外向法在非凸区域（锁骨上窝、裆部）会误翻正常面
5. **不要叠加平滑方法**：Taubin+Laplacian+雕刻平滑叠加会引入新变形
6. **验证**：修复后必须与原始模型（同坐标系）对比，偏差>1mm的顶点数应为0（除目标区域）

## 五、XZ平面距离污染 — 对称双坑事件（2026-08-03，CRITICAL）

**现象**：用环状参考面修复胸口凸起后，用户在两个胸肌位置发现**对称的坑洞**。

**根因**：环状参考面计算用 **XZ 平面距离** `sqrt((x-cx)²+(z-cz)²)`。左右胸肌在 XZ 平面上投影重叠（左胸 x=-0.06,z=1.25 / 右胸 x=+0.06,z=1.25，XZ 距离仅 0.12m < outer_r=0.04m 的 3 倍），导致左胸顶点的参考环包含了右胸顶点，右胸的包含了左胸的，双方互相把对方的正常表面拉向自己 → 正常表面被拉成坑。

**修复**：环状参考面必须用 **3D 欧氏距离** `sqrt((x-cx)²+(y-cy)²+(z-cz)²)`。左右胸肌在 3D 空间中 Y 坐标差异大（前后分开），不会互相污染。

**判断规则**：修复任何**对称部位**（左右胸、左右肩、左右臀）的局部异常时，如果参考环半径 > 对称间距的一半，必须用 3D 距离，不能用投影到任何 2D 平面的距离。

**更稳妥的方案**：对对称部位，参考环额外加同侧约束：
```python
ring = []
for (co, vi, dist) in kd.find_range(v.co, outer_r):
    if dist < inner_r * 0.7: continue
    if (v.co.x < 0) != (co.x < 0): continue  # 跨中线的不采用
    ring.append(bm.verts[vi].co)
```

## 六、方案C：衣服-身体重叠层删除的诊断方法（2026-08-04）

当用户报告"衣服和身体交界处有一坨"时，**不要直接删**——先诊断是否为真重叠层：

**诊断步骤**：
1. **Y 分层统计**：取目标区域所有面，按面中心 Y 值排序。真重叠层会呈现两个明显的 Y 聚类（外层 Y≈-0.138，内层 Y≈-0.125）。若只有一个聚类 → 不是重叠层，是单层几何异常。
2. **BVH 反向射线**：对外层面，沿法线**反方向** ray_cast（距离 5mm），命中面法线应与本面**相反**（dot < -0.9）。找不到 → 不是重叠层。
3. **边界边检查**：目标区域边界边 = 0 → 无破洞，是封闭多层；> 0 → 可能是破洞边缘。

**本案例（领口长条形）诊断结果**：Y 值单峰分布（-0.138 一个聚类），反向射线 0 命中，边界边 = 0 → **不是重叠层，是单层表面局部凸起**。方案C（删层）不适用，只能用环状参考面压平（见第五节）。

**真重叠层删除规则**（确认后执行）：
- 删**内层**（Y 较大的面，即靠近身体的一侧），保留外层
- 删除后必须 `bmesh.ops.holes_fill` 补洞
- 只删法线**相反**（dot < -0.9）的面对，法线同向的重复面是 `remove_overlapping_faces` 的职责
