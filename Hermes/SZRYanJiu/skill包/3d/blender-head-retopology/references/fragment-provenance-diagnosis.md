# 碎片/异物溯源诊断 — AI高模修复流程

## 何时使用

在修复后模型（或任何管线中间产物）上发现可疑几何体（碎片、异物、多余结构）时，
用此流程判断它来自**原始资产**还是**管线引入**。这决定修复策略：
- 原始资产问题 → 需要新删除步骤或留给后续阶段处理
- 管线引入 → 是脚本bug，必须修脚本

## 核心案例（2026-07-23）— 三次误诊后才定位真相

用户在修复后模型右手旁发现"刀片状碎片"，质疑："原始Tripo高模上没这个，
是不是修复流程中出现的？"

**误诊1**：碎片源自原始资产（vision把桨状手误读为碎片）
**误诊2**：碎片是黏连修复把融合手推开产生的
**误诊3**：碎片是fill_holes补洞产生的（手部面数不变→排除）
**真相**：碎片是 **`fix_adhesion`（黏连修复推开步骤）产生的**。
原始模型双手五指齐全无碎片（blades=0），repair全程8阶段blades=0，
`fix_adhesion`后blades突增到160，全部集中在左手（X≈-0.47）。

**教训：用户的质疑往往是对的。视觉诊断会误读，必须用几何不变量+逐阶段
blades计数做三角验证，不要急于归因。**

## 碎片定量检测法（blade detection）

碎片的典型几何特征：**细长三角形**——面积不小但极薄（某维度近零厚度）。
用"厚度比"检测，比视觉可靠得多：

```python
def count_blades(bm, label):
    n = 0
    for f in bm.faces:
        if len(f.verts) < 3: continue
        pts = [v.co for v in f.verts]
        area = f.calc_area()
        if area < 1e-6: continue
        max_edge = max((pts[i]-pts[j]).length
                       for i in range(len(pts)) for j in range(i+1, len(pts)))
        if max_edge < 1e-6: continue
        thickness = 2 * area / max_edge   # 近似厚度
        if thickness < 0.002 and area > 1e-5:  # 厚<2mm且面积>10mm²
            n += 1
    print(f"[{label}] blade_faces={n}")
    return n
```

**逐阶段跑这个函数是定位根因的最强工具**——哪个阶段计数从0跳变，
根因就在哪个阶段。本次实测：

```
[0-initial] blade_faces=0
[1-REMOVE_DOUBLES] blade_faces=0
[2-dissolve_degen] blade_faces=0
[3-fill_holes] blade_faces=0
[4-fix_non_manifold] blade_faces=0
[5-laplacian] blade_faces=0
[6-final_fill] blade_faces=0
[8-ADHESION_FIX] blade_faces=160   ← 根因在此
```

## 四步诊断法

### 第1步：原始资产视觉检查

对**未做任何修复**的原始模型渲染特写。注意原始朝向可能不同（如Tripo arms沿Y、
face朝+X），相机定位要适配原始坐标系。

**必须拍全身+双手两侧特写**，交叉验证。但注意：vision分析会误读
（把桨状手描述成"刀片碎片"），视觉只能做参考，不能做结论。

### 第2步：岛分析（连通性）

并查集找连通岛。岛数=1 → 碎片与主体连通，不能按loose parts删除。
**岛分析只说明连通性，不说明来源**——不要从"岛数=1"推出"碎片是修复引入的"。

### 第3步：逐阶段blade计数回溯（核心步骤）

写一个诊断脚本逐阶段执行管线每一步，每步后调 `count_blades`。
哪个阶段计数跳变，根因就在哪。**这是比任何视觉分析都有说服力的证据。**

### 第4步：机制推断（逐步骤能否引入几何）

| 管线步骤 | 能否产生刀片碎片 | 机制 |
|---------|----------------|------|
| rotate / center / smooth | 否 | 纯坐标变换 |
| remove_doubles | 间接可能 | 合并近距顶点可把两层面拉成细长三角形 |
| dissolve_degenerate / fix_non_manifold | 否 | 只删面 |
| fill_holes | 可能 | 补洞生成新面（但只补边界环，且面数会增加） |
| **fix_adhesion（推开+局部平滑）** | **是（本次根因）** | 把贴得极近的双层皮沿法线推开，层间面被拉成薄刀片 |

**关键区分**：`fill_holes` 会增加面数，`fix_adhesion` 不改面数只移顶点。
本次手部面数全程不变（48901）→ 排除 fill_holes；blades 在 adhesion 后跳变 → 锁定 fix_adhesion。

## fix_adhesion 产生刀片的机制

黏连检测找到"距离近+法线相对"的面片对（双腿内侧、腋下、**手部双层皮**），
沿各自法线把顶点推开。手部区域AI生成时指缝间两层皮贴得极近（<5mm阈值），
被判为黏连→推开→原本连接的过渡面被拉成细长三角形（刀片）。

**修复方向（不是排除手部，而是优化算法）：**
- 检测端加过滤：排除"共享顶点距离<2的面对"（真黏连面不相邻，假黏连是近邻折叠）
- 推开端改策略：小步多次+每步后检查是否产生新刀片，产生则回退
- QA端加blade检测：碎片数应作为质检指标（当前11项里没有）

## 常见误判（本次全部踩过）

- ❌ **"vision说原始模型有碎片=真有"** → vision会把桨状手/融合指误读为碎片，必须渲染多角度+用户确认
- ❌ **"特写没看到=不存在"** → 视角遮挡
- ❌ **"岛数=1=碎片是修复引入的"** → 岛分析只说明连通性
- ❌ **急于归因** → 先做逐阶段blade计数，用数据定位，不要猜
- ❌ **"面数不变=几何没变"** → fix_adhesion只移顶点不改面数，但能把面拉成刀片。面数和顶点坐标统计（spreadY）都可能漏掉拓扑形态变化，blade检测才抓得住
- ❌ **透视图误判左右手** → T-pose侧视图中，画面左侧的手是模型的右手（+X侧），画面右侧的手是左手（-X侧）。本次碎片实际在左手（X≈-0.47），但透视渲染中看起来像"右手附近的黑色物体"。**必须用坐标定位，不能用屏幕位置判断**

## 修复方案（v9, 2026-07-23 已实施）

1. **检测端加四肢末端排除区**：`|X|>0.42`（手腕以远）+ `Z<0.10`（脚踝以下）。AI手部/足部几何不可靠，在这些区域推开必然产生碎片。注意阈值不能太宽（`|X|>0.35`会排除手臂大部分面，导致detect 120秒0对）。
2. **fix_adhesion用检测时法线**（非变形法线）+ **单点位移clamp**至`3×push_step`（1.5mm max）
3. **渐进式平滑**（0.35→0.10）替代固定因子
4. **remove_doubles阈值收紧**至0.05mm（原0.1mm），避免把近距双层皮拉成碎片
5. **QA新增blade_faces检测**（厚度<2mm且面积>10mm²的尖锐三角面）

**结果**：blades 160→0，非流形边27→1，水密False→True。详见
`blender-digital-human-pipeline/references/adhesion-blade-fragment-fix.md`。

## 处理建议

- 根因定位后修算法（检测过滤/推开策略），不要跳过或排除问题区域
- 用户明确反对"排除法"——要的是修复好的高模，不是绕开问题
