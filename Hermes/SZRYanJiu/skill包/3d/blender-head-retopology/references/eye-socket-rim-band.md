# 眼窝 rim 带：精确构造与量测

适用：头部管线里在“已挖开的眼窝开口”与皮肤之间做一圈环形带（内环＝手描轮廓，外环＝皮肤上的偏移环）；
同类问题（需要一条必须闭合的边界）可直接套用。

## 不要用：沿网格边找闭环

用“沿边界边游走找环 → 度≠2 就删掉周围面重试”的方式取外环，遇不规则网格必崩：删面会造出新边界
（实测碎环数 2→5→6 递增，6 轮后放弃），下游拿断裂边界桥接 → 眼角平口切断、面疏密混乱、
回退门控反复重试耗时数十分钟。重试型修法的判据只能是“每轮缺陷数严格递减”，做不到就换获取方式。

## 用：轮廓外扩 + 环形布尔（已验证）

1. **外环＝程序化偏移**：手描轮廓点沿 xz 外法向偏移一个带宽（斜接限 ~2.5W，自交检查＝0，重采样匀距）。
2. **实心棱柱 + EXACT 布尔差集**：以偏移环做**实心**棱柱（y 范围由带内皮肤实测 y 范围活定，两端穿出皮肤），
   对头部网格做一次布尔差集，再按材质槽精确删切割面 → 带区皮肤被切除，边界就是**布尔算出的精确闭环**
   （实测：单眼边界边全部落在目标环 0.02mm 内、单一闭环、与偏移环距离中位=最大=0.000mm）。
   不要用“环形（垫圈）棱柱”绕路，实心棱柱更稳。
3. **同点数一一桥接**：内环＝手描轮廓重采样到与外环同点数 K'；bridge 时按点对点顺序一一连（同起点/同绕向），
   不做最近邻/解绕启发。
4. **单排 → N 排（修长条面）**：`NR = ceil(内外环三维间距中位 / (0.5 × 皮肤中位边长))`（活推导，随带宽/皮肤变化），
   在内外环之间插 NR−1 圈中环：先取线性中点，再投影到**切割前的皮肤快照 BVH**（`closest_point_on_mesh`），
   带位移上限（≤0.45W）与深度跳变则退回中点的保护；**逐圈两两桥接**（一次传入三圈会多桥一排、产生非流形边）。
   实测中缝单圈无效（细长比 4.10→4.18，单圈跨径仍≈整带宽），必须按上式自动增排（3~4 排 → 细长比 4.10/3.91→1.75/2.79）。
5. **旧路径留作回退**（环境变量一键切回），改完 grep 日志确认旧路径标记行为 0 次——
   “新代码已生效”要靠日志证明，不能只看 rc=0。

## 量测口径（机械判据，不靠读图）

- **环**：环数/闭合性、顶点数、边长 CV、转角 中位/p95/max —— 转角一律在**定义形状的那个平面**（本例 xz）里量，
  三维转角会把面外微起伏稀释掉、放过尖点；汇总 XZ 自交处数＝0。
- **带面**：细长比 中位/p95、>6 的个数、<0.10mm 短边个数、面积 CV（剔 <0.001mm² 极小面后另算一列）、
  退化面＝0、眼区法线朝后面＝0、非流形边**与输入基线比（不新增）**。
- 两组数各存一份可对照的文本（改前/改后），并**如实报新法的代价面**（实测：细长比/环指标全面变好，但一侧面积 CV 48%→61%、
  带内面数 ×3、单步耗时 +14%）——只报赢的那半边会被当成隐瞒。

## 沙箱与耗时结构

- 用 `XXX_OUT_BLEND` + 截图目录环境变量把测试产物引到 `logs/`，正式产物零改动；
  跑完 `find -newermt <改动时刻>` 核验正式目录未被写（含输出 blend、手调 json 的 mtime）。
- 该环节墙钟的大头往往是**门控/QA 的多档参数重跑**（实测每眼 3 档带宽 ≈110-150s/轮，占该步 90%），
  布尔本身只 8~10s —— 要提速就动 QA 的档数与早停判据，别去优化布尔。
- A/B 用**同一输入、同一套量测**：新旧法各自留 blend/日志/同机位正交特写，再作对比。
