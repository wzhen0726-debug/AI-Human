# 骨骼绑定标记模板：01A半自动打点逻辑 (2026-08-25验证)

**用户验收的权威模板 = 01A眼窝标记流程**，骨骼绑定必须照搬：
1. 初始位置 = **程序几何测量**（不是拍脑袋写死的常量）→ 用户打开只需微调
2. **只标一侧+中线**，另一侧由镜像脚本生成（x取负，中文名"右"→"左"）
3. Empty球体 + show_in_front=True + 中英文命名（LM_01_头顶_headtop）+ 颜色分组
4. 每个标记配唯一体表标志指南（如"右肩：三角肌中点"），不留歧义

**关键坑：关节在肢体内部 → 不能加Shrinkwrap。** 01A眼睑点在表面所以吸附正确；
关节点加Shrinkwrap会被吸到肚皮/后背表面 = 标记散落乱飞（用户因此判定模板"完全不对"）。

## 关节测量方法 (measure_joints.py)

- **身高分布扫描**：每2%身高的z带算X跨度 → 手臂带=跨度>1.0的连续z带；会阴=自上而下扫到中心空隙（|x|<0.02顶点<20个）的第一个带
- **颈根**：从肩部往上扫(84-90%)找最窄带取上缘。❌ 禁止从头顶往下扫（头跨度0.18<阈值会误判）
- **手臂Y厚度剖面**（沿x方向1cm分箱）：腕=厚度3cm内突增>35%的x（手掌起点）；肘=0.30-0.55范围局部最细
- **腿宽剖面**：膝=15-45%局部最窄；踝=2-14%最窄
- 姿态判断：手臂水平(上段maxX>中段)=T-pose

## 生成流程

measure_joints.py → rig_semiauto_setup.py（R侧+中线8点）→ 用户GUI微调 → mirror_rig_markers.py → rig_from_markers.py（22根Mixamo骨骼, parent_set ARMATURE_AUTO权重, 眼球parent到Head骨骼）→ GLB。
find_marker需模糊匹配（中英文命名：去下划线+小写包含匹配）。

## 验证（必做）

- 权重覆盖率=100%（无权重顶点数=0）
- **弯肘测试**：pose模式旋转RightForeArm 90°，evaluated depsgraph取形变后顶点，位移>1cm的顶点应≈手臂顶点数（本例11051/143708）
- 交付前从最终blend清掉全部LM_标记点
