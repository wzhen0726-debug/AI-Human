# 01高模修复标准管道

**核心原则**: 只做旋转+焊接+非流形+黏连修复，不要加实验性步骤。

## 标准流程

```python
# run_repair.py 一键入口
blender --background --factory-startup --python run_repair.py -- <input.glb> <output.blend>
```

包含步骤：
1. 旋转矫正（foot_score判据+鼻部突出度）
2. 居中+接地
3. remove_doubles（自适应阈值）
4. 非流形修复
5. 黏连修复（adhesion_pipeline，threshold=5mm）

## 禁止操作（用户纠正过）

- **法线翻转**：会翻错多层结构，产生16.7mm变形
- **雕刻平滑**：未经用户确认不要加，会引入新错误
- **Taubin平滑**：同上
- **极小面清理**：阈值判断困难，会误删正常面
- **凸起推平**：会过度推平产生凹陷

## 用户偏好

- 用户说"我在GUI里自己能修"时，几何细节留用户手动处理
- 用户说"翻翻之前的做法"=用已交付的run_repair.py流程，不要自己加东西
- 用户说"别雕刻了"=停止未经确认的雕刻平滑操作

## 常见诊断

**腹部视觉"孔洞"**：不是几何孔洞，是法线朝内（局部翻转法线即可，3459面→0）
**胸口凸起**：原始模型自带几何特征，需局部雕刻平滑（环状参考面15-40mm小步长多次迭代）
