# QR 后低模碗状眼窝 (02qr_socket_cup)

在 QR 输出的低模头上, 用眼孔开放边界重建"碗"(眼球坐进去)。生产脚本 `02QR拓扑/scripts/02qr_socket_cup.py`; 新建碗面打 tag 层 `qrbowl`(核查/GUI 定位用)。

## 构造(定案)
- **眼球球心 = 眼球网格包围盒中心**; **半径 = p90**。顶点均值会被角膜侧密顶点带偏约 4mm, 半径取 max 会虚胖→碗过深。间隙从配置反推, 实测碗面到眼球最小距离 ≥ ~1.3mm。
- 环 = 边界点**逐圈等比缩小**(每圈一个标量, 缩放序列线性到最深环 `_S_DEEP`≈0.152); 深度 = **rim_y 线性插值到"眼窝心"平面**(见下"窝底形状")。⛔ 禁用两类深度源: ①逐点沿 +Y 射线采样旧参考碗(把参考件坑洼/偏心搬进碗; 其中心非单调 → 极点前凸 4.7mm 圆锥尖) ②球面回退公式(与用户做法无关, 会造出斜切长漏斗)。
- 收口 = 末环缩到很小(≈1mm)后接**单极点三角扇**。用户口径: "眼窝内的都是环线…最后成为一个点"。禁用: 大 n-gon 平盖(用户叫它"花生仁"——像一块平板)和大三角扇星形; 圈数不足时收口会呈星形放射, 加深 1-2 圈再收。
  - **收口两条硬约束(尖刺事故后定案)**: ①**极点 y 由"眼窝心平面"连续推得** = `y_deep + 0.058×eye_w`(参考碗实测比最深环再深 +2.17mm); **不要单独对参考件在 r≈0 处打射线** —— 实测该射线值与连续外推差 4.7mm(相邻环间的正常台阶才 1.3~1.7mm), 会造出长扇骨 + 陡锥收口, 是"放射状尖面"的成因之一。②**不要用焊接去治深部细长面** —— 细长面(扇骨 15:1)是此碗法的固有特征, 用户参考碗同位置更重(>10 面 95 个/最差 43.5); 焊接每合一对顶点抬一次 valence, 全环焊会造出聚集假极点(用户圈出报"捏皱"过)。保持方法原样(0 焊接), 细面留在眼球内部不可见区; 真要治先拿参考碗数据问用户。
- **窝底形状 = 用户方法的精确解码(定案, 别再换别的模型)**:
  - 用户手调方法: "取 rim 环 → 缩放成眼窝最深处的环 → 沿 Y 轴打平(该环全部顶点同一 y = 眼窝心平面) → 中间 Ctrl+R 均匀补分段 → 再挤出一点合并到中心"。
  - 实测本质 = **纯线性插值**(逐环核对参考碗 8 环+极点全部命中): `y_k_i = (1-t_k)·rim_y_i + t_k·y_deep, t_k=k/NB` —— 深度步进**逐环全等**(+3.13mm×7)、顶点波动**精确线性衰减** `(NB-k)/NB`(std 4.21→3.61→…→0)、**最深环 y 跨度 = 0.00(全平)**、缩放序列同为线性步进(≈0.105/环)。
  - 参数(全部参考碗实测反推, 随尺寸随动): `y_deep = mean(rim_y) + 0.675×eye_w`; 极点 = `y_deep + 0.058×eye_w`(比最深环再深 +2.17mm@37.13mm); `_S_DEEP ≈ 0.152`。
  - ⛔ 已证伪的旧模型(别再用): ①"逐圈向本圈均值压缩、压缩率 0.956→0.65"(出自**同半径圆周探针** —— 杏仁形环上会混样, 读数不可信) ②rim 中位数基线 + λ≈0.52 常数衰减 ③任何非线性深度剖面 —— 三者产物深度步进忽大忽小(1.5/4.5/5.7mm…)、最深环斜跨 4.5mm 不平, 用户判"结构错了"。
  - 复刻验收: 与参考碗 **BFS 环表逐环比对**(`scripts/bowl_ring_table.py <blend>`), 每环 y 均值/半径比差 ≤0.1mm; 表面级 KDTree 比对在结构错时也会过(ε0.7mm), 不可只信它。
- 深部环向"圆"过渡时**只能动半径, 绝不动角度**。

## 绕序与定向(镜像陷阱)
- 镜像网格上左右孔环**走行方向相反** → 同套顶点顺序必翻一侧。用**种子绕序法**: 每侧取环上与头模面共享的第一条边, 按流形一致规则定序; **封底/极点扇也必须纳入定向**(漏掉=单侧大片红面)。
- 只对新建面定向。全局 `bmesh.ops.recalc_face_normals` 会按连通岛整体重定向, 翻掉腿部整片 ✗。
- 保存 blend 前切回 OBJECT 模式。

## 环带调整铁律(反复踩过)
1. **只允许"每圈一个标量"的调整**(等比缩放、整圈径向位移、整圈沿轴位移)。**逐点重排**(角度均匀化、逐点弧长等分布环) → 环线错位穿插/扭曲, 做一次错一次。
2. 反馈式逐环调参会发散(均值宽度→scales 非单调→环交叉) ✗。要均分用**单标量二分**: w1(s1) 单调减、w2(s1) 单调增, 限定 s1∈(s2,1) 保证不交叉。
3. **环带宽度 ≠ 径向跨距**: 最外一带含"从脸面直落进碗"的深度落差——等比缩小 ≠ 等表面宽度。均分判据必须用**表面 3D 宽度**(环上同名点之间的实际距离)。
4. 细长面/破面先量**四边形质量**(最小内角、边长比、<15° 计数)再动手: 常见主因是**圈位**而非点分布(挪对一圈实测: p1 3.3°→18.6°、<20° 面 267→11)。健康参考: p1≥15°、中位≈50°、<15°=0。
5. 两眼同步改, 不许单眼特判; 位移量/圈位做成脚本顶部常数块, 一处改。
6. 用户否定某一版时: `git checkout <该版commit> -- <脚本>` 精确还原再重建(手改回退易漏改); 重建后与上一认可版核对几何数值(极点坐标/面数/带比)逐项一致再汇报。

## 用户量测口径
- 圈数**从 rim 数起, rim = 第 1 圈**(用户说"这是 3"时先换算成脚本里的第 2 条内环)。
- "+Y / 朝正 Y 轴" = 向眼睛深处; 量以米报(如 0.001688m); "最近的点 X m、其他少一点 Y m" = 沿环**前大后小渐变**(按各点到观察者/前侧的 y 排序)。

## 验证清单(每版必做)
- **面朝向真渲染**: 按用户视角(正前+略俯视)算"是否背对相机"着色后**真渲染**。数值判"朝后"会把被遮挡面也计入——几十个被遮挡面在渲染里完全看不见, 别据此报"还有红面"。Workbench 材质色必须设 `mat.diffuse_color`(节点 Base Color 无效, 会渲出全灰)。
- 腿部翻转 0、开放边 0、碗面朝后占比 0。
- vision 的绝对判读会自相矛盾(同一渲染一会儿"干净"一会儿"乱") → 只作参考; 判据用数值或等用户确认; 优先同参数对侧对比。**特写取景会引入比例错觉**(实测同一摆位在近距灰模渲染里被判"眼球过大/过凸", 而该摆位是用户认可过的) —— 不得凭单张 vision 推翻已认可版本或动几何。
- **碗面缺陷先定归属再动手**: 同一份眼区体检对 ①QR 输出(`02QR拓扑/_中间/02_qr_150k.blend`) ②最终(碗后)文件 各跑一遍 —— 实测 QR 输出眼区干净(边长比>5 仅 1 面), 碗后 242 面异常 → 结论"问题在碗工序", 别去调 QR 参数。判据 = **逐面边长比 max/min**(>10 = 肉眼可见尖刺; ≤7 = 轻微); 再把最差面的**逐角坐标 + 逐边长度**dump 出来认结构: 含"眼轴 r≈0 的极点顶点"且两条边 4~5mm = 极点扇骨过长; 环带四边形一边 4mm+、另一边 <1mm = 环间距各向异性。
- **尖刺修复基线(实测)**: 极点 y 连续 + 全碗环 0.65mm 焊接 → 眼区 >10 尖面 52→0、最差边长比 15.6→6.9; 剩余 ≤6.9 的细条全部位于 **rim 自身密集点**(QR 边界密度继承), rim 按规矩不动, 属已知残留。
- 几何核查以【逐面数值 + SOLID 实体渲染】为准; 不必强求 headless 渲线框图(实测 Workbench WIREFRAME 模式出白图、freestyle 报 `strokes set empty` 且构图不可控, 白花时间) —— 线框观感留给用户在自己的 Blender 视口判读。
- 渲染视角: -Y 视图 + 掠射角(俯视 18°/32°)。
- 汇报格式: 一句结论 + 判据表 + 渲染图 + 提醒"关闭不保存→重新打开"(用户常开着旧文件看)。

## 参考图 / 用户手调参考版(反推工作流)
用户会手调一版参考, 要求"反推我的调整 → 忘掉参数 → 复刻":
1. **先量化再动手**: 两张参考图先分辨版本(读 UI 文件名/资产 ID——同名资产 `_QR` vs `_ORI` 的差别可能就是全部诉求); 像素分析定位标注(黄线/数字)与位移量; 确认"差在哪、差多少"再改。跨图像素→mm 换算只在两图同缩放时可信(曾估 5mm 实为 1.7mm ✗)——方向/量级作参考, 精确值带编号选项问用户(圈的序号从 rim 数、方向、量; 用户会给米制值如 0.001688m)。**不要顺手重建结构**——加圈/换收口这类"优化"会被判为乱改。
2. 拿到参考 blend: 先存自己的基线快照; 拓扑总数先对(顶点/面数差可与自己删掉的部件核对: 如差 351 面恰为左碗 → 用户只删左碗、右碗仅动点)。逐点 KD 匹配(`scripts/diff_reference_blend.py`)只作粗筛——同名点错位时 |Δ|≈顶点间距级噪声, 会掩盖真实改动; **决定性判据 = 网格射线探针 δy 图**(与拓扑无关, 两版拓扑不同也能测): `scripts/grid_probe_delta.py <基线> <参考>` → 逐行 min/max/mean + 热力图。**符号先核对**: 本项目 y 越负越靠前 → Δy>0 = 参考版更靠后(=更深), 标错会把方向读反。**环归属的决定性方法 = BFS 环表**(`scripts/bowl_ring_table.py <blend>`): 碗=四边形环带 → 从 rim 按网格边 BFS, **图距=环号**(确定性, 与顶点顺序/半径估计无关), 逐环出 n/半径比/y均/std/跨度/Δ。实测参考碗立刻读出真规律: 8 环×47+极点、深度步进 +3.13×7 全等、波动线性衰减、**最深环全平(跨度0.00)**。⚠ 同半径圆周探针在杏仁形环上**会把不同环混样** —— 旧结论"深部波动被压小到 0.65×"正是混样假象, 据此建的"逐圈打平"模型已被证伪; 按半径分箱同样不可信。
3. 把"量的规律"抽象成**随动规则**(按圈号/前后位置/头尺寸表达)再重实现; 不抄字面数字。用户说"重做"后, 我此前对该区域的手调位移/补丁一律删除, 不叠加在用户新规则之上。
4. 复刻版用同一判据复核(红面/腿部/面质量/带比 + 渲染), 确认 ⇔ 参考版; 视觉确认用**同机位 A/B 渲染拼图**(左=自己的, 右=参考), 判读问法用左/右对比, 单图绝对描述不可靠。

## 已被证伪的路(别再走)
- 逐点弧长等分布环(外圈等分+深部回落) → 错位穿插 ✗
- 角度解绕+均布过渡 与 半径向圆混合 → 环线断裂/中心星状 ✗
- 逐环均值反馈调参 → 发散 ✗
- 把"参考图差异"误读成要改拓扑(加圈/换收口), 实为"同一条环线沿 Y 挪一点" ✗
- 未经点名的结构"优化"(加圈、深部向圆、均匀化重排)——指标再好也算"乱改"; 每版只做用户点名的一项。
