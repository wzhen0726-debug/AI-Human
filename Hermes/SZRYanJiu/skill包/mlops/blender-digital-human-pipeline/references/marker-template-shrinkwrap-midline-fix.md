# 打点模板关键修正：Shrinkwrap约束策略 + 中线锁定 + 提示牌朝向 + 几何校验 (2026-08-26)

## 核心教训：Shrinkwrap 分两类点区别对待

| 点类型 | 解剖本质 | Shrinkwrap |
|---|---|---|
| 头顶/颈根/会阴（中线表面点） | 皮肤表面标志 | ✅ 保留吸附 |
| 肩/肘/腕/膝/踝（关节点） | **肢体内部解剖点** | ❌ **禁止吸附** |

**根因**：关节点在肢体内部，`NEAREST_SURFACE` 吸附会**主动阻止**用户把点放到皮肤内部（如肩点被吸到三角肌前束表面），导致骨旋转轴心偏到皮肤表面 → 蒙皮变形异常（抬手/走路不自然）。用户原话："我的肩膀都打到前束表面了，不会有影响吗？"——影响很大，轴心偏前偏外。
**修复**：`fix_joint_snap.py` 移除 5 个关节点的 SHRINKWRAP，并**烘焙当前求值位置**到 location（防止移除约束后弹回）。

## 中线点偏移根因 + 修复
**症状**：颈根/会阴偏离中线（实测颈根 x=-0.037、会阴 x=+0.021），头顶恰好对称所以没事。
**根因**：`SHRINKWRAP NEAREST_SURFACE` 沿模型真实（不对称）表面法线投影，把中线点带偏。
**修复**：在中线点约束栈里，Shrinkwrap **之后**追加 `LIMIT_LOCATION` 钳制 X=0。Blender 约束按栈顺序求值——先吸附表面，再钳制 X，既贴皮肤又严格在中线。修复后颈根/会阴 x=0.000。

## 镜像脚本要点
`mirror_rig_markers.py` 镜像出的 L 侧**关节点同样不加 Shrinkwrap**（与 R 侧一致），否则重蹈"吸附阻止放关节中心"的覆辙。且需排除意外混入的中线点（`abs(o.location.x)>0.01` 过滤）。

## 提示牌文字朝向（渲染实测验证）
- 默认 `rotation_euler=(0,0,0)` 是**平躺面朝上**，正面视图看是一条线。
- 正视相机在 **−Y 看向 +Y**（模型正面朝 −Y），文字法线须朝 **−Y** 才正面可读 → `rot_x = +90°`（+1.5708）。
- **坑**：`rot_x = -90°` 会看到文字**背面（镜像）**。必须用 Workbench 渲染图实测验证方向，别凭感觉。

## -b 后台模式视口持久化能力
- ✅ **能持久化**：`shading.type`（MATERIAL）、`region_3d.view_distance`、`view_location`、`view_rotation`、`view_perspective`(ORTHO)。遍历 `bpy.data.workspaces → screens → areas(VIEW_3D) → spaces[0]` 设置。
- ❌ **不能**：`tool_set_by_id`/工具状态在 `-b` 下会 C 级崩溃（ACCESS_VIOLATION，Python 捕获不了）。改用场景内中文文字牌提示"按G切换移动工具"。

## 打点后必做：用模型几何校验关键点
**实测案例**：用户打的会阴点 x=-0.078，但模型真实胯部中点（实测 13905 个顶点）在 x=0.000，左右完全对称（左-0.103/右+0.104）。会阴点是 Hips 旋转轴心基准，偏 7.8cm 会让骨盆轴心偏左、两腿摆动不对称。
**做法**：绑定前对关键中线点用 `check_crotch_symmetry.py` 类脚本测模型几何对称性，发现用户点明显偏离时**主动提示用户**（给修正选项），而不是闷头用错误点绑定。

## 标记点颜色区分
用户反馈"点都是黑色、字也是黑色，没有黄红区分"。`Empty.color` 需在创建时显式设置（中线黄/右红/左蓝），且视口需"对象颜色"显示模式才可见。下次模板务必做颜色区分 + 提示牌文字用高对比色。
