# 高模修复准则（2026-08-03 胸口凸起修复失败教训）

## 核心教训：不要给标准修复管道加实验性步骤

标准管道（repair.py + adhesion.py，run_repair.py 一键运行）：
旋转矫正 → 居中接地 → remove_doubles(自适应阈值) → 溶解退化面 → 清理浮动碎面 → 填洞 → 非流形修复 → 去重叠面 → Laplacian平滑 → Taubin平滑 → 黏连修复(adhesion_pipeline) → 最终焊接(final_weld_for_qr)

## 本次失败过程（血泪教训）

1. **错误尝试**：胸口凸起 → 加了 `sculpt_smooth_chest`（法线翻转 + remove_doubles合并碎面 + 拉普拉斯平滑）。
2. **结果**：法线翻转把脖子根部(z=1.38)正常解剖结构（锁骨上窝，法线朝内是正常的）错误翻掉，造成 16.7mm 变形；肚子(z=1.00)出现 44mm 新错误。
3. **用户反馈**："不知道你改动了啥，胸口错误没变化，肚子上还出现了新错误"、"别雕刻了"、"翻翻之前的做法"。

## 正确做法

1. **先诊断问题类型**，再选处理方法：
   - 几何凸起（原始模型自带的异形结构）→ 局部雕刻平滑（只推凸起区域顶点，用环状参考面 15~40mm 避免自污染）
   - 法线朝向 → 只翻转目标区域的错误法线，绝不做全局法线翻转
   - 重叠面 → 用 `remove_overlapping_faces`（只删法线同向共面重复面）
   - 衣服-身体黏连 → `adhesion_pipeline`（推开近距面对）
2. **新方法引入新错误时立即回退**到标准管道。标准管道不能完美解决所有问题，但不会引入新错误。
3. **用户要求"翻翻之前的做法"时** = 回退到 run_repair.py 标准流程，不要另起炉灶。

## 关键技术细节

- **KDTree 陷阱**：`kd.balance()` 只在全部 insert 后调用一次，绝不能放循环里（117万次 balance 会卡死）。
- **对比模型时坐标必须一致**：修复模型旋转过（面朝-Y），原始模型面朝+Y，直接 KDTree 找最近点会全部错位（显示 50mm 偏差假象）。先对原始模型做同样旋转再对比。
- **获取主网格**：blend 文件里可能有默认 Cube（8顶点），`[0]` 索引会选到它。用 `max(meshes, key=lambda m: len(m.data.vertices))`。
- **blend 文件时间戳**：修改脚本后必须重新运行整个流程，blend 文件不会自动更新（用户发现 11:36 旧文件时明确指出）。
- **vision_analyze 大图失败**：PNG 太大（>1.4MB）会 400 错误，先 resize 到 960x540 JPEG。
- **bmesh 修改后**：`bm.to_mesh(obj.data)` 后要 `obj.data.update()`，然后 `bpy.ops.wm.save_as_mainfile()` 才能保存。
- **KDTree 插入后顶点坐标变化**：迭代平滑时每 N 次迭代要重建 KDTree（不能复用旧的，会报 "Trying to insert more items than KDTree has room for"）。
