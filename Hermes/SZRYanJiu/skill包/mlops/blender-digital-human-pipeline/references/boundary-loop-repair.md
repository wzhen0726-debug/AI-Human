# 边界环(rim/开口边界)的诊断与重建

适用: 用棱柱/平面切出开口(眼窝、嘴、任何洞)后边界不圆顺/有缺口/出现反面; 也适用于任何网格的开放边界修复。

## 0. 通用铁律(先读)
1. 用户报“看起来不对”时, **先确认他看的是哪个文件/版本**(查输出目录时间戳): 陈旧文件会造成假回归, 新流程的产物也常常还没生成。
2. 验收用**独立反向判据**, 与修复判据不同源; 量到数再报, 不只报 PASS。
3. 报告区分“皮肤上的缺陷”与“开口内部的正常现象”(洞内看到后脑反面是正常的)。
4. 存 `.blend` 前切回 OBJECT 模式, 否则文件以编辑模式落盘。
5. 后台任务的迟到通知可能对应已被后续运行覆盖的**旧产物**: 先查文件时间戳/重跑判据再下结论。

## 1. 先量四个直接判据(不靠眼睛、不靠 vision)
1. **环序与度数分布**: 取目标区开放边 → 建邻接表 → 走环。度数全 2 且“走到的顶点数 == 度数为 2 的顶点数” = 单一闭环; **1 度顶点 = 有一条缝**, **≥3 度 = 分叉/自触**。
2. **边界 XZ 自交对数**: 环投影到 XZ, 两两线段求交(排除相邻边)。>0 即“折返尖”——用户嘴里的“缺口/台阶”通常就是它, **不是**深度起伏。
3. **反面面计数**: 逐面 f.normal 与该面各顶点的“邻面法线平均”比, 点积 <0 = 反面。用户开 Blender 面朝向显示时看到的红块就是它。
4. **到目标(手描/设计)轮廓的 XZ 偏差**: 中位/p90/max, 判断边界是否真贴线。
5. **环上最长边**: 应与环平均间距同量级(0.2~0.3mm)。出现 mm 级甚至 10cm 级长边 = 有顶点被抽飞、面变成尖刺(用户描述为“拉伸出去了”)——先查深度采样与内外圈配对, 不要去调形状。

诊断脚本只读不保存; 每次改动后**五项全量重跑**, 不要只看被改的那一项。

## 2. 折返(边界自交)的成因与不可解性
沿单一方向(如 -Y)垂直切的边界, 遇到与切向近乎平行的陡面/鼓包时会“绕过去再折回”, 于是在 XZ 上自交。
- 表面去噪/降噪**修不动它**: 实测表面被改 0.7~1.6mm 而折角几乎不变。
- 本质约束: 边界点必须落在表面上; 要同时满足 (1) XZ 严格贴目标轮廓 (2) 3D 光滑, 当表面跨过该处存在 ~1mm 陡坎时只能二选一——**深度跳(折角) 或 XZ 偏(轮廓被咬一口)**。所以“换切割方向/换扫出方向”绕不开; 沿法向扫还会让相邻切割壁互相穿插, boolean 直接出垃圾。
- 剩下三条路: 改轮廓(局部内收/外移)、改表面(局部抹平陡坎)、或**重建边界**(见 §3)。内收要小到视觉上看不出来才可行(实测 1.5mm 就能在下睑看出被咬的缺口)。

## 3. 整圈皮肤带重建(推荐做法)
思路: 把 rim 内外一小圈皮肤换掉, 用目标轮廓重新缝一圈均匀面, rim 环直接等于目标轮廓。
0. **先取“目标轮廓每点的表面深度”**(内圈新顶点要用它): 沿 Y 射线打表面, 但**开口处射线会直接穿透打到后脑**(实测 y≈+99mm) → 深度被记成 10cm 级 → 缝出来的面被抽成长刺。规则: 命中深度做合理性检查(如 |y − 中心| > 30mm 判无效), 无效点用**邻居闭环插值**补上, 并打印“无效 N/M”确认。
1. **删带**: 沿目标轮廓向外 W(≈1.2mm) 删皮肤面。判据必须精确, 否则粗面区会连带吃出大洞(实测外眼角整片 10mm 皮肤被带走):
   - 面心距轮廓 < W → 删; 或
   - 面的**某条边真的与轮廓折线相交** → 删; 或
   - 任一顶点距轮廓 < W **且** 面心 < 2.5W → 删(专治“面心远但横跨轮廓”的粗面)。
   判据要能按侧/按部位开关——两侧地形不同, 同一条判据可能一边干净、一边吃洞。留安全闸(删面数上限、带宽上限)防越修越大。
   - **删带之前**先把带区域内 >0.8mm 的边细分到位: 粗面区(如外眼角)若先删带, 带边界会离轮廓很远 → 缝回来的面被拉长(与 §1.5 的长边现象同源)。
2. **带外缘细分**到 ≤0.5mm。否则缝合面里会出现 5mm 长条 → 又被判成“折返”。
3. **取带外缘边界环**。走不成单一闭环时: 删掉死端/分叉顶点周围的面重试(数轮), 并**打印所有环的(顶点数, 质心)**——靠它才能定位“副环在外眼角 dx+12/dz+4.5”这类问题区。
4. **内圈 = 目标轮廓本身**, 与外圈一一对应: 逐个外圈顶点求其在轮廓上的最近参数 → 沿外圈顺序解绕 → **单调化 + 最小步长** → 插值取点。三种配对法里只有这一种可用:
   - 纯等弧长重采样: 外圈点数 K > 轮廓点数时会绕回取点 → 重复顶点 → 环被撕开。
   - 按“绕中心的角度”配对: 会把洞口整个盖住(开放边变 0)。
5. **条带三角化**: 每 k 建 quad(inner[k], inner[k+1], outer[k+1], outer[k]) 的两条对角线三角; 三角失败就试**整块四边形**; 不要“换另一条对角线”(会把 rim 盖到自己身上, 边界只剩半圈)。统计“未能闭合格”数, 非 0 必须查。
6. **新面定向**: 逐面与其**非新建**的共顶点邻面的平均法线比对并翻转; 没有非新邻居时用“带外皮肤的平均法线”兜底, 否则留下反面。
7. 结束前切回 OBJECT 模式。

## 4. bmesh 坑(逐条是通用规则)
- `bmesh.ops.delete(context='FACES')` 会**保留与存活面共用的顶点** → 用“删面前后顶点集合”区分新/老顶点的判据必然失效, 改用几何判据(距离/相交)。
- “连续段”检测(找外弧、找 run)必须从**一个反类点**起算, 否则跨越索引 0 的同一段会被算成两段。
- `subdivide`/`delete`/`weld` 之后旧 BMVert 引用失效(`ReferenceError: BMesh data ... has been removed`): 每次操作后重新 `from_edit_mesh` + `ensure_lookup_table`, 用 `{v.index: v}` 映射取顶点, 不要用陈旧索引直接 `bm.verts[i]`; 会把引用弄失效的操作放最后(例如“事后拆分边长”要放到法线处理之后)。
- 删面判据只按“顶点贴近目标”会在粗网格区连带删掉一整片; 只按“面心”又漏掉横跨轮廓的粗面 → 必须两者兼用 + 面边与轮廓真求交。
- Blender 原生程序不认 `/tmp`, 脚本与输出写项目目录内。

## 5. 反向核验(必做)
- **反面**: 计数从 N→0, 并渲面朝向图确认红块位置。洞内的“后脑反面”是正常的, **皮肤上的反面才是缺陷**。
- **边界**: 度数分布全 2 + 单一闭环 + XZ 自交 0 + 到目标轮廓偏差 ≤0.2mm, 四项同时看。
- 终判留给用户在 GUI(面朝向显示 / 正视 / 斜视), 同时给数字。**不要用 vision 判“光滑度”**(多次把渲染锯齿误判成环不光滑、把眼球认成红材质)。

## 6. 无头渲“面朝向”(复现用户视角)
建两个材质: 0=蓝(正面) 1=红(反面); 逐面按 §1.3 的判据设 `material_index`; workbench + `color_type='MATERIAL'` + `light='FLAT'`; 正交相机 4~5cm 视野对准目标中心(**机位由目标 bbox 程序化定位, 不硬编码**)。再渲一张 `light='STUDIO'` 的着色图看形状。
