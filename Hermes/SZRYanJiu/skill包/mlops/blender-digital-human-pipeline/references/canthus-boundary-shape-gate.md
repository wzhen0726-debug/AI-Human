# 眼角/开孔边界形态缺陷：诊断、形态门与修环协议（QR 低模层）

适用：QR（02QR拓扑 环节）输出的低模在眼角（开孔边界）出现「长直弦横切折角、放射扇簇、尖角/尖刺、贴环微面」——
最小边长/三角/非流形/自交这类微面指标可以**全过**也照样发生（「数值好≠形态好」的典例）。
上游 rim 带（01a 输入侧）的坏面与环平滑度问题见 `references/rim-band-qa.md`。

## 0. 结论先行

- 病根 = 引擎对开放边界的**非确定重采样**（同一输入多轮：眼角折角被压成一根 5.9~11.4mm 长直弦；
  带顶点被塞到离环顶点 0.25~0.55mm 近重合处 → 贴环微面/极点簇/尖刺），**不是上游输入（01a）的问题**。
- 治理四件套 = ①形态门（进选优与验收）②修环（吸真值+微量插点+尖角开口）③顺序（修环排在建碗之后）
  ④交付件（含碗）复跑门。纯 QR 轮实测 0/9 过形态门 → 修环是必跑项；配多轮选优（N=3 ≈99%）兜概率。

## 1. 先量化复现用户目视，再谈修

每眼角单独算（窗口 ±5~9mm，按眼区半径推导）：环最大转角 / >40° 处数 / 最长直弦（及其跨过的真值弧长）/ 
切角偏离（直弦相对真值折线的最大偏差）/ 环点-真值偏差 / 针状面（内角<12° 面的最长边）；
极点价表只报告不门控（真值自身有极点）。

- 真值 = 输入高模的 rim 环（01_1 层）；
- 动手前，数字排序必须能**复现用户的目视排序**（哪件差、哪件稍好——用户判差的那件必须排到差端），
  复现不了说明量错对象或量错口径；
- 同机位特写渲染：固定正交机位 + 固定缩放（±5mm 高倍 + ±9mm 全景），2×2 四联图带标签对照。

## 2. 「是不是输入的锅」——三条判据（实测均为否）

1. 输入层环是干净的：闭环、边中位 0.22mm、最大转角 ~20°、带内无窄面无极点；
2. 同一输入多轮：缺陷**逐轮漂移**、rim 采样点数每轮都不同（实测 7 轮取到 25~41 点共 7 种值）
   → 引擎非确定；输入若为病因应稳定复现同处；
3. 「修输入」全是反例：边界粗化 → BadInput；FreezeBorders → 面数爆炸（见 `references/qr-engine-knobs-and-boundary-limits.md`）。

→ 不要为这个问题去动 01a 输入/轮廓/倒角/带行。

## 3. 形态门（选优 + 验收共用）

| 项 | 阈值 | 说明 |
|---|---|---|
| 环最大转角 | ≤ 40° | 折角被直弦截平的直读量 |
| 切角偏离 | ≤ 0.30mm | 直弦相对真值折线的最大偏差 |
| 最长环边 | ≤ 8.0mm | 粗闸，专抓 11mm 级直弦 |
| 环点-真值偏差 | ≤ 0.40mm | 环整体贴合度 |
| 针状面(内角<12°)最长边 | ≤ 1.5mm | 尖角/尖刺 |

- **标定协议**：把历史全量件（各轮原始、各种修复件、真值、用户判过「差/稍好」的件）过一遍门，
  要求与用户目视排序**完全一致**（用户判差的必须 FAIL）。
- **只量微面指标的选优门会选中肉眼最差的轮**（实测：按最小边长择优取到四件里目视最差的一轮）
  → 选优门必须含形态量，且跑在**交付件（含碗）**上，不只中间件。

## 4. 修环协议（顺序：QR → 建碗 → 修环 → 并眼球）

1. **只移动/吸真值**：环点沿真值折线按弧长重排（点数不变）。单靠移动吃不掉 5.9~11.4mm 级直弦
   （±0.5mm 内移动实测无效）→ 与 2 组合。
2. **微量插点**：只在长弦/大转角/密度失衡处拆段（每环 ≤12 点量级；**参考必须用输入高模环**，
   用 json 折线更糟）。守门：单闭环 / 非流形不增 / 退化不增 / 自交不增 / 边界边不变 / 不新增 <0.15mm 短边
   （修复会引入少量 0.2~0.5mm 短边，属已知残留）。
   参数草案（env RS_*）：INS_MAX=12 / SEG=1.6mm / KINK=30° / WIN=12mm / MIN_DEV=0.15mm / MAXMOVE=1.5mm / FOLD=0.25mm。
   上正式前按 `pipeline-parameter-liveness` 审计：窗口/阈值/距离随模型尺度（身高/眼区半径/环自身边长）推导，别留死毫米。
3. **尖角开口**：把针状面小角顶点在窗口内推开（不动环点；env NO_*：ANG=12°/TARGET=18°/ZONE=9mm/STEP=0.12mm/MAX=0.6mm）。
   若小角顶点锚在 rim 环上，动旁邻会涨自交 → 该轮放弃（交给选优淘汰，别硬修）。
4. 实测（用户轮）：L外 49.0°→23.7°、弦 5.87→2.61mm；L内 83.7°→17.3°、切角 1.465→0.104mm；R外 69.3°→19.1°。
5. **任何加做的手术都要复跑形态门**：修环后再叠「推开近重合」曾引入共线窄面（0.00° 内角）→ 否决。

## 5. 工序回落（最容易白做的一步）

建碗收尾自带 1.5mm 级微焊接：修环若排在建碗**之前**，眼角细点会被焊掉——实测整段回落：
L外 23.7°→67.2°、切角 0.121→1.151mm（间距改 2.0mm 也无效）。**修环必须排在建碗之后**，
且每次改动后对「交付件（含碗）」复跑门，别只看中间件的数字。

## 6. 被否方案（别再走一遍）

- 材质引导（rim 外 2 排独立材质槽 + UseMaterialIds=1）：带最小边 0.017mm（比病处还差 15 倍）、带内三角 8、
  FBX 导出 ~1min→~11min。
- 输入侧带行重建/微倒圆：历史与本轮数据均更差（不要为形态问题去动输入）。
- 扩大化「同疗」外科：只治贴环微面，直弦不动；不做形态修复就没有形态收益。
- CurvatureAdaptivness/DensityMap 只降概率、不给保证（边界不响应密度图，见 `references/qr-engine-knobs-and-boundary-limits.md`）。

## 7. 工具与残留

- **多轮 QR 严格串行**：引擎临时目录全局共用，并发会串产物；每轮独立输出根 + 独立**纯 ASCII** 临时目录（含中文路径 → BadInput 秒败）；跑前查无残留引擎进程。
- 工具稿（沙箱定稿，**以正式入库版为准**）：形态量 `morph_metrics.py`（env MM_BLEND/MM_OUT/MM_LABEL）、
  形态门 `rim_canthus_shape_gate.py`、修环 `rim_snap_truth.py`（RS_*）、开口 `needle_open.py`（NO_*）、
  同机位特写 `render_eye.py`（RN_*）。渲染/合并脚本对原生 Blender 必须传**绝对路径**（相对路径会解析到 C:\ 盘根）。
- 已知残留（未闭环）：碗-带交界处个别窄面（小角顶点落在建碗焊接过的环点上）；修复引入的 0.2~0.5mm 短边待压平；
  「针面锚在环上」型轮次的专项处理。
