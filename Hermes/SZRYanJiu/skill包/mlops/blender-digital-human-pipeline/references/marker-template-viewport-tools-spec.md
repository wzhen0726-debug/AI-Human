# 半自动打点模板：视口/工具/坐标读取 完整规范 (2026-08-26)

模板文件 `06_rig_markers.blend` 打开后必须"即开即用"。以下为所有需配置项与已验证做法。

## 1. 视口参数（全部可在 -b 后台持久化）
- `shading.type = 'MATERIAL'`
- `view_distance = 3.0`，`view_location = (0, 0, 0.9)`
- `view_rotation = Quaternion((1,0,0), 0)`（正视）
- `persp = 'ORTHO'`
- **注意**：视口基础参数可存，但**复杂布局拆分/激活工具存不进**（见下）

## 2. 激活工具（移动工具）— 后台无法预设
- `tool_set_by_id` 在 -b 模式下 C 级崩溃，`active_tool_id_name` 属性不存在
- **替代方案**：在场景里放一块中文文字牌（FONT 对象），提示用户"按 G 切换移动工具"
- 文字牌必须**竖立朝前**：正视相机在 −Y 看 +Y，`rotation_euler.x = +math.pi/2`（−90° 会镜像）

## 3. 标记点颜色
- 用户反馈"点都是黑色，没黄红区分"→ 颜色必须**按集合分组**：
  - LM_M（中线）= 黄 `(1.0, 0.9, 0.2)`
  - LM_R（右侧）= 红 `(1.0, 0.2, 0.2)`
  - LM_L（左侧）= 蓝 `(0.35, 0.5, 1.0)`
- **关键**：Empty 的颜色在 Workbench/非材质预览着色下可能显示为黑；渲染验证时要用带颜色的球体替代或确认着色模式

## 4. 吸附约束（Shrinkwrap）— 分两类
- **表面点**（头顶/颈根/会阴，中线）：加 `SHRINKWRAP + LIMIT_LOCATION(锁X=0)`，贴皮肤
- **关节点**（肩肘腕膝踝）：**不加吸附**（关节在肢体内部，吸附会阻止放到关节中心 → 骨旋转轴心偏到表面 → 蒙皮变形异常）
- 用户反馈"肩膀打到前束表面"就是这个根因

## 5. 读取标记位置 — 必须读求值后坐标
- **错误**：`pos = m.location.copy()` → 读的是**原始坐标**，不应用约束
- **正确**：`pos = m.matrix_world.translation.copy()` → 读约束求值后的"所见即所得"
- **根因事故**：会阴点用户已调回中线（x=0），但原始坐标还偏左 −0.078 → 骨骼建在偏左位置 → 腿不对称。**必须读 matrix_world。**

## 6. 镜像 — 实时驱动器，非静态副本
- 静态副本 = 生成后与 R 侧脱节 → "两套点"+"不能同步"
- **正确**：L 点 location 三轴加驱动器（`L.driver_add("location", i)`），x 取反、y/z 跟随，`hide_select = True` 锁定防误碰
- 驱动器本体在 `fcurve.driver`（不是 fcurve 本身）
- 验证：临时挪 R 点 → 检查 L 点实时跟随 → 立即还原

## 7. 参考 01A 模板的完整清单
`01A眼窝与眼球/scripts/place_eyelid_markers.py` 是模板源头。必须全参考：
1. 初始位置=实测数据
2. 只标 R 侧+中线，L 侧镜像
3. Empty 球 + show_in_front
4. 中英文命名 `LM_01_头顶_headtop`
5. Shrinkwrap 吸附（仅表面点）
6. 空 `LM_L` 集合等镜像

## 教训
- 视口配置、颜色、工具、坐标读取、镜像方式——任何一项漏掉，用户打开模板就"不能用"
- 所有"打开即可用"的处理必须在后台脚本里固化，不能依赖用户手动设置
