## 一、QR 边界已经精确 —— 不要做 RimFit

当高模上存在**真实网格边界**(boolean 切出的眼洞), xremesh 会把低模新边界**吸附到它上面**。
实测(同一套 01→04 产物): 低模孔环 ↔ 高模切口环 **3D 距离 mean 0.00 / p95 0.01 / max 0.04 mm**(左右眼同), 周长比 0.99。

- 所以「把手描轮廓当 guide 把低模环拉过去」是**倒退**: 会把边界从真实曲面上扯下来 → 表面失配 → 烘焙/法线随之错。
- 真正的 rim 偏差在上游: 轮廓低通(K=2)自身对 手描轮廓 max 2.96 mm; rim 带重建再外扩 ~1.2mm → 切口周长 89.1mm vs 手描 81.9mm(**+8.6%**)。
- 结论: rim 问题在**切割环节**诊断, 不在 QR。
- 验证方法: 用 `boundary_loops()` 提取两侧开放边界闭环(按位置/点数配对), 逐点算 3D/XZ/y 三个口径的距离。

## 二、眼窝「黑」通常是法线贴图, 不是漫反射

大 cage 是**必要**的(碗面法线朝前, 射线要从脸前回程才能命中眼睑):

| cage | 背向命中 | 命中点在眼球之前 |
|---|---|---|
| 1 mm | 80.6% | 20.0% |
| 20 mm | 53.5% | 51.0% |
| **99.5 mm** | 2.1% | **98.0%** |

但碗面法线在眼角处几乎平行于脸面 → cage 起点横向偏出近 100mm → 命中眉/鼻/颊的陡面:

- 碗区烘焙法线 vs (0,0,1): **mean 83.9°, p95 150.8°, >30° 占 72.4%**
- 身体其它区: mean **2.96°**, >30° 占 1.4%(同一测量方法, 身体数据即方法自校)
- 碗区命中面同向率仅 0.63(身体 0.98), 命中距离 mean 71.6mm(身体 20.0mm)

→ 涂漫反射肉色**修不了**法线。正确修法 = **沿眼轴(-Y)的几何重投影**取 Diffuse+Normal;
验收用独立口径: 碗区法线与 (0,0,1) 夹角 mean<10°、>30% 占比<5%, 且隐藏眼球时碗内有真实纹理。

## 三、真值层: 判定修复层有效性的唯一可靠判据

```
texel 中心 → UV 三角形 → 3D 重心插值 → 低模表面点 P + 平滑法线 N
          → 起点 O = P + N·cage → 沿 -N 射线 → 高模 BVH 首命中
          → 命中三角形 3D 重心 → 命中面 UV 重心 → 高模 basecolor 真值色
```

再跟第 2/3 层命中(<8mm 内还有一层且颜色差 >0.12 = 薄壳/骑跨), 并对"被后处理改动过的 texel"
比较 `|烘焙−真值|` 改前 vs 改后。**这是唯一能证明修复层有效或有害的判据**, 它不依赖修复层自己的假设。

自校(必做): 命中面与射线同向的 texel 上 烘焙 vs 真值应高度一致 ⇒ 射线模型可信。
实测: 中位亮度差 **0.0048**, 99.19% 在 0.05 内, r = **0.997**。

## 五、参数/API 坑(都踩过)

- `BVHTree.ray_cast(origin, dir, 0.0)` = **零长度射线**(静默 100% miss); 不传 distance 才是不限。
  而 `bpy.ops.object.bake(max_ray_distance=0.0)` 相反, 0 = 不限。同一个 0, 两个 API 含义相反。
- PIL 第0行 = 图像顶部; `Image.pixels` 第0行 = v0(底部) → 比对前必须 `[::-1]`。
  不翻会得到"看起来很合理但全错"的统计(曾造出假的 −0.23 亮度偏置、只有 16% 一致率)。
- `np.mgrid[y0:y1+1, x0:x1+1]` 返回**绝对索引**, 索引目标数组时不要再加 x0/y0。
- 高模 basecolor 要按"真正连到 Principled Base Color 的图像节点"找, 不要按文件名关键词猜(可能命中 normal/roughness)。
- 8bit sRGB 图像的 `image.pixels` 是原始编码值(与 PIL 读同一 PNG 同空间), 可直接互比; 混入 linear 会引入假偏置。
- 逐 texel 追踪成本: 4096² 的 1.3M texel × 3 层命中 ≈ 5 min(Python + mathutils BVH), 进度写固定日志文件。
