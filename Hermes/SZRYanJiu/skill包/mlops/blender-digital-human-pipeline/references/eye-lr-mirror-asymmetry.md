# 左右眼不对称：镜像侧必须按自身几何取轮廓

**症状**：一侧外眼角反复偏弱/内收/拥挤；多轮几何修复、多组方案比选后"仍然是同一侧差"。这是"一手标 + 一镜像"打点方式的固有病：镜像假定脸左右对称，而扫描脸不是。

## 机制（实测，人体尺度）
- 脸本底不对称：眼区绕轴镜像最近距离 中位 0.49mm、p90 0.97mm，外眼角区最差（中位 0.40）——**任何轴都消不掉**（换最优轴/加平移/加旋转后仍是 0.49mm 级）。
- 镜像侧轮廓装配错位：1.1–1.3mm（三种独立量法同向：外观分区互配 / 贴图瞳孔质心 / 轮廓–虹膜偏移）→ 该侧眼角整条落在真实睑缘内侧，看起来"偏内偏软"。
- 几何最优轴 ≠ 眼睛特征最优轴（实测差 ~0.6mm）→ **继续调轴是错方向**。

## 规则
1. **镜像侧轮廓按该侧自身几何生成**，不靠调镜像轴补救：把修正落成"眼区镜像轴覆盖"env（`EYE_EYE_AXIS_MM` 这类；默认不设=历史行为，可回退、可复现），不要写死点数据。
2. **眼球每侧锚定**：眼球 x 取"该侧自身"的 3DDFA 虹膜锚推导（`EYE_EYEBALL_ANCHOR=e3` 这类；推导式，禁止硬编码坐标）。只改有问题的一侧，另一侧保持已验收口径。严格对称摆放会在不对称脸上再叠 ~1mm 级错位（该侧虹膜在开口内偏内）。
3. **重跑放点/手调步时带上覆盖 env**，否则修正会静默回落到旧镜像路径。（等价近路：让用户把另一侧也手工打点——精度更高、无需 env。）
4. 修后"环质心左右差"变大属设计使然（该侧不再镜像等于对侧），别当回归。

## 感知对齐验收门（局部网格质量门看不见这些）
最小边/面积/细长面/自交/极点这类局部门**看不见开口轮廓的位置与尖度损伤**——实测有方案数值最漂亮却肉眼最差（倒圆类平滑把眼角尖点往里/下拽 0.3–0.55mm、尖度掉 11°、新造 1mm 级左右差）。必加：
1. **解剖相对失配** |环质心 − 本侧虹膜锚| 的 L/R 差 ≤0.3mm（旧 1.14 → 修后 ~0.17–0.23）。
2. **眼角尖点 Δz(L−R)** ≤0.3mm（01A 层口径；QR 层有引擎跑次 ±1mm 浮动，不作验收口径）。
3. **尖度左右差** ≤5°（2mm 弧三点夹角）。
4. 眼角区修复若用"整平/倒圆"类平滑：单用会把尖点磨钝（对照实验里"仅倒圆"肉眼最差），要么不用、要么与重建合用并让上面三条把关。

## 效果参考
- 修后：解剖失配 1.14→0.165–0.225mm（降 ~85%）；眼角盒最小边 0.274→1.008–1.36mm、细长面 3→0；左右尖度差 −9.7°→−3.6°。
- 回退点：备份 + md5 清单；env 不设即历史行为。
