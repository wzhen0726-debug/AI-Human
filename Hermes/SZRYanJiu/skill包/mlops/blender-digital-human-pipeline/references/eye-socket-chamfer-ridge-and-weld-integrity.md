# 眼窝倒角凸脊(M形线)消除 与 焊接完整性验证 (v46i~v47)

01A眼窝管线 `socket_ops.py` make_eye_cup 阶段的两个结构性问题及定案方案。

## 1. M形凸脊根因

倒角环**先向外扩 W 再向内收缩**，扩到最大的那一圈（ring F）形成一圈**凸脊**——用户在 GUI 看到的"M形边"。注意区分：
- v46i"合并环"（倒角带+碗面从 ring0 一次成型连续环序列，删 ring1 分界）解决的是**两段网格拼接的分界线**，vision 线框图确认分界线消失；
- 但**凸脊仍在**（几何上外扩段必然产生脊），用户 GUI 复核仍看到 M 边 → 必须再处理。

## 2. 凸脊两方案 (v47, config `SOCKET_VARIANT` 开关)

- **A `no_chamfer`**：F=0, W=0, D=0，碗面从 rim 直接单一 smoothstep 收缩下沉（无外扩段→无脊）。拓扑简洁（16环×M），但**内眼角有小皱褶/pinch**。
- **B `chamfer_relax`（推荐）**：保留倒角（F=8），对内部环顶点做 **Jacobi Laplacian 松弛**（ring1~末环全动；ring0 已缝合皮肤、碗底 pole 锁住），λ=0.5、8 轮。实测全顶点移动、最大半径下降（R眼 18.06→17.58mm），凸脊被磨圆。

### 松弛代码要点（真实 bug 教训）
- **锁定集合必须用 `id(v)` 不能用 `v.index`**：新建顶点后未 `ensure_lookup_table()`，v.index 过期/冲突 → 第一版所有内部顶点都被误判为锁定，一个都没动（日志"最大半径不变"就是证据）。改用 id() 后全移动。
- Jacobi 式：每轮先用旧坐标算全部 delta 再统一应用，防不对称漂移。
- 加逐轮"移动 N/M 顶点+最大半径"打印——松弛是否生效一眼可查。

## 3. 焊接阈值 vs 最小顶点间距（v46j 事故）

碗底末环收缩到 10%（半径≈1.2mm）后，84 顶点环间距 = 2π·1.2/84 = **0.09mm < remove_doubles 阈值 0.1mm → 正常顶点被焊坍缩**（极点三角扇 84→55）。
- **规则：焊接阈值必须小于最小正常顶点间距**。设计收缩环时验算 `间距 = 2π·末环半径/M`。
- 修复：收缩到 25%（间距 0.22mm > 0.1mm 安全）。碗底也不需要更高密度。

## 4. 重复顶点检测必须 KD-tree 精确（≤0.01mm），禁网格哈希

- 0.1mm 网格哈希把密集区正常相邻顶点误报为重复（"50个重复"全是误报）→ 按误报焊接 → 极点扇坍缩（74→58）。
- 正确做法：`mathutils.kdtree` `find_range(co, 0.00001)`；并用 v44tag 层归属区分"新结构问题 vs 高模自带老问题"。
- **焊前先用精确距离+连线方向分类**：真重复 <0.02mm；密集环相邻顶点 >0.05mm（连线沿切向）不能焊。
- 检查脚本自身也要验证（本次误报源于检查方法，误焊才暴露）。

## 5. 眼窝局部完整性验证套件 (check_integrity_local.py)

眼窝**不是独立对象**——直接合并进高模 mesh（OUT_BLEND 只有一个 MESH 对象），全局检查会被高模自带的 48831 个老重复点淹没。必须眼中心半径 30mm 局部检查：
1. KD-tree 重复顶点（0.01mm，含 tag 归属）
2. 游离点 / 退化面（面积<1e-12）
3. 非流形边（内部边恰 2 面共享）
4. **边界边 = 0 = rim 完全缝合**
5. 碗底极点扇完好性：眼中心径向<0.5mm 最深处顶点应连 **M 个三角面**（L=84/R=74）

## 6. 线框图 vision 误报

vision 有时把健康的细线框渲染判为"炸点/严重异常"。定量完整性通过时，用 **PIL 对比已知良好版本**（暗像素占比+径向 8 带分布，逐带一致即结构等效），不采信 vision 单次判断。素模（clay）图比线框图更适合 vision 判断凸脊/分界线。
