# 眼窝 M 形环线修复（v46g）— 碗面极点收敛拓扑错误

## 问题现象
用户素模线框模式下发现眼窝内部（非眼窝缝）有一圈明显的 M 形/唇珠状环线，线内面分布极度密集且向中心极点收敛，与眼窝缝到 M 形线之间的均匀面分布完全不同。vision 确认：
- M 形线是**几何环线**（真实网格边线），非 UV 线
- 位于眼窝缝内侧第一层内壁环线处（倒角带与碗面交界）
- 内部"放射+同心环"拓扑向中央黑色极点收敛，环线越来越密
- 顶部有折角凸起，呈方折/M 形锯齿

## 根因分析

### 1. 碗面极点三角扇拓扑错误
`make_eye_cup` 的碗面设计：从 ring1（倒角带内环）开始，24 环逐渐收缩到单个共享极点顶点，形成三角扇封底。这导致：
- **ring1 处面分布突变**：倒角带均匀分布 → 碗面密集分布
- **极点收敛**：所有径向线向中心极点汇聚，形成"放射+同心环"密集拓扑
- **素模线框下显示为 M 形错误环线**：极点三角扇的环线在素模下被视觉放大

### 2. 为什么之前修倒角带曲线没解决
之前尝试改倒角带过渡曲线（1/4圆弧→smoothstep→sin+smoothstep→quintic），都没解决 M 形线，因为根因不在倒角带，而在**碗面从 ring1 收缩到极点的拓扑结构**。

### 3. 用户反馈的关键线索
- "M 形内的面分布跟眼窝缝到 M 形之间的面分布完全不同"
- "M 形环线附近有很多很密集的线"
- "眼窝只需要蓝色的眼窝缝，里面那个 M 环形就是个错误结构"
- "眼窝缝倒角要做到蓝色的线上，眼窝缝内的眼窝布线也要均匀"

## 修复方案（v46g）

### 核心修复：碗面改为环形网格
把碗面从"收缩到极点"改成"环形网格+最后 5% 快速收拢到小圆盘"：

```python
# v46g: 碗面改为环形网格(消除M形环线/极点收敛).
# 根因: 原设计碗面从ring1收缩到极点, 导致ring1处面分布突变(倒角带均匀→碗面密集),
#       且极点三角扇形成"放射+同心环"的密集拓扑, 素模下显示为M形错误环线.
# 修复: 碗面用cosine剖面(两端平缓), 最后5%快速收拢到小圆盘, 消除极点收敛.
vgrid = [list(ring1)]
NR = 24  # 环数
for j in range(1, NR + 1):   # 环1..NR, 最后NR环收拢成小圆盘
    t = j / NR
    if t < 0.95:
        # 正常环形: 半径缓慢收缩, 深度均匀增加
        s = 0.5 * (1 - math.cos(math.pi * t))  # cosine, 两端平缓
        scale = 1.0 - 0.9 * s    # 半径收缩到10%
        depth_frac = s            # 深度均匀增加
    else:
        # 最后5%: 快速收拢到小圆盘
        u = (t - 0.95) / 0.05    # 0..1
        scale = 0.1 * (1 - u)    # 10%→0%
        depth_frac = 0.95 + 0.05 * u
    row = []
    for i in range(M):
        base = ring1[i].co
        x = center.x + (base.x-center.x)*scale
        z = center.z + (base.z-center.z)*scale
        y = base.y + (rim_y + max_depth - base.y)*depth_frac
        row.append(bm.verts.new((x,y,z)))
    vgrid.append(row)
# 碗底小圆盘: 中心点
pole = bm.verts.new((center.x, rim_y + max_depth, center.z))
```

**关键点**：
- 碗面用 cosine 剖面（两端平缓），半径收缩到 10%（不是 0%）
- 最后 5% 快速收拢到小圆盘（直径约 1mm）
- 消除极点收敛，面分布均匀

### 为什么这个方案有效
1. **消除极点三角扇**：碗底从"单个极点+三角扇"改成"小圆盘"，消除放射+同心环密集拓扑
2. **面分布均匀**：cosine 剖面让半径收缩平缓，面分布从倒角带到碗面连续过渡
3. **素模线框下不显示 M 形环线**：没有极点收敛，没有密集环线堆积

## 血泪教训
1. **素模线框模式是检验拓扑结构的最好方式**——M 形环线在实体着色下不明显，但在线框下清晰可见
2. **极点三角扇是拓扑灾难**——任何"收缩到极点"的设计都会在素模下暴露密集环线
3. **面分布均匀性比曲面平滑更重要**——用户明确"眼窝缝内的眼窝布线也要均匀"，不是只追求曲面平滑
4. **vision 是定位拓扑问题的关键工具**——之前多次修倒角带曲线都失败，vision 一次就定位到 M 形线是几何环线而非 UV 线
