# 半自动打点模板：重复点根因与三集合结构 (2026-08-25根因定位)

## 症状
用户打开打点模板发现：左右两边各一份侧别点都要打（本该只打右侧），且**中线点（头顶/颈根/会阴）也出现了两份**——同位置两个球。

## 根因（两层源头缺陷）
1. **模板脚本**：中线点和 R 侧点混在同一个 `LM_R` 集合
2. **镜像脚本**：无差别镜像集合内全部 8 个点。中线点没有 `_R` 后缀 → `replace("_R","_L")` 失效 → 走 `+_L` 分支 → 同位置产生 `LM_01_头顶_headtop_L` 重复

## 修复（源头结构，不是删重复点）
三集合分离：
- `LM_M`（黄）：中线点 3 个，**永不镜像**
- `LM_R`（红）：右侧点 5 个，用户只打这一侧
- `LM_L`（蓝）：镜像脚本生成

镜像脚本加双保险：
```python
r_objs = [o for o in r_coll.objects if o.type == 'EMPTY']
r_objs = [o for o in r_objs if abs(o.location.x) > 0.01]  # 排除意外混入的中线点
```

## 教训
- 镜像类操作必须区分"可镜像点"和"中线点"，不能假设集合内全部点都是侧别点
- 命名后缀（_R/_L）要作为结构属性从一开始就带对，不能靠镜像时字符串替换兜底
- 打点数量设计：中线 3 + 一侧 5 = 用户只需打 8 个点，其余 5 个脚本生成
