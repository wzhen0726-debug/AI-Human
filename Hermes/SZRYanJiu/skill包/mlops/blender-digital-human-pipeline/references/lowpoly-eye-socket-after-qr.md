# QR 后低模碗状眼窝重建 (02qr_socket_cup.py)

## 何时用
02 QR 输出的低模上, 眼孔=开放边界环; 需要"眼球坐进去"的碗状眼窝(有碗面)。

## 用户定案规格(不可自由发挥)
- 眼窝内 = 同心环线: 从 rim 环【保持其形状】等比缩小(8圈: 0.90→0.15), 保持眼窝曲率, 最后收敛到【单极点】(三角扇)。
- ❌ n-gon 平底盖(低模上=一块拉长平板, 用户称"花生仁")。
- ❌ 用角度重排做"均匀化"(解绕后向均布角过渡): 破坏环与环的对应 → 环线打断/中心挤团, 用户实测否决("还不如上一版")。
  环线等比缩小本身就是要的秩序; 外圈不均 = rim 共享顶点间距的固有属性, 要治只能纯切向松弛 rim(须用户点头)。
- 改动用 git 管好: 用户认可的版本=冻结基准(commit+记数值), 回退用 `git checkout <commit> -- <file>` 后重建并核对数值完全一致。

## 深度与球体参数(全随动, 禁写死)
- 深度优先【逐点射线采样高模旧碗】: `_eye_cup_ref.blend` = 01_1 副本跑旧版 `make_eye_cup` 的产物(碗面 = v44tag_L/R==2 面层),
  从 (x, y_face-60mm, z) 沿 +Y 射线取 y; 打不到则回退"眼球同心球 + 1.5mm 间隙"。
- 眼球球心 = 对象【bbox 中心】, 半径 = 到该中心距离的 p90。
  ⚠ 顶点均值不是球心(角膜侧顶点更密, 均值被带偏~3.8mm → 半径谱虚胖 6.9~18.7 → 据此取 max 会把碗撑到比可见球面深 5mm+, 用户报"深洞里一条红胶囊")。
  正确性标志: 半径谱紧致([10.6~14.9] ≈ 配置里独立标定的 14.56)。

## 三大硬陷阱(全踩过)
1. **镜像网格绕序**: L/R 孔环的拓扑走行方向相反 → 同一建面顺序必有一侧整体反(用户看到整碗红)。
   修: 绕序种子法 —— 每侧取环上第一条与头模面共享的边, 按"流形一致(共享边两侧走相反方向)"定该侧顶点顺序;
   所有环带 + 封底(含极点扇)都沿用同一约定。
   全模型【禁用】`bmesh.ops.recalc_face_normals`(按连通岛整体重定向, 实测把左腿 245 面翻掉)。
2. **BMFace 引用失效**: 建面后若再跑 remove_doubles/holes_fill, 先前收集的 BMFace 列表失效(tag 只剩个位数)。
   tag/记录必须在【建面当刻】做; 需要索引时先 `bm.faces.index_update()`(新面 index 默认 -1)。
3. **子进程 Blender 的 print 默认缓冲**: 脚本头加 `print = functools.partial(print, flush=True)`, 否则卡死时 LOG 只有文件读取行、无法定位(实测一次 BFS 卡死 9 分钟靠它定位)。

## 自检清单(多轮)
- 翻转面(与邻域平均相反): 腿部/全身 = 0。
- 相机判据(正前+略俯视, 与 Blender 面朝向 overlay 同原理)必须用【渲染】判: 可见面应 100% 蓝、零可见红;
  数值标记的背对面若被遮挡=无害 —— 只数数值会把被遮挡面误报成问题, 只信渲染的"可见红"。
- 开放边 = 0、单一闭环、眼球(全点)到碗面最小距离 > 0。
- 反例归档: 固定角度圆形化→0.01mm sliver; 角度均布→环线破坏; 全模型 recalc→腿 245 面翻转; 顶点均值当球心→"深洞胶囊"。
