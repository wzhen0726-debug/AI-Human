# 04 烘焙后贴图清理 v3/v4/v5（2026-09-21 定案）

背景：04 烘焙（selected-to-active, cage/ray 按 bbox 比例）后，diffuse 贴图残留三类缺陷，
用户报为"黑面/锯齿/噪点"。texture_fix.py 现有 v1(溢出)/v2(网格引导异常斑) 均覆盖不到，
新增 v3/v4/v5 三个函数，全部在 04_bake.py 的 try 块内顺序调用，任一失败不阻断管线。

## 三类缺陷与判据

1. **v3 皮肤区深色条纹/黑面**（如肩部黑条纹，用户红圈）
   - 根因：烘焙射线在皮肤凹陷/褶皱处打偏；v2 的 head_ratio 高度截断把肩/头排除在外。
   - 判据：面 3D 邻域皮肤占比≥0.85 + 亮度偏差<-thr（模型自身 MAD 统计）；
     保护 = 发际以上(z>0.90H)整体 + 头列(|x|<0.10H)内小暗簇 bbox 柱（眼/鼻/口/眉）。
   - ⚠ 保护盒种子必须限头列，否则肩部条纹会自建保护盒逃过清理。

2. **v4 衣物岛内皮肤色碎点**（贴图层）
   - 判据：皮肤色小簇(≤600px) 且 4px 膨胀邻域内衣物色占比≥0.60。
   - ⚠ 实现必须 bbox 切片膨胀（全图逐簇膨胀 4K 会 300s+ 超时）。
   - 局限：岛边界邻接处邻域含空 margin/皮肤岛 → 漏检；领口虚线查不到（见 v5）。

3. **v5 衣缘骑跨误采样 = 领口/袖口浅色虚线（最终正解）**
   - 根因：薄衣缘面烘焙射线穿透薄边打到内侧皮肤 → 低模采样=皮肤色，
     而高模同位置真值=衣物色。贴图层(v4)/邻域统计(v5旧版)判据都会误伤真皮肤面。
   - **唯一无歧义判据 = 高模真值**：低模面心→BVH 高模最近面(距离<0.4%对角线)→
     高模面 UV 采样高模贴图=真值；真值=衣物色(暗且冷调 b≥r-10) 且 低模采样=皮肤色 → 替换为真值色。
   - 采样必须 **UV 三角形 7 点中位数**（3顶点+3边中点+中心）：细长三角形/QR 面心常落在三角形外，
     单点中心采样会采到邻岛色 → 假真值（实测 3034 面误报的根因）。
   - ⚠ **Blender image.pixels 行0 = v=0（底边）**，与 PIL/PNG（行0=顶）相反：
     用 pixels 数组索引时 y = v*hh，不是 (1-v)*hh（上下翻转=头部真值取到腿部，实测 25081 面误报）。
   - 保护：发际以上(z>0.90H)不动（头发暗色易误判为衣物色）；全局上限 0.5% 面数，超则不写回并告警。
   - 写回：只替换三角形内皮肤样像素+1px 过渡环（保留三角形内正常衣物 texel）。

## 衣物色/皮肤色定义（本项目背心为蓝灰）
- 衣物色 = lum<60 且 b≥r-10（冷调/低饱和）；皮肤阴影是暖暗(r>b+15)不算衣物——
  只用 lum<60 会把颈部/腋下阴影误判为衣物（实测假阳性根因）。
- 皮肤色 = r>140,g>100,b>70,r>g（或像素级 Mahalanobis ≤2.5σ，由亮暖像素推导）。

## cage挤出/最大光线距离 调研定案（2026-09-22, 用户实测+BVH几何数据）
- **cage单一全局值无解，用区域自适应2次烘焙texel合成**:
  - BVH模拟(碗区427面): cage=0.10碗正面命中400/427、背面命中3278最低档、miss=0；cage=0.02碗正面仅60/427(眼窝黑根因)；cage=0.15背面升4311(过冲)。用户实测0.1"略微改善眼窝"与数据一致。
  - 但全局0.10使肩带薄区ray起点10cm外首中肩皮肤→肩带皮肤色涡斑(实测回归)→身体需小cage。
  - 解: passA cage=bbox×0.011(身体) + passB cage=bbox×0.055≈0.10(眼窝碗), 碗区UV三角形mask(+2px膨胀)内取B其余取A; Normal用身体cage。
- **ray=0(无限)**: 穿透由首命中决定与ray无关; 有限ray只造成眼窝miss黑块(用户实测0更好)。2-pass有限+无限合成经复核等价单无限(首命中相同), 无效已移除。
- 领口下缘1-2px皮肤色虚线=薄衣缘固有(用户手跑金标准同相机同样有), 按用户观看距离验收。
- 纯烘焙对照blend的贴图必须**另存+pack**(指向正式路径会被后处理覆盖→假对照, 实测踩过)。

## v2边界保护 + v7 rim环内无条件涂肉色（2026-09-22 用户报修）
- 用户报"修复后衣身交界反而多锯齿/噪点": 根因=v2把衣-肤交界骑跨混色面(偏暗)判为异常斑→涂皮肤色→交界皮肤色斑。修: v2加boundary保护(邻域同时有皮肤样面与衣物样面(lum<60且b>=r-10)→跳过), 747面→378面。
- 用户定案"眼窝直接涂肉色": v7改rim环内(眼球球心d/r<1.0)**无条件**涂眼窝缘肉色中位(不看亮度; 旧版只修暗面用户实测仍黑)。813面/10010px。
- 无限ray副作用: 2.3%面背面命中(错面), 其中21面0.42-0.84m(碗内壁看到对侧眼睑内表面) → 全在眼球球体内, v7已覆盖。
- ⚠ mathutils BVHTree.ray_cast 的 max_distance=0 不是无限(全miss)! 探针用10.0模拟无限。
- cage_extrusion 保持 bbox_max*0.011(0.0199): p50首命中=0.0198=cage偏移本身, 贴合良好。

## 03 岛内自重叠（2026-09-22, 用户GUI圈出眼角/耳后）
- 类型: 同岛同向自重叠(耳漏斗/眼角锥面总角>2π, angle-based展开必然叠盖); 岛间重叠/折叠检测都查不到。
- 检测: 双重覆盖栅格(两层owner不同三角)+腐蚀1px去共享边缝; 当前模型实测199px/338面(耳743px/眼角363px两簇)。
- 修复(03_auto_uv.py 定状态后): 选中重叠面→region_to_loop标seam→仅选区unwrap(ANGLE_BASED)
  →average_islands_scale(否则CV爆表31.8)→全模型pack; 循环≤4轮。实测1轮清零, U/CV/岛数比不回归。
- ⚠ unwrap前必须重选面(region_to_loop会把面选区变边选区); use_uv_select_sync=True。
- 布局图 draw_layout S=4096(用户要求4K便于检查)。

## v7 眼窝碗心暗块（2026-09-22）
- 烘焙源=01闭眼高模的副作用: 碗底面射线打到眼睑【内表面】→ 暗色texel; 带眼球时被遮挡,
  隐藏眼球/无眼球查看器下是黑块. fix_diffuse_socket_interior: 眼球球体内(d/r<0.85)且暗(lum<60)面
  → 三角形texel替换为眼窝缘皮肤色中位(眼区2.2r内 lum>100 面中位). 实测128面/2328px.
- ⚠ 低模是quad: 三角形光栅化必须用 me.loop_triangles(loop→uv), 不能 v0,v1,v2=polygon的loops(4个会unpack崩).
- 眼区暗面texel(睫毛线/内眦深棕[75,51,35]等)是8K源贴图固有, 用户手跑版同位置同样有(左39/右49面 vs 我51/83), 不算缺陷.

## 04 烘焙源高模选择（2026-09-22 用户定案）
- **用 01高模修复/输出/01_highpoly_repair.blend（眼睑闭合），不用 01a眼窝版**。
- 原因: 01a的眼窝碗是新切几何, 其UV在8K源贴图上无有效texel → 碗内烘出暗青黑块;
  01眼睑闭合, 眼窝区烘到眼睑皮肤色, 眼球遮挡后整体自然(用户验收标准)。
- 低模(02 QR输入)虽源自01a带眼窝几何, 但04烘焙源可独立选; 对齐检查(中心偏差<9mm)两版均通过。
- 验证: 隐藏眼球渲染眼窝本体, 碗缘应为皮肤色; 带眼球渲染应无露出黑块。

## 自查纪律（用户多次纠正"自查了个寂寞"）
- 渲染相机位置必须由模型 bbox/已知 3D 坐标推导并打印，禁止凭感觉放相机；
  T-pose 下 bbox x 极值=指尖，肩特写不能用 x1 比例定位（实测截到前臂）。
- 每处修复先 dry=True 打印命中簇的 3D 位置+颜色，人工核对位置合理后再写回。
- 判据改动后必须重跑 dry 对比命中数：命中数暴涨(>0.5%面)=判据失准，不写回。
- **验收距离对齐用户**：衣缘1-2px过渡带虚线是源贴图(8K)固有缺陷，用户手跑产物同相机同样有，
  用户观看距离(全身/半身)不可见即合格；超近特写(0.5m+70mm)自查会提出比用户更严的标准→假FAIL。
  自查用全身(4.2m)+半身(1.6m)+部位特写三档，判定以半身档为准。

## v6 衣缘像素级碎线 + v5 raycast真值（2026-09-21 晚补充）
- v6 fix_diffuse_edge_specks: 皮肤色像素且5x5邻域衣物占比≥0.35 → 邻域衣物色中位；
  处理与皮肤岛粘连的衣缘碎线(v4连通簇查不到)。实测272像素。
- v5 真值获取必须 **可见性raycast**(法线外2mm向内打, |hit-2mm|≤0.8mm=面自身可见)：
  find_nearest 在薄衣缘命中贴合的内侧皮肤面→真值错(领口带漏检根因)。
- v5 颜色判据保守版: 衣物=lum<60且b≥r-10(冷调), 皮肤=r>140,g>100,b>70,r>g；
  放宽(衣物=任意暗色/皮肤r>120)会误伤手腕/鞋缘/阴影皮肤面(实测47簇假阳性)。
- 高模贴图用 image.pixels 索引时 y=v*hh(行0=v=0底边)；PIL/PNG 则 y=(1-v)*H。两者相反，实测上下翻转=25081面误报。
