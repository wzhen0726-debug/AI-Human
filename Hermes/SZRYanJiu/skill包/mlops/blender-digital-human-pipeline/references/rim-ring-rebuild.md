# Rim 环重建(眼窝边界) — 有效做法 / 已否决做法 / 验收

## 症状与真因
boolean(或任何切割)得到的 rim 环, 在"近垂直鼓包"处会**折返自交**: 边界出去又折回, XZ 上自己跟自己相交。
表现: 正面看洞口有缺口/台阶, 3D 转角出现 30~130° 异常值。**转角大不等于表面起伏, 先查折返。**

## 先量再改
`_q_fold.py`: 按边序把 rim 环取成折线, 在 XZ 上求线段自交对数 + 交点位置。
实测参考: R 环 0 处 / L 环 6 处(全集中在下睑外侧那 3mm) → 确诊。

## 有效做法: D2 整圈 rim 皮肤带重建
1. 沿手描轮廓向外删一圈皮肤面。判据必须用**"任一面顶点贴近轮廓"**, 不能用面心:
   粗面(边长 > 2×带宽)面心离得远但整面横跨轮廓 → 会戳进洞口, 形成用户一眼看见的"反面+面扭曲"。
2. 带外缘(此时是唯一洞边界)细分到 ≤0.5mm。
3. 内圈 = 手描轮廓本身; 外圈↔内圈对应关系用**沿环序的最近参数 → 解绕 → 单调化(带最小步长)**。
4. 每格两三角缝回; 失败则整块四边形(不要换对角线)。
5. 法线**逐面**与"共顶点的非新建面平均法线"比对定向(整圈统一判据会被污染)。

## 已实测否决(别再走)
- **绕眼中心角度配对**: 全局单调听着稳, 实际把洞口整个盖住(眼周开放边 0)。
- 只按面心判据删带 → 粗面残留 = 用户看到的反面/扭曲面。
- 局部补片(删小圆盘+缝回): 圆盘周界用的网格原顶点有 4~5mm 粗边 → 缝合长条 + 假折返。
- "换对角线"兜底缝合 → 把 rim 盖到自己身上。
- 事后用 subdivide 拆 rim 长边 → bmesh 引用失效(ReferenceError: BMVert removed), 拆分要放在法线处理之前/之外。
- 换切割方向(沿局部表面法向扫出切割体): 相邻切割壁互相穿插, boolean 出垃圾(洞直接消失)。

## 验收(缺一不可)
- rim 环: 开放边数 + 度数分布(应全 2 度, 出现 1 度=有缝、3 度=自交)+
- 折返自交数 = 0
- 洞口轮廓 vs 手描线 XZ 偏差 ≤0.2mm
- **面朝向**: 逐面法线 vs 共顶点邻面平均法线, 反面 = 0。用户会开 Blender"面朝向显示"(蓝=正面/红=反面)一眼查, 只看**洞外皮肤**上的反面; 眼窝深处看到后脑反面属正常。
- 存盘前 `bpy.ops.object.mode_set(mode='OBJECT')` — 否则文件以编辑模式保存。

## 诊断脚本(项目根, 只读)
`_q_fold.py`(折返) `_q_gap.py`(开放边/度数) `_q_normal.py`(反面数) `_q_faceo.py`(复现面朝向显示) `_q_ang.py`(边界角度分布) `_q_step.py`(轮廓偏差) `_diag_rim3d.py`(转角/抖动/间距) `_q_eb3.py`(眼球是否戳出 rim: 必须按环的真实顺序做 XZ 点内判, 角度排序会失效)
