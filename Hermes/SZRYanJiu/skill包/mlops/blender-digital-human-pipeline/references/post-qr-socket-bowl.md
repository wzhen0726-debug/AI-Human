# QR 之后的低模眼窝碗重建 — 现行做法在 `qr-lowpoly-eye-socket.md`

本主题(眼球球体拟合 / 镜像绕序种子 / 等宽内收 / 旧碗形状采样 / 多轮自检口径)统一维护在
`references/qr-lowpoly-eye-socket.md`; **不要按本文件的旧版内容执行**。三条不可回退的硬规则:

- **眼球球体**: 球心 = 包围盒中心; 半径 = 到该中心的 **p90**。禁用"顶点均值当球心"、禁用 max 当半径
  (顶点均值被角膜侧更密的顶点带偏 → 半径谱虚胖成 6.9~18.7mm → 碗面球过深, 用户判"完全不对")。
- **绕序**: 种子法 —— 每侧取环上第一条与既有面共享的边, 按流形一致规则定该侧顶点顺序;
  **该侧全部新面(含封底: 极点三角扇, 不是 n-gon 平盖)共用同一约定**。禁用拓扑 BFS 传播(会挂起)。
- **定向**: 只允许"局部 + 明确参考物"的定向; 禁止对工作网格用全局 `recalc_face_normals`
  (按连通岛重定向, 会把腿等远处区域成片翻掉)。
