# 左右不对称与镜像侧轮廓错位（01a 眼窝实例；方法通用）

## 现象
打点流程 = 一侧 GUI 手标、另一侧由镜像轴自动生成。脸/物体本底不对称 → 镜像侧天然错位：
**实测左轮廓整条落在左眼真实睑缘内侧 1.1~1.3mm**，表现为左侧“偏短偏窄、外眼角内收/发软”，且下游（重拓扑/建碗）怎么调都只剩左侧问题。

## 量化三件套（互相独立、同向则坐实）
1. **区域互配**：左右区域分别取几何/外观图，沿横向平移扫描求最优相关 → 最优平移量即错位。
2. **特征质心**：一侧特征质心（如贴图瞳孔 ±34.5/−35.9mm）与镜像预测值差 = 1.22mm。
3. **相对失配（验收主口径）**：|本侧轮廓质心 − 本侧特征锚| 的左右差——修复前 1.138mm，修后 0.165mm（目标 ≤0.3mm）。

## 为什么“调轴”不是解法
- 本底不对称不可约：右区绕轴镜像到左，最佳轴/最佳平移后最近距离仍是 **中位 0.49mm**（特征级 ~1.1mm）。
- 几何 RMS 最优轴（≈−0.07mm）≠ 特征最优轴（≈−0.62~−0.90mm）——两条口径给不出同一根轴。
- 结论：**按每侧自身几何取轮廓**，而不是拿一根轴硬对齐。
  实测修法 = 偏移侧轮廓 x 平移 −1.2mm（等效该侧区域轴 −0.67mm，零脚本改动、走 env 开关）；
  更准的等价做法 = 让用户在该侧 GUI 补标点（半自动工作流本来就允许）。

## 连带项：锚定物也要每侧摆
严格对称摆放会把镜像侧的锚定物（如虹膜/眼球）在开口内偏 ~1.3mm；应按本侧特征锚点逐侧摆放。

## 验收门（对齐用户感知，旧门看不见的）
| 门 | 阈值 | 旧门为何漏 |
|---|---|---|
| 解剖相对失配 \|Δ(L,R)\| | ≤0.3mm | 只量网格局部质量（最小边/面积/细长面）不看开口轮廓位置 |
| 眼角尖点 Δz(L−R) | ≤0.3mm | 同上 |
| 眼角尖度差（2mm 弧三点夹角） | ≤5° | 平滑类修复把尖磨钝、局部指标反而变好（实测倒圆减尖 ~11°、尖点内拽 0.29~0.55mm），单看局部质量必被蒙蔽 |

## 坑
- 引擎（QR）跑次浮动会在眼角产生 ±1mm 的 z 摆动 → 左右对称类验收**定在输入层（01a）**，低模层不做此口径。
- 平滑/倒圆类修复的代价要单列：它能让最小边指标从 0.27→1.6mm 变漂亮，但把开口轮廓位置与尖度损伤了——**修复引入新可见错误 = 全否**。
- 多方案对比时，同一部位“看起来好”可能只因为局部指标好；新旧门一起量，并以用户 GUI 观察为终审。
