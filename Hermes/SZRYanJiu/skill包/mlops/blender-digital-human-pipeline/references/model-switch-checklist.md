# 换原始模型：全链重跑检查清单

**为何需要**：管线关键参数全部由模型自身几何推导（bbox 比例 / 瞳距 / 眼宽 / 身高），换模型**不需要手改参数** —— 但有三类**旧模型数据会静默残留**，必须人工清理：

1. **修复类替换件**：如 `01高模修复/输出/01_original_tex_fixed.png`（眼窝皮肤化版）—— 04 的 FIXED_TEX 机制「文件存在即自动替换」，换模型后不清 = 拿旧模型贴图烘新模型。**换模型前删除或 `clean` 清输出**，由新流程重新生成。
2. **同名历史文件**：用户目录可能躺同名不同版本（实测见过与现用源 19.7% 像素差异的历史件）。替换件必须记录生成脚本+输入源；发现同名件只报告请用户处置，不假定使用、不顺手删。
3. **手调数据属旧模型**：手描轮廓 JSON、标记 blend（eyelid_contour_manual.json / 01A_markers_eyelid.blend）换模型后必须重新打点，不能沿用。

**资产替换**（`原始文件/`）：原始 GLB / 眼球资产 / Mixamo 动画 / 眼位检测 JSON（3ddfa 三件 = 眼中心锚点，新模型需重跑 3DDFA 或人工确认）。

**自动自适应项**（无需改代码，但要抽查日志推导值）：
- cage/ray = bbox 比例 ×0.0033 / ×0.0077
- margin 阶梯 = 基准 16 × [1, 1.5, 0.6]，择优
- 五官保护球 R = 2.2 × 瞳距（必须覆盖下巴/最远特征）
- 眼窝掩膜 = 真实眼球对象（位置/半径）射线命中推导
- RIM 带宽 = 0.035 × 眼宽；碗深 = r_ref 自算
- UV/QA 判据 = 全自参照比值（跨体型成立）

**抽查法**：看每环节日志里的推导值是否与模型同量级（保护球 R≈150mm、cage≈6mm、间距≈瞳距），数量级不对 = 推导输入坏了。

**半自动人工点**：01a 眼睑打点（12 点→镜像）、05 关节打点（17 点）。每轮点位天然不同，出现 rim/角部新形态按 `rim-band-qa.md` 流程归因修复（正常成本，不是回归）。

**逐环节验收点**：
- 01：对齐检查（低↔高中心偏差 <0.5% bbox；不合格脚本自动中止）
- 01a：交叉自检 = 0；针状面 <5° 列
- 02：QR 完成判据 progress==2；碗逐环 y 均差
- 03：折叠 == 0（硬门槛）+ 三项自参照比值
- 04：未填充 ≈0%；双 blend + 双贴图；**程序化 dump 材质连线（BaseColor+Normal 都在）**
- 05：物体模式移骨架 1m → 眼珠跟随 1000.0mm；眼珠间距
- 06：GLB 重导入复核（比例 1 单位=1 米 / 骨数 / 动画签名）

**时间预算**：全链 ≈12 分钟 + 两处 GUI 人工。首日建议先跑 01→02 确认两个人工点质量再续。
