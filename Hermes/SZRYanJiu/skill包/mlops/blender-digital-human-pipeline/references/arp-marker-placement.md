# ARP 17 点打点: 指南维护与放置规则(05 绑定)

## 指南文件结构(用户偏好, 已定形 — 重写/改版时保持)
1. **速览表放最前**: 每点 = 一句话位置 + 本模型高度参考(z); 其后一行对称自检(所有左右点 |x|/z 相等; 手臂四点 z 相同)。
2. "正面+侧面都要看": 点是 3D 点 —— 正面定 x/z, **y 必须切侧面视图(小键盘3)核**; 逐点列出侧面要查什么(chin/neck/root/knee/foot)。
3. 每点详条 = 唯一体表标志 + "不是…"反例(用户明确要求的两件套)。
4. 高度参考标注"本模型"—— 换模型需同步改, 不得当通用常量。

## 每个点是干什么用的(打偏会往哪传导 — 改指南的依据)
- **thigh(大转子)**: 直接决定骨盆半宽(=UpLeg|x|), 进而决定重定向后的**落地脚离中线比例(步态宽度)**。
  要放"大腿外侧最上方最外侧的骨突"; **不是裤缝线/大腿外侧中点** —— 放偏内 → 落地脚向中线收窄,
  步态 QA 的裕度全靠它(参见 `rest-normalization-x-leg.md` 的步态判据一节)。
- **root**: 骨盆上缘(髂嵴最高点连线高度), **必须高于 thigh 6-7cm**(Hips 骑在大腿根上方); 前后取体腔中点
  (不贴肚皮、不贴后腰)。
- **knee**: 膝关节**外侧**骨性边缘(股骨外上髁高度 / 髌骨外侧缘); **不是膝盖正前面**。
- **shoulder**: 三角肌中点(≈T恤肩缝); 不是体内肩关节旋转中心、不是斜方肌上缘。手臂四点(肩/肘/腕/指尖)z 全相同。
- foot=外踝中心(不是脚底/脚跟); chin=颏隆凸(不是嘴唇/喉咙); neck=大椎高度正中线(不是喉结);
  hand=腕横纹中点(不是掌根); hand_tip=中指指尖末端。

## 流程与保护(铁律)
- GUI 有镜像约束自动同步左右; 顺序: 正面打完 → 侧视核 chin/neck/root/knee/foot 的 y → 回正面复查。
- **05 第①步(打点 GUI)绝不 headless 跑** —— 会覆盖用户手调标记; 每轮自动备份手调版(安全网 `_备份/手调文件_权威/`)。
- 打点结果直接影响 rig 比例(骨盆宽比/腿长比), 这些比例又进入重定向缩放 —— 改指南前先看它们在步态 QA 里的作用。
