# 眼窝轮廓平滑（v46e）— Catmull-Rom 样条替代线性插值

## 问题现象
用户反馈眼窝上半部分出现 M 形/唇珠状波折，尤其在 LM_04→LM_05 控制点处。定量分析显示轮廓一阶差分有突变（+0.0015→+0.0002→-0.0008），二阶差分 0.001 级别，是分段线性折线导致的折角。

## 根因分析

### 1. 手动轮廓 12 点线性插值加密导致折角
`load_eyelid_contour` 用线性插值把 12 个手动标记点加密到 72 点：
```python
# 旧版: 线性插值加密
for k in range(n_points):
    target = total * k / n_points
    # ... 线性插值
    pt = pts[i] + (pts[(i+1)%M] - pts[i]) * t
```
线性插值在控制点处产生折角，尤其在上眼睑 LM_04→LM_05（几乎水平）处，折角通过径向投影传递到 ring0 形成 M 形波折。

### 2. 定量证据
R 眼 12 点轮廓上眼睑 z 序列一阶差分：
```
['+0.0042', '+0.0025', '+0.0015', '+0.0002', '-0.0008', '-0.0018']
```
点 3→4 是 `+0.0002`（几乎水平），点 4→5 突然变 `-0.0008`，突变 0.001 级别 = 折角。

## 修复方案（v46e）

### 核心修复：Catmull-Rom 样条加密
用 Catmull-Rom 样条替代线性插值，通过所有 12 个控制点且切向连续，消除折角：

```python
# v46e: Catmull-Rom样条加密(消除12点分段线性折线导致的M形折角).
# 根因: load_eyelid_contour用线性插值加密12→72点, 折角被保留→径向投影→ring0 M形.
# Catmull-Rom通过所有控制点且切向连续, 消除折角.
N = len(pts)
seg_len = [np.linalg.norm(pts[(i+1)%N]-pts[i]) for i in range(N)]
total = sum(seg_len)
n_out = 72  # 输出72点, 与load_eyelid_contour的n_points一致
out = []
for k in range(n_out):
    target = total * k / n_out
    acc = 0.0
    for i in range(N):
        s = seg_len[i]
        if acc + s >= target:
            t = (target - acc) / s if s > 1e-9 else 0.0
            p0 = pts[(i-1)%N]; p1 = pts[i]; p2 = pts[(i+1)%N]; p3 = pts[(i+2)%N]
            t2 = t*t; t3 = t2*t
            pt = 0.5 * ((2*p1) + (-p0+p2)*t + (2*p0-5*p1+4*p2-p3)*t2 + (-p0+3*p1-3*p2+p3)*t3)
            out.append(pt)
            break
        acc += s
pts = np.array(out)
```

**Catmull-Rom 样条特性**：
- 通过所有控制点（用户打的 12 个点位置不变）
- 切向连续（一阶导数连续，无折角）
- 曲线平滑（二阶导数连续）

## 验证结果
- 轮廓从 12 点加密到 72 点，尺寸保持 35.1×12.2mm
- 一阶差分从突变（+0.0015→+0.0002→-0.0008）变成平滑渐变（+0.0005→+0.0004→+0.0003...）
- 二阶突变从 0.001 级别降到 0.0001
- 管线 jump 从 2.1mm 降到 0.55/0.64mm（轮廓平滑后 ring0 更顺）

## 血泪教训
1. **线性插值会保留控制点折角**——手动打的点如果分布不均（尤其上眼睑几乎水平段），线性插值会在控制点处产生折角
2. **Catmull-Rom 是手动轮廓加密的正确选择**——通过所有控制点，切向连续，消除折角
3. **定量验证必须检查一阶/二阶差分**——不能只看宽高尺寸，要看差分连续性
