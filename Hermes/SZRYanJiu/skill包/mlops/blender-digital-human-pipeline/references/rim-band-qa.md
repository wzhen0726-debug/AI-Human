# Rim 带（开孔缝合带）坏面：归因与自适应修复

适用：眼窝/开口 rim 环附近出现扭曲、细长、错面，且会被下游重网格（QR）放大。

## 1. 先归因，再动手（禁止猜）

对**输入网格**与**处理后输出**分别统计同一区域的坏面占比，并与其**同网格上未被修改的参考带**对比：

- 分区口径：面心到轮廓折线的 XZ 距离（band < 1.16×名义带宽；参考带 2.3~6.2×名义带宽）—— 窗口随推导带宽缩放；眼区半径用模块既有推导值（EYE_AREA_R＝0.86×实测眼宽），不要再引入毫米绝对值；
- 指标：最小角 < 15°、长宽比 > 4 的面占比（可选：非平面度、法向朝后）；
- 判据自参照：`band 占比 ≲ 2× 参考带占比`。若输入本身干净而输出 band 变差数倍 → 坏面是缝合带产生的，从缝合带修。

用**距轮廓直方图 + 面心深度 + 方位直方**把坏面定位到具体机制：
条带内 → 采样/参数问题；pit/壁面内（深度在 rim 之后）→ 布尔切割产物，与带宽无关（做带宽扫描可验证：不敏感即非条带问题）。

## 2. 内环采样必须做间距正则化

"外环每顶点取轮廓最近参数"的内环构造会把**外环疏密原样带进内环** → 高曲率处条带楔形/细长。
修复：把 K 段环距序列做**有界低通迭代**（低通 → 限幅 0.45~2.2×均距 → 重新归一 → 保持单调/不跨越），
内环仍严格落在原轮廓折线上（只改采样位置）。参数全来自环自身统计（周长/K），换模型不失效。

## 3. rim 处理块外套"检测→调参重跑→择优"（不阻断）

半自动打点每轮点不同 → 最优参数每轮不同 → 不能写死。

- 阶梯：带宽 W = [默认, ×1.45, ×0.70]（内环不动，只改外扩量）；
- **跨轮必须量同一物理区域**：QA 窗口一律按【名义带宽 base】算（不是各轮自己的 W），否则跨轮分数不可比；
- 每轮重建后测 band/参考带占比，按 (小角+长条) 择优保留；
- 达 "band ≤ 2×参考带" 早停；轮内异常跳过；全部失败保留原样并告警；
- 实现：进入前 `snap = obj.data.copy()`，重试时 `obj.data = snap.copy()` 还原；
- **坑**：整体替换 mesh 数据块后，调用点下游的本地 `mesh` 变量会失效（`ValueError: The mesh must be in editmode`），必须 `mesh = obj.data` 重新绑定。

## 4. 验证

- 数值：修复后 band 占比应接近参考带（实测可从 7.2%/6.3% → 2.5%/0.9%）；下游 QR 输出同区再测一遍（11.2% → 1.6%）。
- 视觉：正交正视特写 + 平面着色即可看到外眼角拉出的**细长丝状面**；修好后消失、睑缘平滑。相对路径在原生 Blender 进程中会解析到 C:\（工作目录不同），**输出务必用绝对路径**。

## 5. 参数纪律（交付前必审计）

用户会直接追「再检查是不是死参数」。新增的每个数字必须归入三类之一，归不进的找出推导：

1. **模型实测推导**：带宽＝0.035×实测眼宽；内环均距＝环周长/K；QA 窗口＝名义带宽的倍数；眼区半径用模块既有 EYE_AREA_R。
2. **无量纲比值**：限幅 0.45~2.2×均距；阶梯 ×1.45/×0.70；早停 2×参考带；面形判据 15°/4:1。
3. **策略预算**（与尺寸无关，且最终由实测择优兜底）：迭代次数、滤波核权重、轮数上限。

审计做法：对新代码行区间拉全部数字字面量（先落盘脚本或 `sed -n 'A,Bp' f.py | grep -oE "[0-9]+" | sort | uniq -c`），逐条标来源；凡绝对毫米（窗口/半径/阈值）→ 改为随推导量缩放；改完**复跑等效性检查**（选定参数与指标应与审计前一致，不一致＝行为被改）。

耗时预期：每眼 ≤3 轮 × ~50s，达标早停 → 该步 ~1 分钟变 ~5-6 分钟属预期，主动向用户说明，免得以为卡死。
